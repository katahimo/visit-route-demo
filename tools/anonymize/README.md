# 予約情報・顧客情報の匿名化

顧客から受け取った予約情報・顧客情報（タブ区切り）とスタッフ情報（カンマ区切り。区切りは自動で判定）を、デモで使える形に匿名化する。
**元のファイルも出力も、このリポジトリにコミットしない**（`data/`・`out/` は .gitignore 済み）。

```bash
python3 -I tools/anonymize/anonymize.py \
  --customers tools/anonymize/data/顧客.tsv \
  --reservations tools/anonymize/data/予約.tsv \
  --out-dir tools/anonymize/out --salt 好きな秘密の文字列
```

## 列ごとの扱い

| 扱い | 列 |
|---|---|
| 仮名（江戸時代以前の歴史上の人物・皇族を除く。顧客と予約で同じ人に同じ名前） | 氏名・姓・名・姓（カナ）・名（カナ） |
| 仮名（スタッフ。同じスタッフには同じ名前。予約の新規登録者とスタッフ表の氏名は同じ名前になる） | 新規登録者（予約）・氏名（スタッフ） |
| 仮ID（C00001・R00001・S00001。顧客ID と会員番号は同じ表で振る） | 顧客ID・会員番号・予約番号 |
| 架空の値（スタッフ表は staff0001@example.com・080-0000-NNNN・ユーザーID staff0001） | メールアドレス（userNNNN@example.com）・電話番号（090-0000-NNNN） |
| 町丁目まで残す | 住所・住所2 |
| 丸めてずらす（半径 200m） | 緯度・経度 |
| 空にする | （スタッフ表）住所・パスワード・LW_ID・GoogleChatID・SessionToken・SessionExpiry、パスワード・顧客メモ・シンプルアンケート・駐車場番号など・緊急連絡先・関係性・避難場所・世帯全員の情報・Benefit会員ID |
| そのまま | 予約の日時・所要時間・金額・メニュー・状況、会員種別・状況・支払、登録日時、性別、年代、駐車場、住所2 の適用日 |

見出しが表にない列は空にする（`--keep-unknown` で残す）。結果の件数（住所をどの粒度で切れたか・表にない列）は標準エラーに出る。

## 仮名の振り方

- 顧客に似せず、ひとめで架空と分かるよう、織田 信長・北条 政子・源 義経のような江戸時代以前の歴史上の人物（皇族を除く。男性約 95 人・女性 34 人）を、出てきた順に振る
- 顧客は「性別」の列に合わせる（男→男性の名前、女→女性の名前）。予約の氏名は、同じ人の顧客の性別に従う。性別が空・その他の人は男女交互。スタッフは全員女性（出力の最後に「性別」列を足して「女」を入れる）
- 使い切ったら姓と名を組み替える（徳川 信長・織田 政子など。実在の組とは重ならず、男性の名前・女性の名前それぞれ数千通り）
- 同じ人は顧客と予約で同じ名前。1 回の実行の中では、顧客・スタッフ・予約をまたいで名前が重ならない

## 住所の切り方

| 元 | 出力 |
|---|---|
| 世田谷区三軒茶屋1丁目2番3号 ○○ハイツ | 世田谷区三軒茶屋1丁目 |
| 世田谷区三軒茶屋1-2-3 | 世田谷区三軒茶屋1丁目（3つ組は 丁目-番-号 と読む） |
| 架空市大字架空123-4・123番地 | 架空市大字架空（2つ組は 番地-号 か 丁目-番 か決まらないので町名まで） |
| 札幌市中央区北1条西2丁目3-4 | 札幌市中央区北1条西2丁目 |

- `--address-level town` で町名まで、`city` で市区町村まで
- 数字がなく切れない住所（建物名だけなど）は残して行番号を報告する。`--drop-unparsed-address` で空にする
- 地図に載せるには、切った住所をアプリの住所検索（国土地理院）にかけると町丁目の代表点が出る。`--coords drop` で元の緯度・経度を捨てて引き直すと、元の位置を全く残さない
