# メールの予約送信（Google Apps Script）

訪問予定アプリが「明日の訪問のお知らせメール」などを予約するための、スプレッドシート付きの Google Apps Script（GAS）のひな型。
アプリは GAS の Web アプリ（`/exec`）へ JSON を送り、GAS がシート「予約」に預けて、時刻になったら Gmail で送る。
やりとりの形の正は `src/contracts/mailSchedule.ts`。`Code.gs` はそれに手で合わせてある。

## 構成

| 場所 | 中身 |
| --- | --- |
| シート「予約」 | 1通1行。列は キー（訪問の日）・送る時刻・宛先・件名・本文・状態・更新日時・メモ・差出人 |
| シート「設定」 | 合言葉・トリガーの有無・使い方 |
| `Code.gs` | `doPost`（アプリからの頼み）／`sendDue`（5分ごとに送る）／メニュー「訪問予定」 |

状態は「予約」「送信済み」「取消」「置き換え」「失敗」。失敗の理由は「メモ」に入る。

## (a) 提供側：ひな型のシートを1回作って公開する

1. 新しいスプレッドシートを作る（名前は「訪問予定 メール予約送信」など）。
2. 拡張機能 › Apps Script を開く。
3. 最初からある `コード.gs` の中身をすべて消し、`gas/Code.gs` の中身を貼る。
4. 保存する（プロジェクト名は「訪問予定 メール予約」などにしておく。許可の画面に出る）。
5. シートの「共有」を「リンクを知っている全員が閲覧可」にする。
6. 次のコピー用のリンクを作る（`<ID>` はシートの URL の `/d/` と `/edit` のあいだの文字）。

   ```
   https://docs.google.com/spreadsheets/d/<ID>/copy
   ```

7. アプリの `src/lib/mailSchedule.ts` の `GAS_TEMPLATE_URL` にそのリンクを入れる。

提供側のシートでは「初期設定」を実行しない（合言葉やトリガーを作らない）。
コピーされたシートに合言葉は引き継がれないが、念のためひな型には予約も入れない。

## (b) 事業所：コピーして使う

1. 提供側のコピー用リンクを開き、「コピーを作成」を押す。**事業所の共用アカウント**（担当者個人ではないもの）でやる。
2. コピーしたシートで、メニュー「訪問予定 › 初期設定」を選ぶ。
3. 許可を求められたら許可する。「このアプリは Google で確認されていません」と出たら、「詳細」を押し、「（プロジェクト名）に移動」を押して進む。許可し終わったら、もう一度「初期設定」を選ぶ。
4. 出てきたダイアログの手順で公開（デプロイ）する。
   1. 拡張機能 › Apps Script を開く。
   2. 右上の「デプロイ」 › 「新しいデプロイ」。
   3. 種類の歯車 › 「ウェブアプリ」。
   4. 実行するユーザー：**自分**。
   5. アクセスできるユーザー：**全員**。
   6. 「デプロイ」を押し、出てきた `/exec` で終わる URL をコピーする。
5. アプリの「管理者設定 › メールの予約送信」に、その URL と、シート「設定」の合言葉を貼る。
6. 「接続を試す」を押す。うまくいくと、今日あと送れる宛先の数が出る。

### URL が変わる点

- 「新しいデプロイ」を押すたびに **URL が変わる**。そのたびにアプリへ貼り直しが要る。
- コードを直したときは、「デプロイ」 › 「デプロイを管理」 › 鉛筆のアイコン › 版を「新しいバージョン」にして「デプロイ」を押す。これなら **URL は同じ**。
- 版（`v`）を上げる更新（アプリとの形が変わるとき）は、`Code.gs` を新しいものに貼り直し、保存して、「デプロイを管理」で新しい版にする。アプリ側が新しい版になっているのに GAS が古いと、`badRequest`（版が合わない）になる。

## 運用の注意

- **共用の事業所アカウントで作る**。個人のアカウントで作ると、その人が辞めたときに送信が止まる。
- 1日に送れる宛先の数：無料の Gmail は **100**、Google Workspace は **1500**。超えた分は残り、翌日以降の実行で送られる。
- 送信は予約の時刻から **最大5分遅れる**（5分ごとの確認で送るため）。
- 1回の実行で送るのは、残りの上限まで・約5分まで。残りは次の回に回る。
- 合言葉が漏れたら、メニュー「訪問予定 › 合言葉を作り直す」を選び、シート「設定」の新しい合言葉をアプリに貼り直す。古い合言葉はすぐ使えなくなる。
- シート「設定」には合言葉がそのまま出る。シートの共有は事業所の人だけにする。
- **予定・住所などが、事業所の Google アカウントを通る**。預けたメールの宛先・件名・本文はシート「予約」に残る。古い行は手で消してよい（送信済み・取消・置き換え・失敗の行。「予約」の行を消すと送られなくなる）。
- 同じ日（キー）でアプリから預け直すと、まだ送っていない「予約」の行は「置き換え」になり、新しい行が足される。
- 宛先・件名・本文の先頭が `=` `+` `-` `@` のとき、シートで数式にならないよう先頭に `'` を付けて書き、送るときに外す。

## (c) よくあるつまずき

| 症状 | 原因と直し方 |
| --- | --- |
| 「接続を試す」で `notSetUp` | 初期設定がまだ。メニュー「訪問予定 › 初期設定」を実行する |
| `unauthorized` | 合言葉が違う。シート「設定」の合言葉を貼り直す（前後の空白に注意）。作り直した後は古い合言葉が使えない |
| `badRequest` | 版（`v`）が合わない・メールの形が違う（宛先に `@` が無い、1回に101通以上、本文が40000字超など）。版が原因なら `Code.gs` を貼り直して「デプロイを管理」で新しい版にする |
| `serverError` | GAS の中のエラー。Apps Script の「実行数」でログを見る。混み合っているだけなら少し待ってやり直す |
| 接続できない・HTML が返る | URL が `/exec` で終わっていない（`/dev` や編集画面の URL を貼っている）。または「アクセスできるユーザー」が「全員」になっていない |
| 古い URL に変わりがない | コードを直したのに反映されない。「デプロイを管理」で新しい版にしていない（保存しただけでは `/exec` は古いまま） |
| Workspace で「全員」が選べない | 管理者が、組織外へ公開する Web アプリを止めていることがある。Workspace の管理者に許可を頼むか、無料の Gmail の共用アカウントで作る |
| メールが送られない | メニュー「訪問予定 › 初期設定」でトリガーが付いたか（シート「設定」の「トリガー」が「あり」か）、シート「予約」の状態・メモを見る。時刻を過ぎていれば「今すぐ送る」で試せる |
| 状態が「失敗」 | メモに理由が出る（宛先が不正など）。直したいときは、アプリから預け直す |
| 上限に達した | 残りは「予約」のまま。翌日以降の実行で送られる。急ぐ分は別の手段で送る |
| 初期設定を2回押した | 合言葉もトリガーもそのまま（重複しない）。合言葉を変えたいときだけ「合言葉を作り直す」 |
