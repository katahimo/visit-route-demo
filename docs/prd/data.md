## フォーム（入力と保存）

| ID | 要件 | 優先度 |
|---|---|---|
| D250 | 入力の誤りは赤い文で欄の近くに出す。保存を押したときの誤りは読み上げ（`role="alert"`。同じ誤りで押し直しても読み上げ直す）、打つたびに検査する欄の誤りは読み上げで割り込まない。誤った入力欄には `aria-invalid` と誤りの文への `aria-describedby`。必須の欄は見出しに小さな「必須」の札を付け、読み上げにも伝える | Must |
| D251 | 入力の欄（訪問・〈利用者さん〉・〈スタッフ〉・種類・欠勤・仮押さえ・呼び方）は Enter で保存（複数行の欄は除く。欄の中の繰り返し・休みの入力の Enter はそのまとまりの保存）。保存して誤りがあれば最初の誤った欄へフォーカス。訪問の入力は開いたら最初の欄へフォーカスし、閉じたら開いたボタンへ戻す。日の予定の日を変えても入力を引き継ぐ（保存する日が表示中の日と違えば知らせ、表示中の日にするボタンを出す）。開いた後に消された・取り消された訪問は保存せず知らせる | Must |
