# PRD §3 要件：AI の提案・条件・点数

共通の決まり・読み方・索引・廃止した D番号は [../prd.md](../prd.md) §3。各表は D番号の昇順。画面の細部は `docs/design.md`・`docs/design/`。

## AI案・条件・点数

| ID | 要件 | 優先度 |
|---|---|---|
| D7 | **条件**を並べ、各々に**重み 0〜5**（0＝無効。1＝1件あたり移動10分ぶん）か**必須**。型：必要条件・希望（満たすと加点）・相性・担当の継続（いつもの担当）・負担の均等・移動と待ち | Must |
| D9 | ブラウザ内（Web Worker・焼きなまし）で**AI案（割当と順番）**を作る。時間の約束・稼働時間帯・必須の条件は破らず、重み付きの条件は移動と同じ分換算で足して最小化。計算中も画面は固まらない | Must |
| D10 | 同じ入力・同じ seed からは同じAI案 | Must |
| D12 | 訪問ごとに「なぜこの担当か」（相性◎・希望○ 女性・資格✓・継続・移動12分 など。見せ方は D229）。入らなかった訪問は原因の条件 | Must |
| D17 | 各〈スタッフ〉の件数を、稼働時間に比例した目安へ寄せる（外れた件数の2乗で重く）。必須なら目安の上限＋1件を超えない。既定は重み3 | Must |
| D20 | 条件の**プリセット**（初期：バランス・移動を短く・人の組み合わせ重視。「組み方の標準」と紛れないよう、初期の名前は「標準」ではなく「バランス」）。プリセットの重み・必須は変えられない（ADR-0065）。重みを変えるときは条件の重みの表で直して新しいプリセットとして保存する（最大6つ。D286）。名前・一言は変えられる。消せるのは自分で足したもの（初期の3つと最後の1つは不可）。「案を変える ▾」と「条件を調整する」のカード（点数・移動・入らない・違反・達成の要約。最高点に王冠）で選ぶと、この日だけ試す重み（D234）をその重みにし案を今の案にする（同じ条件・データの記録があれば計算しない。手直しを捨てるなら確認）。**点数はいつも「点数の基準」のプリセット**（条件の重みの画面で1つ選ぶ。組み方の標準を案から登録したときもその案のプリセットになる。初期はバランス）で付ける（ADR-0008・0010） | Must |
| D24 | 重みをプリセットとして保存（最大6つ）：日の予定の「条件を調整する」・作り直しの帯は「試す重みをプリセットとして保存」（この日だけ試す重みを写す）、条件の重みの画面のプリセットの節は「基準の重みを写して保存」（点数の基準の重みを写す。D235） | Should |
| D25 | 今の案の**条件ごとの達成の件数**（例 希望 18/20件・相性◎○ 6件・△ 1件・負担の均等 7/8人。分母はその条件が関わる訪問）を「詳しく」とカードの要約で。点数の基準の物差しで数える | Should |
| D173 | 今の案の帯で点数の横に「点を下げているいちばんの理由」（今の採点の内訳から）：必須の違反があれば「必須の違反 N件」、入らない訪問があれば「入らない訪問 N件」、減点 0.5点未満なら出さない、ほかは減点の最大の成分（「移動が長め（N分）」「相性△が N件」「「条件名」に合わない訪問 N件」「件数の偏り（N人）」など）。比較の記録の表でも同じ | Should |
| D229 | **理由は符号の無い言葉で**：訪問ごとの理由（D12）は「✓ 相性◎（選ばれやすい）」「! 移動12分（やや遠い）」のように印と言葉で出し、内部の値（費用の符号つきの数。100点の点数と向きが逆）は title だけ。点数の説明に内部の費用を出さない。比較の記録の表に乱数の種を出さない（表の下の「詳細設定」に畳む）。点を下げているいちばんの理由（D173）のすぐ後ろ（今の案の1行の中。D237）に**次の一手**（移動が長い→「移動を短く」で作る、入らない→受けられる人を見る、相性△→相性の表を開く） | Should |
| D233 | **条件の重みの画面＝考え方（プリセット）の中身と、ふだん使う考え方（点数の基準）を決める画面**（ADR-0035・ADR-0065・ADR-0066）：組み方の標準の「1. 案をくらべる」からの寄り道（D360。触らなくても初期の考え方で組める）。上にプリセットの節（点数の基準を選ぶ）、その下に重みの表。表の名前・種類は条件のまま、重み・必須は点数の基準のプリセットの型のもの。確定すると（D286）基準のプリセットのその型を直す（同じ型の条件は同じ重み。足す条件の重み・必須は基準のその型）。担当を組む・組み方の標準の点・初期データの検査・画面の点数はこの重みで作る・付ける。組み方の標準の案はプリセットごとに作る。見出しの下に「ふだんの考え方（点数の基準）の重みを決めます。触らなくても、初期の考え方で組めます」と［組み方の標準へ戻る］、表の上に直している基準のプリセットの名前 | Must |
| D235 | 条件の重みの画面のプリセットの節：プリセットの重み・必須は読み取り専用（変えられない。ADR-0065）。名前・一言の編集・消す（初期の3つと最後の1つは不可）・点数の基準に選ぶ だけ。初期に戻す操作と「基準の重みを写して保存」は無い（初期の3つは変わらないので、戻すときはそれを点数の基準に選ぶ）。「点数の基準」の説明は「ふだんの考え方。担当を組むと点数に使う。上の表はこのプリセットの重みから始め、変えると新しいプリセットにする」。ツアーの AI の条件の枚と用語「点数の基準」の説明も同じ考え方で書く | Should |
| D271 | **条件の重みの名前は文字で出す**（ADR-0044）：ふだんは文字、［名前を変える］で入力欄（Enter・欄を離れると決め、Esc で取り消す。空なら型の名前）。必須の条件を消す確認には「必須の条件です。消すと「守らなければ担当にしない」決まりが無くなり、合わない人にも担当が入ることがあります。」の本文 | Should |
| D286 | **条件の重みの表は下書きにして確定で保存**（ADR-0048。D233 の「変えると直す」を書き換え）：重みのスライダー・必須の切り替えは動かしても保存せず画面の中の下書きに置く。保存済みと違う行は左に注意の色の帯と淡い地、「変更あり 3→2.5」の印（色だけに頼らない）。下書きがある間だけ画面の下（下のタブの上）に貼り付く帯に主ボタン「新しい考え方として保存（N件）」（プリセットは書き換えない。ADR-0065）と文字のボタン「取り消す」（「条件を足す」は枠にして主ボタンは1つ）。保存は独自の確認で、名前（既定「〈元の名前〉（改）」）・変わる条件と重み（前→後）・元のプリセットはそのまま残り新しい考え方を点数の基準にして担当を組む・点数・要対応の検査に使う・今の担当は変わらず組み直すなら担当を組むで提案を出すを出し、保存で新しいプリセットを足して点数の基準にしトースト。プリセットが6つなら保存できず、使わない考え方を消すよう出す。取り消すは確認なしで捨てる。下書きは型ごとに触った欄（重み・必須）だけを持ち、保存済みに重ねて出す・確定する（別のタブで変わった触っていない欄を上書きしない）。確認の間に別のタブで点数の基準が替わったら確定しない。下書きのまま画面を離れる（アプリの中のリンク・［組み方の標準へ戻る］・コマンドパレット・案内ツアーの「今日の予定を開く」）と確認（「捨てて移る」／「編集を続ける」）、再読込・タブを閉じるはブラウザの確認。ブラウザの戻るは止めない。点数の基準を替える・基準のプリセットを消すと下書きを捨て（下書きがあれば確認で「捨てる」ことを言う。基準のラジオは独自の確認「点数の基準を「〈名前〉」に替えますか？」（「捨てて替える」／「編集を続ける」）で断れば替えない）、条件を消して型が無くなる・保存済みと同じ値に戻ると、その型の下書きは消える。名前・条件を足す・消す・プリセットの節・乱数の種は今までどおりすぐ保存 | Should |

## 「AI で組む ▾」の項目（D157・D158・D315）

説明の文の細部は `docs/design/pages-plan.md`。どの項目も提案を出すだけで、反映するまで訪問は変えない（ADR-0053）。

| まとまり | 項目（押せないとき） |
|---|---|
| AI で組む（範囲） | この日（M/D）を組む（計算中・今日より前・伝えた日・訪問が無い）・この週（M/D〜M/D）を組む（組める日が無い・ほかを組んでいる）・この月（N月）を組む（ほかを組んでいる）。日・週・月で同じ（D328） |
| プリセットで試す | 「〈プリセット名〉」で組む（点数の基準のほかのプリセットごと。条件の重みを切ると出さない。計算中・訪問が無い） |
| 比べる | 2つの提案を比べる（比較の画面へ。提案を比べるを切ると出さない。D331） |
| そのほか | ピンをすべて外す（N件）（ピンの付いた訪問が無い・計算中） |
