## 用語の言い換えと説明（D174・D175）

画面の用語は「反映する」（旧「当てる」。AI の提案・案A／案B・プリセットなどを訪問・条件に書き込む操作。元に戻すの手の名前・トースト・確認の文・glossary も同じ。担当を割り当てる意味は「割り当てる」、試しに使う意味は「プリセットで試す」）。過去の ADR は当時の文言のまま。

説明の文は `src/lib/glossary.ts`。言い換えは表示だけ（データのキー名・書き出しの見出しは変えない）。説明の目印は用語の後ろの ⓘ で、同じ画面の同じ語は最初の1か所だけ（D240・D241）。
