# PRD §3 要件：住所・地図・メール・道順

共通の決まり・読み方・索引は [../prd.md](../prd.md) §3。画面の細部は `docs/design.md`・`docs/design/`。

## 住所・地図（ADR-0016）

| ID | 要件 | 優先度 |
|---|---|---|
| D86 | 〈利用者さん〉に**郵便番号**（任意。入力を7桁に直し、直せなければ保存しない）。Excel に列（先頭の0を補う） | Should |
| D87 | 編集の「住所を探す」：郵便番号から外部の郵便番号検索で住所（都道府県〜町名）を入れる。候補は選び直せ、違う住所を書いていれば「元に戻す」 | Should |
| D88 | 「地図に置く」：住所から国土地理院の住所検索でピンを置く（候補5件まで）。ずれは地図のクリックで直す | Should |
| D89 | 一覧の「まとめて地図に置く」：位置の無い人（終了を除く）を 0.4秒あけて順に置く（郵便番号だけなら先に住所を入れる）。その間に直された人は書き換えない。進み具合・止める・置けなかった人と理由 | Should |
| D90 | 外部へ送るのはボタンを押したときだけで、郵便番号か住所の文字だけ。近くに「押すと、郵便番号・住所を外部のサービス（郵便番号検索・国土地理院）へ送ります」を常に出す。失敗（見つからない・8秒で時間切れ・つながらない・形が違う）は短く知らせ、データは変えない | Must |
| D118 | 空き状況の場所にも郵便番号と「住所を探す」（郵便番号は保存しない）。仮押さえのときは郵便番号も写す | Should |
| D119 | 空き状況の場所にも「地図に置く」。置いた点は表・試算・案内文の移動に使い、無ければ目安（前後15分）。打っただけでは計算し直さない。ピンがあるまま住所を変えたらピンは残し置き直しを促す（どこでも同じ） | Should |
| D120 | 空き状況でも送るのはボタンを押したときだけ。D90 と同じ注記（＋「条件などほかの項目は送りません」） | Must |
| D121 | 〈スタッフ〉の自宅にも同じ部品（郵便番号は保存しない） | Could |
| D399 | **名簿のあとの「位置の無い N人を地図に置く」**（ADR-0076）：〈利用者さん〉の名簿（Excel・CSV）を読み込んだあと、D89 の対象（位置が無く住所か郵便番号のある人。終了を除く）が残っていれば、名簿の欄の読み込みのすぐ下にボタン「位置の無い N人を地図に置く」と D90 の注記。読み込みだけでは送らない。押すと名簿の欄を閉じ、「位置が未登録の〈利用者さん〉」の欄で D89 のまとめて置くを始める（この1回の押しが送る同意で、もう一度押させない）。押した・置いている間・対象が0人・郵便番号・住所の検索が切のときは出さない。置けなかった人は D89 の出し方で、住所から見つからなかった人がいれば「市区町村の名前が無い住所は見つからないことがあります」を足す。〈スタッフ〉の自宅はまとめて置かない（D121） | Should |
| D415 | **初めての訪問先に決まりごと**（ADR-0082）：振り直しで新しく入る〈スタッフ〉がその〈利用者さん〉を過去8週に担当していなければ、連絡文（D245）の「お願いします」の行の下に決まりごと（入り方・鍵・駐車場・注意。入っているものだけ。D66）を添え、行に「初めて」の印。添えるのは欠勤・キャンセルの欄の連絡（振り直しで新しく入る人）だけで、日の予定の連絡の一覧・すべての連絡文のコピー・メールには添えない。日の予定の訪問の詳細とスマホ画面（D16）にも「初めて」の印と決まりごとを先頭に。判定は lib の純粋関数 | Should |
| D419 | **チャット用にコピー**（ADR-0085）：日の予定の「その他 ▾」に書き出しを行き先ごとに「チャット用にコピー」・「メールで送る」・「印刷」。チャット用の文は1日の全員分（「11/3（火）の予定」→「■〈名前〉」→「 9:00 〈利用者さん〉様（60分）」、担当なしは「■担当なし」）。決まりごと（入り方・駐車場・注意）は初めての訪問先（D415）の行の下だけ、鍵は「鍵の情報も入れる」のときだけ（既定は入れない）、住所は入れない。伝えた内容（無ければ今の担当）から作る。押すとコピーして知らせ。文は lib の純粋関数（メールと共通部分を使い回す） | Should |

## メール（ADR-0017・ADR-0069）

| ID | 要件 | 優先度 |
|---|---|---|
| D91 | 〈スタッフ〉と紹介元に**メールアドレス**（任意。緩い検査、直せない値は保存しない）。Excel に列。初期データに架空のアドレス（example.com） | Should |
| D92 | 日の予定の「メールで送る」：その日の予定を担当ごとに（伝えた内容、無ければ今の担当）。件名「10/18（日）の訪問予定」。本文は順番・時刻・〈利用者さん〉・住所・入り方・駐車場・注意・事業所名、欠勤・希望休はその旨。鍵は選んだときだけ（既定オフ） | Should |
| D93 | 週の「予定をメールで送る」（確定の書き方は D346）：週の予定を担当ごとに（件名「10/19〜10/25 の予定」）。訪問の無い日は休みや未定の旨。最終勤務日が前の人は出さない | Should |
| D94 | 連絡の一覧の〈スタッフ〉あての連絡文に「メール」（件名「10/18（日）の予定の変更」） | Should |
| D95 | 空き枠の案内文に「紹介元へメール（BCC）」：紹介元のアドレスを重複なく BCC（チェックで外せる）。長すぎれば分けて複数のボタンと「宛先をコピー」 | Should |
| D96 | メールは `mailto:` でアプリを開く（送信は人。日の予定は予約送信も選べる。D366〜D369）。本文は文字だけ。URL が目安（Windows・不明 2000字、iOS・Android・macOS 8000字）を超えれば要点に絞り、なお超えれば本文なしで「本文をコピー」。アドレスの無い人は押せず「メールアドレスが未登録です」。1人は To・一斉は BCC | Should |
| D366 | **メールの予約送信の設定**：管理者設定のいちばん下に「メールの予約送信（Google）」（メールの機能が入のときだけ）。ひな型のスプレッドシートをコピーするリンクと手順（「詳しく ▾」。D395。コピー → メニュー「訪問予定 › 初期設定」→ ウェブアプリとしてデプロイ → 貼る）、ウェブアプリの URL（`https://script.google.com/…/exec`）・合言葉・送る時刻（訪問の前日の HH:MM。既定 18:00）の欄、「接続を試す」（つながれば今日あと送れる数）・「保存」・「この端末の設定を消す」。URL・合言葉はこの端末だけに残し、データの書き出し・読み込み・初期化に入れない | Should |
| D367 | **日の予定のメールを Google で予約**：日の予定の「メールで送る」の欄に枠「Google で予約して送る」。つないでいれば、メールアドレスのある〈スタッフ〉全員分の件名と全文（長さの目安で削らない）を事業所の GAS に預け、前日の送る時刻に送らせる（過ぎていればすぐ。最大5分遅れ）。過ぎた日・アドレスのある人がいない日は押せず理由。つないでいなければ管理者設定への案内だけ。mailto の「メールを作る」はそのまま並べる | Should |
| D368 | **予約すると確定**：「N人分を予約して確定」を押して預けられたら、その日を確定（伝えた）にする（確認なし。知らせの「元に戻す」で確定を戻せる。予約は残る）。確定済みの日は「N人分を予約する」 | Should |
| D369 | **予約し直す・取り消す**：預けた日は枠に「予約済み：10/27（火）18:00 に N人分」（この端末の記録）と「予約し直す」（同じ日のまだ送っていない分を置き換える）・「予約を取り消す」（確認つき。確定はそのまま）。送る時刻を過ぎたら「送信の時刻を過ぎました」。失敗は理由の文（合言葉・初期設定・版・つながらない・時間切れ 20秒） | Should |

## 道順のリンク（ADR-0018）

| ID | 要件 | 優先度 |
|---|---|---|
| D97 | 日の予定のメールに Google マップの**道順のリンク**：全行程（自宅→訪問…→自宅）と区間ごと。移動手段は〈スタッフ〉の移動手段。長すぎるときの削り方は D346 | Should |
| D98 | スマホ画面の各訪問に「ここへ道案内」（今いる場所から）と「前の場所から」、地図の下に「1日の全行程を開く」 | Should |
| D99 | 1本の経由地は3件まで。超える・URL が 2,048字を超えるときは全行程を分ける（「全行程 1/2」）。公共交通は区間ごとだけ | Should |
| D100 | 日の予定の訪問の詳細に今の担当の順番での「前の場所から」と「ここへ道案内」（担当が無ければ出さない。未確定ならその旨） | Should |
| D101 | 道順は公開の Maps URLs を作るだけ（キー・サーバーなし。アプリから送らず新しいタブで開く）。URL には場所（座標か住所）と移動手段だけ。場所が無い区間は理由を書いて出さない。自転車には徒歩への切り替えの注記。区間の分数・距離は Google から取らない | Must |
