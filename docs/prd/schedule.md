## データの形と予定の組み方（版2。ADR-0053）

| ID | 要件 | 優先度 |
|---|---|---|
| D314 | **担当は訪問に持つ**：1回の訪問が担当（null＝担当なし）・組んだ開始・ピンを持ち、その日の割当は「その日の訪問の担当と開始の並び」から決まる。繰り返し（定期パターン）の回は見るときに計算し（担当は繰り返しの担当、組んだ開始はその曜日の標準の開始。D353）、変えた回（担当・開始・ピン・時刻・取り消し・メモ）だけを保存する。先に作っておく「展開」と「未作成」は無い（先の週・月も繰り返しの回が出る）。〈利用者さん〉の「いつもの担当」は無くし、繰り返しごとに担当を1人持つ | Must |
| D315 | **AI は提案を出すだけ**：担当を組む（D356）・組み方の標準（D350）で、担当・順番の**提案**を出す。提案の帯に担当が変わる件数・時刻が変わる件数・点（今 → 提案）と「反映する」「捨てる」。反映するまで訪問は変わらない。反映すると訪問に担当・開始を書き、全体の「元に戻す」（D329）で戻せる。ピンの訪問と、標準の担当の計算した回（D352）の担当は変えない。提案は保存しない（読み直すと消える）。予定（日・週・月）を開いても自動では組まない | Must |

| D317 | **提案を比べる**（`#/compare`。担当を組むの「案を比べる」から開く。D331）：欠勤前（振り直しを反映した日）・今の担当・担当を組むで出したその日の提案・その場で作った提案（考え方＝プリセットを選んで「提案を作って比べる」）を並べ、A・B を選んで担当ごとに比べる（移動・待ち・点・入らない・地図）。保存しない（日付を変える・読み直すと消える）。「反映する」でその提案を今の担当にする（作ったあとに訪問が変わっていれば古い印）。訪問の無い日は空の画面（日の予定で訪問を足す） | Should |
| D318 | **重みは1組**：条件の重みはいつも点数の基準のプリセットにそろえる（日ごとに別の重みは持たない）。AI で組む・点数・訪問ごとの検査はこの重みで計算し、ほかのプリセットは「試す」（提案を出すだけで重みは変えない） | Must |
| D319 | **ピン**：手で担当を替えた訪問（ドラッグ・「担当を変える ▾」・受けられる人に入れる・訪問の詳細の欄）は自動でピンになり、AI で組んでも担当を変えない。「次からもこの人に」の記憶はやめ、続けて同じ人にするときは繰り返しの担当を直す（これ以降・すべて） | Must |
| D321 | **要対応は訪問ごとの検査**：担当なし・担当が休み（欠勤）・条件に合わない（必須の条件・担当を限る）・時間に間に合わない（担当が休みの訪問には重ねない）を訪問ごとに出し、日・月の要対応はその数で数える。月の要対応の行は 要対応の訪問のある日・未連絡の変更のある日・出勤〜退勤（拘束）が上限を超える日。「条件が変わった」・作り直しの帯・条件の変更の控えと戻す（D161〜D166・D290〜D292）はやめ、条件を変えたら訪問ごとの検査で分かる形にする。欠勤があってもその人に訪問が無ければ要対応にしない（「欠勤あり（対応済み）」は無い） | Must |
| D322 | **初期データ（版3）**：繰り返しは前の月の1日から始まり、前の月の1日〜昨日は繰り返しの担当のまま伝えた（確定済み）状態（月の予定で過去の混み具合も見られる）。繰り返しは担当を1人持つ（担当する曜日すべてに勤務があり、同じ人の回が30分より近く重ならない人。無ければ担当なし）。今日からの日は AI で組まず、繰り返しの担当のまま（AI で組むのは担当を組むで。ADR-0064）。同じ日付なら同じデータ | Must |
| D323 | **予定の組み方の言葉**（D307）：提案（AI）・ピン・確定（伝えた）・まだ伝えていない・未連絡の変更・担当なし・要対応。「AI案・今の案・確定した割当・記録・未作成・条件が変わった・試す重み・手直しの記憶」は画面に出さない。案内ツアーの予定の枚の3段は「提案（AI）→ ピン → 確定（伝えた）」。用語の説明（ⓘ）も同じ言葉 | Should |
| D324 | **データの版2**：保存の版を2に上げ、版1のデータは移さない（デモなので）。版1の保存データ・控えのファイルを開くと「データの形が変わったので初期データで始めます」と知らせて初期データで始める（控えのファイルの読み込みは同じ文で断る）。Excel のブックも版2の形（訪問に担当・開始・ピン、繰り返しに担当） | Must |
| D325 | **欠勤・キャンセルの欄（版2）**：振り直し（案A・案B）は提案と同じく訪問に書き、振り直す前の担当を日ごとに1つ残す（「振り直す前に戻す」・比べるの「欠勤前」）。段階は 起きたこと→休む人（訪問）→影響→振り直し→連絡・確定 の5つ。5段目で連絡の一覧（D244）を見て「連絡したので確定」で伝えた内容を残し欄を閉じる（「あとで確定する」でも閉じられる） | Must |
