## データの形と予定の組み方（ADR-0053）

| ID | 要件 | 優先度 |
|---|---|---|
| D314 | **担当は訪問に持つ**：訪問は担当（null＝担当なし）・組んだ開始・ピンを持ち、その日の割当はその日の訪問の担当と開始の並びで決まる。繰り返し（定期パターン）の回は見るときに計算し（担当は繰り返しの担当、開始はその曜日の標準の開始。D353）、変えた回（担当・開始・ピン・時刻・取り消し・メモ）だけ保存する。先の週・月も回が出る。担当は〈利用者さん〉でなく繰り返しごとに1人 | Must |
| D315 | **AI は提案を出すだけ**：担当を組む（D356）・組み方の標準（D350）で担当・順番の提案を出す。提案の帯に担当が変わる件数・時刻が変わる件数・点（今 → 提案）と「反映する」「捨てる」。反映するまで訪問は変わらず、反映すると訪問に担当・開始を書く（元に戻せる。D329）。ピンの訪問と標準の担当の計算した回（D352）は変えない。提案は保存しない。予定を開いても自動では組まない | Must |
| D316 | **確定＝〈スタッフ〉に伝えた内容**：日の予定の「確定（伝えた）」で、その日の今の担当・開始を伝えた内容として残す（日ごとに1つ）。日の状態は まだ伝えていない／確定済み／未連絡の変更あり の3つ。確定後に担当・時刻を変えた訪問は未連絡の変更になり、連絡の一覧（担当が外れる・入る・時刻が変わる。〈スタッフ〉ごと）で確かめて「確定し直す（伝えた）」。月のマス・進み具合の帯・要対応の帯の「未確定 N日」（D404）・週もこの3つで数える | Must |
| D317 | **提案を比べる**（`#/compare`。入口は D331）：欠勤前（振り直す前の担当）・今の担当・担当を組むで出したその日の提案・その場で作った提案（考え方＝プリセットを選んで「提案を作って比べる」）を並べ、A・B を選んで担当ごとに比べる（移動・待ち・点・入らない・地図）。保存しない（日付を変える・読み直すと消える）。「反映する」でその提案を今の担当にする（作ったあとに訪問が変わっていれば古い印）。訪問の無い日は空の画面（D176） | Should |
| D318 | **重みは1組**：条件の重みはいつも点数の基準のプリセットにそろえる（日ごとの重みは持たない）。AI で組む・点数・訪問ごとの検査はこの重み。ほかのプリセットは提案を出すだけで重みは変えない | Must |
| D319 | **ピン**：手で担当を替えた訪問（ドラッグ・「担当を変える ▾」・受けられる人に入れる・訪問の詳細の欄）は自動でピンになり、AI で組んでも担当を変えない。手直しを覚えることはせず、続けて同じ人にするときは繰り返しの担当を直す（これ以降・すべて） | Must |
| D321 | **要対応は訪問ごとの検査**：担当なし・担当が休み（欠勤）・条件に合わない（必須の条件・担当を限る）・時間に間に合わない（担当が休みの訪問には重ねない）を訪問ごとに出し、日・月の要対応はその数で数える。月の要対応の行は 要対応の訪問のある日・未連絡の変更のある日・出勤〜退勤（拘束）が上限を超える日。条件を変えたら訪問ごとの検査に出る（別の知らせ・控えは持たない）。欠勤の人に訪問が無ければ要対応にしない | Must |
| D322 | **初期データ**：繰り返しは前の月の1日から始まり、前の月の1日〜昨日は繰り返しの担当のまま伝えた状態（入の月の予定で過去の混み具合も見える）。繰り返しの担当は1人（担当する曜日すべてに勤務があり、同じ人の回が30分より近く重ならない人。無ければ担当なし）。今日からの日は作るときには組まず繰り返しの担当のまま（デモで始めるときは作ったあと D409 で担当なしを組む）。同じ日付なら同じデータ | Must |
| D323 | **予定の組み方の言葉**（D307）：提案（AI）・ピン・確定（伝えた）・まだ伝えていない・未連絡の変更・担当なし・要対応。「AI案・今の案・確定した割当・記録・未作成・条件が変わった・試す重み・手直しの記憶」は画面に出さない。ツアーの予定の枚の3段は「提案（AI）→ ピン → 確定（伝えた）」。用語の説明（ⓘ）も同じ言葉 | Should |
| D324 | **データの版**：古い版の保存データ・控えは移さない。開くと「データの形が変わったので初期データで始めます」と知らせて初期データで始め、控えのファイルの読み込みは同じ文で断る。Excel のブックも今の版の形（訪問に担当・開始・ピン、繰り返しに担当） | Must |
| D325 | **欠勤・キャンセルの欄**：振り直し（案A・案B）は提案と同じく訪問に書き、振り直す前の担当を日ごとに1つ残す（「振り直す前に戻す」・比べるの「欠勤前」）。段は 1 何が起きたか（D414）→ 2 連絡・確定 の2つ。2段目で連絡の一覧（D244）を見て「連絡したので確定」で伝えた内容を残し欄を閉じる（「あとで確定する」でも閉じる） | Must |

## 訪問の詳細の欄（ADR-0051）

| ID | 要件 | 優先度 |
|---|---|---|
| D301 | **訪問の詳細の欄**：1件の訪問を、どの画面から開いても同じ右の欄で見る・直す。中身は〈利用者さん〉の名前（押すと詳細）・日付・時刻（受けられる時間帯）・所要・種類・担当（〈スタッフ〉の印・ピン・いつもの担当）・繰り返しの回なら「繰り返し：月・水 14:30（10/22から）の回」・この回の変更の印（「日付 10/28→10/29」など。「繰り返しのとおりに戻す」）・メモ・決まりごと・道順。操作は日時を変える（日付・時間の約束・開始・所要・種類・メモ）・担当を替える・取り消す（ふつう／当日キャンセル）・取り消しをやめる。日時と担当は同じ「保存」で変わる。主ボタンは1つ（保存。新規は「追加」）。Tab は欄の中で回り、Esc で閉じ、保存・閉じたあとのフォーカスは開いた帯・行（作り直した回は新しい帯）。保存・取り消しのトーストに「元に戻す」（あとで別の変更があれば戻さず理由）。今日より前の訪問は見るだけ。日の予定以外から開いたら「日の予定で見る」。印刷では出さない | Must |
