# PRD §3 要件：予定を組む・定期パターン

共通の決まり・読み方・索引は [../prd.md](../prd.md) §3。画面の細部は `docs/design.md`・`docs/design/`。予定を組む（担当を組む・条件の重み・案を比べる）はエキスパート機能が入のとき（D406）。

## 予定を組む（ADR-0063・ADR-0100）

| ID | 要件 | 優先度 |
|---|---|---|
| D355 | **AI で組むのは「組む」**：メニューの「組む」（子：条件の重み `#/rules`・担当を組む `#/arrange`。ADR-0100）で AI で組む。予定（月・週・日）は手で直す（ドラッグ・「担当を変える ▾」・受けられる人・訪問の詳細の欄）だけで、AI で組む入口・予定のモードを置かない。欠勤の振り直し（案A・案B）と入れた分の自動の組み（D372）は別 | Must |
| D356 | **担当を組む**（`#/arrange`）：範囲（月・週・日）を選び、担当なし・要対応の数を見て「AI で組む」（今の条件の重み＝点数の基準で組む。標準は置かない。D435）。考え方を選ぶ欄は置かず、「考え方：〈点数の基準の名前〉」と［条件の重み］へのリンクを出す（考え方を比べるのは案を比べる）。結果は提案の帯（担当・時刻が変わる件数・点・［反映する］［捨てる］と、日ごとの変わる訪問の一覧（時刻・〈利用者さん〉と「今の担当 → 提案の担当」、時刻だけなら「今の開始 → 提案の開始」））で見て、反映すると訪問に書く（元に戻せる）。案を比べる（`#/compare`。D331）へ移れる。細部は `docs/design/pages-arrange.md` | Must |
| D358 | **全画面の切り替え**：上の帯の右端にアイコンのボタン「全画面で表示」（全画面のときは「全画面をやめる」。Esc などで戻ったときも合わせる）。全画面にできないブラウザ（iPhone の Safari など）と印刷では出さない | Should |
| D362 | **予定と相性**（`#/basics`。〈利用者さん〉の小さいタブ 一覧・予定と相性・相性。D394。ADR-0100）：〈利用者さん〉の繰り返しの時刻と相性・勤務を1枚の表で確かめて直す。行＝〈利用者さん〉の繰り返し・列＝曜日で、マスにその曜日の時間の約束・担当・その組の相性の記号・担当が休止／勤務日でない／勤務時間の外なら札、右の列にその〈利用者さん〉と相性を入れた〈スタッフ〉（◎○△×の順）。マスの時刻を押すと直せる（曜日が1つの繰り返しは共通の時刻、2つ以上は曜日ごとの時刻。毎月のパターンの機能が切なら曜日が2つ以上の繰り返しは直せない）。名前からその人の画面へ。相性の機能が切なら相性を出さない | Should |

## 繰り返し（定期パターン）

| ID | 要件 | 優先度 |
|---|---|---|
| D38 | 〈利用者さん〉ごとに**繰り返し**（定期パターン：種類・曜日・繰り返し方・時刻・所要・開始日〜終了日・担当・メモ）。1人に複数 | Must |
| D39 | 繰り返しの回は見るときに計算する（D314）。ID は元の日と繰り返しから決まる（`${日付}_${パターンID}`。保存した回も同じ ID） | Must |
| D40 | 回は1件ずつ直せる（日時・所要・取り消し＝「この回だけ」。繰り返しを直しても残る）。繰り返しを直すときは「いつから」（初期は今日）で分け、それより前の回と、この回だけ変えた・取り消した回は変えない | Must |
| D64 | 繰り返し方は毎週系（毎週〜4週ごと）か**毎月の第N週**（第1〜第5を複数。無い月は作らない）。**曜日ごとに開始時刻を上書き**できる（月曜 9:30・木曜 15:00）。Excel にも列 | Must |
| D151 | 月の予定の見出しの下に**進み具合の帯**：その月の今日以降の「訪問 N件」「担当 x/y日」「確定 x/y日」「要対応 N件」（右の「要対応」の欄と同じ数え方。要対応の帯とは数える種類が違う）。済んだものに✓、要手当ては注意の色。下の縁に積み上げ（D80） | Should |
| D152 | 帯の右に次の一手を1つ（従のボタン。主ボタンは操作の行。D393）：担当なしの訪問がある日が2日以上→「担当を AI で組む」（D356）、手当てが要る要対応→「要対応を見る」、確定していない日→「確定していない日を見る」、見るだけの要対応（未連絡の変更・拘束超）→「要対応を見る」、無ければ「準備は済みました」 | Should |
| D153 | 帯の数字・ボタンは、担当を組むはその月の担当を組む（`/arrange?ym=`）、要対応・確定していない日は月の予定の欄（`do=attention`／`unconfirmed`）を開く。`do=batch` は担当を組むへ移す。数が変わったら要約を読み上げる | Should |
| D154 | 月の予定には AI で組む入口を置かない（帯の次の一手と担当を組むの画面だけ）。月の見出しの下の要約は「月全体：入らない N件・当日キャンセル N件」だけ | Should |
| D165 | 帯は変更が 600ms 止まってから数え、日ごとの結果を覚える（相性の画面の速さを落とさない） | Should |
| D256 | **担当を組むの計算は画面を移っても続く**（ADR-0042）：画面の外で回し、ほかの画面へ移っても止めない。上の帯に「〈名前〉の担当を組んでいます N/M日」（担当を組むへのリンク）と［止める］、担当を組むと月の予定では画面の中に進み具合（上の帯に出さない） | Should |
| D257 | 1日ずつ組んで提案にし、反映するまで訪問は変えない（D328）。終わったら知らせ（「〈名前〉の担当を N日分組みました」など）と［担当を組むを開く］（提案の帯が見える画面では出さない）、止めたら「N日分組んだところで止めました」とそこまでの提案。二重には始めない。ページを閉じる・読み直すと止まり提案は消える。データの丸ごと差し替え（読み込み・初期状態に戻す・直前の状態に戻す・別のタブの変更）で止めて提案を捨てる。組み始めたときと訪問・その日の問題の入力が変わった日は反映せず知らせる | Should |
| D353 | **標準の開始**：繰り返しは曜日ごとに標準の開始を持てる。計算した回の組んだ開始はその曜日の標準の開始（無ければ開始（早）で並べる）。繰り返しの節・Excel の繰り返しの列で見て直せる | Should |

## 入れたら自動で組む・エキスパート機能（ADR-0072）

| ID | 要件 | 優先度 |
|---|---|---|
| D372 | **ふだんの道は 登録 → 希望日時 → 自動**：〈利用者さん〉・〈スタッフ〉を登録し、希望日時（繰り返し＝曜日と時刻。単発＝予定のカレンダーで日を選んで足す）を入れたら、入れた分を自動で組む。繰り返しは今日から翌月末まで。単発は日ごとに足す（ベビーシッター型は単発だけ） | Must |
| D373 | **自動の組みの範囲**：担当なし・ピンなし・伝えていない日・開始日が今日以降の訪問のうち、今の入力で増えた・日時が変わったものだけ。ほかの訪問の担当はピンと同じに固定する。伝えた日は組まない。今の点数の基準で組む（組み方の標準は置かない。D435） | Must |
| D376 | **繰り返しの担当を自動で書く**：繰り返しを足す・直して自動で組んだ担当は、担当の決まっていない繰り返しの担当（`usualStaffId`）に書く（以後の週は同じ人。範囲の中で組まなかった回は担当なし）。単発・手直しからは書かない（D319） | Must |
| D378 | **ひな形「単発の予約」**（ベビーシッター型。ADR-0092 で「単発のみ」から改名）：機能 `patterns`（繰り返し。既定は入）を切り、〈利用者さん〉の画面の繰り返しの欄を隠す。入力は予定のカレンダーで日ごとに足す単発で、足すたびにその日の分を自動で組む（D373） | Should |
| D405 | **自動の組みの反映**：保存の直後に1回、1手で書き（元に戻せる）、知らせに「N件の担当を組みました」と［元に戻す］。提案の帯は出さない。組む対象は担当なしと、その保存で変わった日の要対応＝間に合わない・重なり・休みの人の訪問（切。ADR-0089。要対応の組み直しだけで1件も書けなかったときは知らせを出さない）。組めない訪問は担当なしのまま（日の予定の「受けられる人」で手で選ぶ）。重い範囲は Worker で計算し進み具合を出す。計算中の次の保存は順に待たせ、計算中に変わった日は書かない（要対応の帯の［要対応を組む］（D403）で拾う） | Must |
| D406 | **エキスパート機能**（機能 `expert`。既定は切。ADR-0028）：入れると担当を組む・案を比べる・条件の重みの入口が出る（メニューは D401）。切のメニューは D400。予定と相性（`#/basics`）は入切とも〈利用者さん〉のタブ（D394）。`compare`・`rules` は切のとき使えない。初期データ・ひな形の「基本」は切で始め、features の無い古いデータ・控えは入 | Must |
| D407 | **自動の組みを走らせる時**：人が希望日時を入れて保存したときだけ＝〈利用者さん〉の繰り返しの足す・直すと、訪問の欄の保存（新しい単発・日時の変更。担当に「担当なし」を選んだときは除く）。ドラッグ・まとめて直す・アプリを開いたとき・予定と相性の表の時刻の変更では走らせない（読み込み・取り込み・貼り付けのあとは D442）。エキスパート機能の入切によらず走る。取りこぼしは切なら要対応の帯の［要対応を組む］（D403）、入なら担当を組むで拾う。担当を組む・欠勤の振り直しは提案を見て反映する | Must |
| D416 | **「定期の予定を追加」の開始日と毎月**（ADR-0083）：定期の欄に「開始日」（既定は今日・今日より前は不可。繰り返しの `from`。自動の組みは開始日から翌月末）。くり返しは1つの選択で 毎週／隔週／3週ごと／4週ごと／毎月（第N）。毎月は第N曜日の機能が入のとき（ひな形の「基本」は入。ADR-0086）で、毎月なら 第1〜第5 のチップ（複数・1つ以上必須。D64）。契約は変えない | Must |
| D434 | **切の進み具合の帯は担当を組むの画面へ移らない**（エキスパート機能が切）：訪問・担当の数字はリンクにせず文だけ（組む日が0日なら移っても何もできない）。担当なしの訪問がある日が1日以上なら次の一手は「担当を AI で組む」のボタンで、押すとその場でその月の担当なしの訪問がある日を担当を組むの画面と同じ手順で組み、案は範囲の提案の帯で「この案にする」（D257）。組んでいる間は押せない。入は D152・D153 のまま | Should |
| D435 | **組み方の標準は置かない**（ADR-0100）：標準の週の表・登録・案の日で見る・基本情報が変わった知らせ・要対応の帯の「組み方の標準が無い」は無い。担当を組む・自動の組みは標準なしで、今の条件の重み（点数の基準）で組む。同じ人に寄せるのは繰り返しのいつもの担当（`usualStaffId`）：その日に担当できる回はピンと同じに固定し（担当が休み・条件に合わない回だけ AI が代わりを探す）、自動の組みが繰り返しを入れて組んだ担当は `usualStaffId` に書く（D376）。重みを直すのは条件の重み（D233・D286） | Must |
| D442 | **読み込み・取り込みのあとは自動で組む**（ADR-0108）：予約の CSV・名簿の読み込み、休みのカレンダーの取り込み、連絡の貼り付けで入れたあと、要対応の帯の［要対応を組む］（D403）と同じ対象（今日〜翌月末の担当なし・ピンなし・伝えていない訪問と、切なら間に合わない・重なり・休みの人の訪問）を自動で1回組む（D405 の反映・知らせ・元に戻す。読み込みの1手とは別の1手）。エキスパート機能の入切によらず走る。組む対象が無ければ走らせない。アプリを開いたとき・元に戻したとき・データが変わるたびには走らせない（戻した直後に組み直して戻せなくなる・残した担当なしを埋めてしまうため）。住所から位置をまとめて探したあと（D427。止めた・画面を離れて止まったときも。1人だけ探す行の［住所から探す］と、探すあいだにデータを丸ごと差し替えたときは除く）は、位置を入れた人がいれば同じ対象を自動で1回組む（探すあいだは位置が変わり続け、読み込みのあとの自動の組みはその日を飛ばすため）。読み込み・確認のあいだにデータが変わったら（位置の検索など）、同じファイルを今のデータで読み直し、確かめた内容（件数・名前）が同じなら入れる（違えば入れずに読み込み直しを頼む） | Must |
