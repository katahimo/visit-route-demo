## 組み方の標準（標準の週。ADR-0062）

| ID | 要件 | 優先度 |
|---|---|---|
| D350 | **組み方の標準の画面**（`#/standard`。「組む」の子。段は D361）：標準の週（誰が・どの〈利用者さん〉へ・何曜・何時）を表で決める。表は行＝利用中の〈利用者さん〉の今日以降に続く繰り返し、列＝曜日、マス＝担当と開始（今の標準と違うマスは色と「担当変更」「時刻変更」の文字）。**案をくらべる**：プリセット（最大6つ）ごとに、来週の月曜から利用中の繰り返しの間隔の最大の週数（毎月の第N週があれば4週）の日を AI で組んで標準の表の案を作る。カードで点（点数の基準の物差し）・移動・担当なし・人ごとの件数の偏り・今の標準と違うマスの数を比べ、点のいちばん高いカードに王冠。［表で見る］で案の表を読み取り専用で見る。「日で見る」で期間の日を選び、タブ（今の標準と案ごと。点・担当が変わる件数。王冠）で切り替えて、選んだ案のその日を日の予定と同じ見せ方（担当ごとの時間軸。名前・訪問・区間を押すとその担当のルートを強調。下に全幅の地図、画面の外なら右下に浮かぶ地図。担当・時刻が変わる訪問に印）で見る。［この案から作る］で下書きへ。**標準にする**：下書き（［今の標準から作る］からも）のマスを押して担当（勤務中の〈スタッフ〉か担当なし）と時刻（その曜日の時間の約束の中だけ。空は時刻なし）を選び、上に今の標準と違う所の数、下で登録（D351）。案・下書き・作る途中の進み具合は画面の外に置き、ほかの画面へ移っても残す（読み直す・タブを閉じる・データの丸ごと差し替えで消える。データには入れない）。案を作ったあとに繰り返しが変わったら、違うマスの数は「—」、［この案から作る］は押せず作り直す案内。予定（訪問）には登録まで書かない。上に今の標準（いつから・考え方・周期・登録した日） | Should |
| D351 | **標準にする**（下書きがあるとき）：「いつから」（既定は来週の月曜。今日と伝えた日より前は選べない）を決め、確認のあと下書きの表で繰り返しを書き換える（1手。元に戻せる）。曜日で担当が違う繰り返しは曜日ごとに分ける。隔週などは周期をずらさない。「いつから」以降の伝えていない日の、書き換える繰り返しの保存した回は、この回だけ日時などを変えた回とピンの回は残し、新しい標準と同じ回は消す。新しい標準と違う回があれば件数を出し「標準どおりに入れ替える」（既定）か「今のまま残す」（今の担当でピン）を選ぶ。伝えた日の回は変えない。案から作った下書きならそのプリセットを点数の基準にする。標準がまだ無ければ違う所が無くても標準にできる（繰り返し・予定は変えず、登録の記録と点数の基準だけ書く）。標準があって違う所が無ければ押せず「今の標準と同じです」と、マスを直すか違う案から作る案内・予定に担当を入れるのは担当を組むからの案内。登録したら「M/D から毎週この表のとおりに並びます」と［週の予定で見る］ | Should |
| D352 | **標準の案はひな形**：組み方の標準の案は繰り返しから計算した回だけで作り、保存した回・単発の訪問の手直しとピンは効かせない。伝えた日も作ってよい（予定には書かない）。予定の画面では AI で組まない（日の予定の「担当なしの訪問」の列にドラッグで入れられることと［この日の担当を組む］（`#/arrange?date=`）の案内） | Should |
| D353 | **標準の開始**：繰り返しは曜日ごとに標準の開始を持てる。計算した回の組んだ開始はその曜日の標準の開始（無ければ開始（早）で並べる）。繰り返しの節・Excel の繰り返しの列で見て直せる | Should |
| D354 | **標準の入口**：標準が無い間は「組む」の子「組み方の標準」・予定を組むの段から、標準があれば担当を組むの［標準の組み方を変える］から開く。要対応の帯は標準が未登録なら「組み方の標準が無い」を出してこの画面へ向ける（D404）。担当を組むも標準が無い間はここへ案内する（D356）。見直し・ほかの曜日の手直しもこの画面 | Should |
