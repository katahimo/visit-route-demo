# PRD §3 要件：欠勤・キャンセル

共通の決まり・読み方・索引・廃止した D番号は [../prd.md](../prd.md) §3。各表は D番号の昇順。画面の細部は `docs/design.md`・`docs/design/`。

## 欠勤・キャンセル

| ID | 要件 | 優先度 |
|---|---|---|
| D26 | その日の**欠勤**（終日か30分単位の時間帯。早道：午前だけ・午後だけ（境12:00）・〇時から・〇時まで。メモ）を登録・直す・取り消す。1人1日1件、稼働時間の上書きとは別。稼働時間から差し引き、AI案・手直し・点数・理由に使う（ADR-0011） | Must |
| D27 | 振り直し（案A「空き時間に入れる」）：欠勤の人の**振り直す訪問**（欠勤と重なる訪問すべてと、欠勤明けに間に合わない訪問）だけを、**ほかの人の担当・順番・開始時刻を変えずに**空き時間へ。入れられる人の少ない訪問から（同点は regret の大きい順）、約束・稼働時間・必須・件数の上限を守るうち費用が最も増えない位置へ。1秒以内で決定的。入らない訪問は残す。「いまの時刻」は扱わない | Must |
| D28 | 振り直しと元の案（確定した割当、無ければ今の案）の**差**を差の欄で：「代行」「+N分」、変わらない人は薄く、まとめ（変わる人・振り直し・入らない・移動）、地図で強調。差の欄が画面外なら左下の帯と列の見出しから行ける。入らない訪問の理由と、欠勤の人に残る訪問の「対応が必要」 | Must |
| D29 | 入らなかった訪問ごとに**受けられる人の候補**（増える移動・約束を守れるか・違反・件数の上限・「〇分ずらせば入る」）。押すとその人に固定で入れる（時刻は変えず、守れなければ違反の赤枠）。後ろが遅れるなら「後ろの N件が遅れる」と出し、押したとき確かめる | Must |
| D31 | 欠勤を取り消しても案は戻らない。「元の案に戻す」で振り直す前へ（続けて振り直しても最初の元の案へ）。確定した割当を元にするとき、未確定の変更は確かめて捨てる | Must |
| D32 | 稼働時間の画面の欠勤の日のセルに「欠勤」の印（時間帯・メモ） | Should |
| D34 | 案B「少し動かしてよい」：焼きなましの費用に元の案からの変更の減点（「変更を減らす」0〜5・既定3。担当の変更1件＝移動 w×10分・ずれ1分＝w×0.2分）を足す。案A から始め、案A より悪くならず入らない訪問も増えない（でなければ案A のまま理由を出す）。点数に減点は入れず変更の数は別に出す。案A に入らない訪問があれば勧める。案A と並べ差（点数・入らない・担当の変更・時刻のずれ・移動）を比べて選ぶ（全部固定）。記録に残り、比較で 欠勤前／案A／案B | Should |
| D35 | 確定前でも**連絡の一覧**：担当が変わる〈利用者さん〉・時刻が変わる訪問・仕事が増える/減る〈スタッフ〉。人ごとの連絡文を1件ずつ・まとめてコピー（送信しない）。印刷すると一覧だけ | Should |
| D74 | 取り消すとき「**当日キャンセル**」かを選ぶ。月の見出しと〈利用者さん〉の右の欄に月の回数（請求はしない） | Should |
| D167 | 日の予定の操作の行の先頭に入口「欠勤・キャンセルを登録」（枠のボタン（D238。前は赤い縁）。主ボタンにせず、下のタブにも入れない）。訪問も働く人もいない日は押せない | Should |
| D168 | 入口で段階のある右の欄「欠勤・キャンセル」：1 起きたこと（〈スタッフ〉が休む／〈利用者さん〉がキャンセル／登録済みの欠勤）→2 休む人（訪問）→3 影響→4 確定→5 連絡（D243）。段階の表示と見出し、「戻る」（入力は残す）。種類を変えたら前の選択を消す。日付を変えると閉じる | Should |
| D169 | 〈スタッフ〉が休む：2段目で休む人と欠勤の入力（D26）、3段目で影響（入らなくなる訪問）と案A・案B の説明を見て、主ボタン「登録して振り直す（おすすめ）」・ほかのやり方（もう一方の案・「欠勤だけ登録」）・「欠勤を取り消す」（ボタンの並びは D264）。4段目で今の案のまとめ・担当が移る訪問の一覧（D265）・案B の欄・確定の状態・「この割当で確定」・「元の案に戻す」・「日の予定で差を見る」。確定済みの日は確定した割当を元にし確定し直しを促す。案の無い日は欠勤だけ。計算中は振り直し・登録・確定を押せない | Should |
| D170 | 〈利用者さん〉がキャンセル：2段目で取り消していない訪問と種類（既定は当日キャンセル）、3段目で影響（その時間が空く・ほかは変えない）を見て取り消す（定期パターンの訪問は「この回だけ」）。4段目で確定の状態と「この割当で確定」。空いた時間へ入れ直す計算はしない | Should |
| D171 | 列の見出しの「この人の欠勤を登録」「欠勤を直す」は同じ欄をその人の2段目で開く。一覧の行の「取り消す」は別の欄のまま | Should |
| D172 | ホーム・メニュー・パレットの「欠勤・キャンセルを登録」は、今日の日の予定でこの欄を1段目で開く（`#/plan?date=今日&do=absence`）。案が無ければ自動で作る | Should |
| D203 | 勤務時間（シフト）の右の欄に「この日の欠勤を登録する」（「直す・取り消す」）。その日の欄をその人の2段目で開く（`do=absence&staff=`）。その日に働く人だけ。元の画面の日付は変えない | Should |
| D244 | 5段目の**連絡の一覧**（ADR-0038）：確定し直した差（前の確定した割当、無ければ振り直す前の案 → 新しい割当）と、欄で取り消した訪問から、1人に1行（〈スタッフ〉→〈利用者さん〉の順）。種類は 担当が外れる・新しく入る・時刻が変わる・中止（キャンセルの担当あて）・〈利用者さん〉あて（担当・時刻が変わる）。キャンセルした〈利用者さん〉には作らない。各行に連絡文・［文をコピー］・〈スタッフ〉あてはメール（D94。アドレスが無ければ押せず理由）・［連絡した］のチェックと「連絡した N/M人」。［連絡した］はその場の状態だけでデータに残さず、文が変われば（確定し直したなど）印は消える。欠勤の人に残る訪問があれば上に「欠勤の人に残る訪問 N件」。キャンセルの差の「前」は取り消したときの確定した割当を振り直しの元の案と同じ並べ方（今の案の列の順）にしたもの、取り消した訪問の担当は確定があれば確定した担当だけ。送信はしない | Should |
| D245 | **連絡文のひな形**（ADR-0038）：〈スタッフ〉あては丁寧語の短文（「〈名前〉さん／10月21日（水）の予定の変更です。／・9:00 〇〇様の訪問は、△△さんに代わりました。伺わなくて大丈夫です。」「・14:00 〇〇様の訪問をお願いします（住所・60分）。」「・15:00 〇〇様の訪問は、開始が15:20に変わりました。」「・8:30 〇〇様の訪問は、中止です（キャンセル）。伺わなくて大丈夫です。」。行の頭は元の案の開始）。〈利用者さん〉あては敬語（「〇〇様／いつもお世話になっております。〈事業所名〉です。／10月21日（水）の訪問について、変更をお知らせいたします。／・9:00の訪問は、担当が△△に代わります。／・9:00〜9:30の間の訪問は、開始が9:20ごろに変わります（担当は変わりません）。／ご迷惑をおかけして申し訳ございません。どうぞよろしくお願いいたします。」。どの訪問かは見込みの時刻でなく約束の開始（時刻の指定は「9:00」、幅があれば「9:00〜9:30の間」）で書き、新しい開始は見込みなので「ごろ」）。日付は「本日」と書かず「10月21日（水）」、時刻は24時間で時の0を付けない（9:00）。文中の時刻の前後に空白を入れず、「〜様の訪問は、」と読点を打つ。今の時刻は見ず、過ぎた時刻の行も除かない（D27）。連絡の一覧（D35）の文も同じひな形 | Should |
| D246 | **連絡文に載せる範囲**（ADR-0038。個人情報を最小に）：〈利用者さん〉の住所・所要は〈スタッフ〉あての「お願いします」の行だけ（外れる・時刻・中止の行は名前と時刻だけ）。〈利用者さん〉あては担当の姓と時刻だけ（前の担当・ほかの〈利用者さん〉・住所・代わる理由（欠勤など）は書かない） | Should |
| D264 | **影響の段の主ボタンは1つ**（ADR-0044。D169 の3段目を置き換え）：主ボタンは「登録して振り直す（おすすめ）」の1つ。案A で入らない見込みなら案A を作ったあと案B も作り（おすすめは案B）、無ければ案A。案A・案B の説明カードは残し、おすすめの方に縁と札「おすすめ」、上に「おすすめ：…」の1行。もう一方（「案A だけで振り直す」または「登録して、案B も作る」）と「欠勤だけ登録（振り直さない）」は「ほかのやり方」に文字のボタン。振り直しの元の案が無い日（案の無い日・案を作っている間・見込みを出せない）は押せない振り直しのボタンを出さず、「欠勤だけ登録」を主ボタンにする（主ボタンは1つ）。「欠勤を取り消す」「戻る」は今どおり | Should |
| D265 | **確定の段に担当が移る訪問の一覧**（ADR-0044）：4段目のまとめの下に、担当が変わる訪問を1行ずつ（時刻と〈利用者さん〉の名前・元の担当 → 新しい担当。入らない訪問は「入らない（〇〇さんから外れる）」）。並びと行の時刻は訪問の受けられる時間帯の初め（最も早い開始）で、振り直したあとの開始時刻ではない。390px でも折り返して欄に収まる。案B の「変更を減らす」のスライダーと説明は「詳しく：変更を減らす（3.0・既定）」に畳む（差の欄の案B も同じ部品なので同じ。開いたかは保存しない） | Should |
