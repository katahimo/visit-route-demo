# PRD §3 要件：欠勤・キャンセル

共通の決まり・読み方・索引は [../prd.md](../prd.md) §3。画面の細部は `docs/design.md`・`docs/design/`。欄の段階と振り直しの書き方は D325。

## 欠勤・振り直し（ADR-0011）

| ID | 要件 | 優先度 |
|---|---|---|
| D26 | その日の**欠勤**（終日か30分単位の時間帯。早道：午前だけ・午後だけ（境12:00）・〇時から・〇時まで。メモ）を登録・直す・取り消す。1人1日1件、稼働時間の上書きとは別。稼働時間から差し引き、AI で組む・手直し・点数・理由に使う | Must |
| D27 | 振り直し（案A「空き時間に入れる」）：欠勤の人の**振り直す訪問**（欠勤と重なる訪問すべてと、欠勤明けに間に合わない訪問）だけを、**ほかの人の担当・順番・開始時刻を変えずに**空き時間へ。入れられる人の少ない訪問から（同点は regret の大きい順）、約束・稼働時間・必須・件数の上限を守るうち費用が最も増えない位置へ。1秒以内で決定的。入らない訪問は残す。「いまの時刻」は扱わない | Must |
| D28 | 振り直しと振り直す前の担当の**差**を差の欄で：「代行」「+N分」、変わらない人は薄く、まとめ（変わる人・振り直し・入らない・移動）、地図で強調。差の欄が画面外なら左下の帯と列の見出しから行ける。入らない訪問の理由と、欠勤の人に残る訪問の「対応が必要」 | Must |
| D29 | 入らなかった訪問ごとに**受けられる人の候補**（増える移動・約束を守れるか・違反・件数の上限・「〇分ずらせば入る」）。押すとその人にピンで入れる（時刻は変えず、守れなければ違反の赤枠）。後ろが遅れるなら「後ろの N件が遅れる」と出し、押したとき確かめる | Must |
| D31 | 欠勤を取り消しても担当は戻らない。「振り直す前に戻す」で振り直す前の担当へ（続けて振り直しても最初の担当へ。D329） | Must |
| D32 | 稼働時間の画面の欠勤の日のセルに「欠勤」の印（時間帯・メモ） | Should |
| D34 | 案B「少し動かしてよい」：焼きなましの費用に振り直す前からの変更の減点（「変更を減らす」0〜5・既定3。担当の変更1件＝移動 w×10分・ずれ1分＝w×0.2分）を足す。案A から始め、案A より悪くならず入らない訪問も増えない（でなければ案A のまま理由を出す）。点数に減点は入れず変更の数は別に出す。案A に入らない訪問があれば勧める。案A と並べ差（点数・入らない・担当の変更・時刻のずれ・移動）を比べて選ぶ。比較で欠勤前と並べられる（D317） | Should |
| D35 | 確定前でも**連絡の一覧**：担当が変わる〈利用者さん〉・時刻が変わる訪問・仕事が増える/減る〈スタッフ〉。人ごとの連絡文を1件ずつ・まとめてコピー（送信しない）。印刷すると一覧だけ | Should |
| D74 | 取り消すとき「**当日キャンセル**」かを選ぶ。月の見出しの要約に月の件数（D154。請求はしない） | Should |
| D296 | **差の欄で担当の変わった訪問を見る**：差の欄に、はじめ畳んだ「担当が変わった訪問を見る（N件）」。開くと欄の一覧（D265）と同じ形（1訪問1行「10:00 〈利用者さん〉：〇〇さん → △△さん」・入らない訪問は「入らない（〇〇さんから外れる）」）。変わる訪問が無ければ出さない。案を比べるを切っていても確かめられる。印刷では見出しを出さない | Should |

## 連絡（ADR-0038）

| ID | 要件 | 優先度 |
|---|---|---|
| D244 | 2段目（連絡・確定）の**連絡の一覧**：伝えた内容（無ければ振り直す前の担当）→ 今の担当の差と、欄で取り消した訪問から、1人に1行（〈スタッフ〉→〈利用者さん〉の順）。種類は 担当が外れる・新しく入る・時刻が変わる・中止（キャンセルの担当あて）・〈利用者さん〉あて（担当・時刻が変わる）。キャンセルした〈利用者さん〉には作らない。各行に連絡文・［文をコピー］・〈スタッフ〉あてはメール（D94。アドレスが無ければ押せず理由）・［連絡した］のチェックと「連絡した N/M人」。［連絡した］はその場の状態だけで残さず、文が変われば印は消える。欠勤の人に残る訪問があれば上に「欠勤の人に残る訪問 N件」。キャンセルの差の「前」は取り消したときの伝えた内容（今の担当の列の順）、取り消した訪問の担当は伝えた担当だけ。送信はしない | Should |
| D245 | **連絡文のひな形**：〈スタッフ〉あては丁寧語の短文（「〈名前〉さん／10月21日（水）の予定の変更です。／・9:00 〇〇様の訪問は、△△さんに代わりました。伺わなくて大丈夫です。」「・14:00 〇〇様の訪問をお願いします（住所・60分）。」「・15:00 〇〇様の訪問は、開始が15:20に変わりました。」「・8:30 〇〇様の訪問は、中止です（キャンセル）。伺わなくて大丈夫です。」。行の頭は振り直す前の開始）。〈利用者さん〉あては敬語（「〇〇様／いつもお世話になっております。〈事業所名〉です。／10月21日（水）の訪問について、変更をお知らせいたします。／・9:00の訪問は、担当が△△に代わります。／・9:00〜9:30の間の訪問は、開始が9:20ごろに変わります（担当は変わりません）。／ご迷惑をおかけして申し訳ございません。どうぞよろしくお願いいたします。」。どの訪問かは約束の開始（時刻の指定は「9:00」、幅があれば「9:00〜9:30の間」）で書き、新しい開始は見込みなので「ごろ」）。日付は「本日」と書かず「10月21日（水）」、時刻は24時間で時の0を付けない（9:00）。時刻の前後に空白を入れず、「〜様の訪問は、」と読点。今の時刻は見ず、過ぎた時刻の行も除かない（D27）。連絡の一覧（D35）の文も同じ | Should |
| D246 | **連絡文に載せる範囲**（個人情報を最小に）：〈利用者さん〉の住所・所要は〈スタッフ〉あての「お願いします」の行だけ（初めての訪問先なら決まりごとも。D415。外れる・時刻・中止の行は名前と時刻だけ）。〈利用者さん〉あては担当の姓と時刻だけ（前の担当・ほかの〈利用者さん〉・住所・代わる理由は書かない） | Should |
