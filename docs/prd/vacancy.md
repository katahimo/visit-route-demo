# PRD §3 要件：空き状況・問い合わせ

共通の決まり・読み方・索引は [../prd.md](../prd.md) §3。画面の細部は `docs/design.md`・`docs/design/`。

## 空き状況・問い合わせ（ADR-0012）

| ID | 要件 | 優先度 |
|---|---|---|
| D45 | **空き状況の表**（曜日×30分刻み。「詳しく ▾」の中。D412）：その時刻から〈所要〉分の訪問を受けられる人数（勤務から訪問と移動を引いた空き。先4週の今の担当から）。種類・所要・条件（特性）で絞る | Must |
| D46 | **問い合わせの試算**：新しい〈利用者さん〉の場所・種類・所要・希望の曜日と時間帯・週の回数・開始日から、曜日×開始時刻ごとに先4週の今の担当へ移動込みで入るか（○ すべての週・△ 入らない週あり（日付）・× 入らない）と入れられる人。担当は変えない（ほかを動かさず空き時間に入れて判定）。要約（「火・木の 10:00〜11:30 なら対応できます」）をコピー | Must |
| D47 | 試算から**仮の〈利用者さん〉と定期パターン**を登録して押さえる（相談受付・仮押さえ。本登録・取り消し） | Should |
| D67 | 期間（今週／来週／先4週）と種類で**空き枠の案内文**（事業所名入り）を作りコピー。今週・来週は日付ごと、先4週は毎週続けて受けられる曜日ごと。数えられない日は入れず画面で知らせる | Must |
| D79 | 試算の結果に希望の曜日×週のマス（「詳しく ▾」の中。D412。行＝一番良い開始時刻と判定、マス＝その日受けられる人数） | Should |
| D184 | 空き状況の画面（`#/vacancy`）を段階で上から：1 いつ・何を（チップ3つと「くわしい条件 ▾」。D411。入れると 300ms 後に下を計算）→2 場所（任意。D118〜D121）→3 答え（見出しに「目安。移動を前後15分で見込む」か「〈場所〉への移動を含む」・答えのカードと［要約をコピー］・「詳しく ▾」に D79・表・凡例。D412）→4 次の一手（仮押さえ・案内文・紹介元へメール） | Should |
| D185 | 入っていない段階は畳むか要約の行に（場所ははじめ畳む。案内文・メールは4段目で畳む）。畳んでも入力は消さない。案内文は開いているときだけ計算し、計算し直すまでコピー・メールを押せない | Should |
| D186 | 主ボタンは答えのカードの中の「要約をコピー」だけ（D412）。仮押さえできないときは理由を出す | Should |
| D187 | 記号：○ どの週も受けられる（人数。目安は「約」）・△ 受けられない週がある（a/b 週）・× 受けられない・？ 数えていない（×・？は数字なし）。凡例（「詳しく ▾」の中。D412）と用語の説明 | Should |
| D204 | 右の欄の日ごとの結果に、日付ごとに「その日の予定を見る」（`/plan?date=…`） | Should |
| D258 | **空き状況の答えを1枚目に**：結果の先頭に答えのカード（「受けられます：火・木 10:00〜12:00 に 3人」。週の回数に足りない・受けられない週がある・受けられない・数えられないも同じ形。時刻は開始の時刻、人数はどの週でも受けられる人数の幅）。凡例（印・色・数字の読み方）は「詳しく ▾」の中の1か所（D412）。種類を選ばないときは「指定なし」（要約の行は「種類の指定なし」）。入力（条件・場所・曜日・時間帯・案内文の期間と種類）はタブの間だけ覚える（sessionStorage。データ・書き出しには入れない） | Should |
| D411 | **空き状況はチップ3つで聞く**（入切とも。ADR-0080）：段階1は 曜日（D46 の希望の曜日。選ばなければどの曜日でも）・時間帯（指定なし／午前 8:00〜12:00／午後 12:00〜17:00／夕方 17:00〜20:00。複数可。開始の時刻の幅）・所要（30／45／60／90分）のチップ。種類・週の回数・開始日・週数・開始の幅（30分刻み）・所要のほかの分・必要な条件は「くわしい条件 ▾」（閉じて始める。既定はいまの既定）。くわしい条件で開始の幅を変えたら時間帯は「指定なし」に戻す。入力の覚え方は D258 | Must |
| D412 | **答えのカードでコピー**（入切とも。ADR-0080）：答えのカード（D258）を結果の一番上に置き、カードの中に主ボタン［要約をコピー］（D186）。曜日×時刻の表（D45）・希望の曜日×週のマス（D79）・凡例（D187）は「詳しく ▾」（`components/DetailsFold`。閉じて始め、開閉は `details:vacancy` で端末に覚える）。次の一手（仮押さえ・案内文・紹介元へメール）はカードの下 | Must |
