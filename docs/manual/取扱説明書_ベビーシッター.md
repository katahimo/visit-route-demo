# この説明書について

訪問ルートAI は、「どのシッターが、どのお客様のお宅へ行くか」を決めるためのアプリです。
ブラウザで開いて使います。インストールやログインはありません。

この説明書では、今お使いの予約システムから書き出した3つの CSV ファイル
（**顧客**・**スタッフ**・**予約**）を読み込み、日ごとの予約に担当を付けるまでを順に説明します。
急な欠勤やキャンセルのときの使い方も説明します。

- 公開先：<https://staff-assign-demo.katahimo.com/>
- おすすめの環境：パソコンの Chrome か Edge（画面の幅 1280 以上）。スマホでも予定の確認と担当の変更はできます
- 説明に使うデータ：`samples/ベビーシッター_顧客_サンプル.csv`・`samples/ベビーシッター_スタッフ_サンプル.csv`・`samples/ベビーシッター_予約_サンプル.csv`
  （予約システムから書き出した CSV と同じ列・同じ形です。人の名前・電話・メールはすべて架空で、住所は仙台市の公共施設です）

> **大切なお願い（デモ版について）**
>
> - 入れたデータは、このパソコンの中（ブラウザの中）だけに置かれます。外へは送りません
> - ただし、名簿を読み込んだあとと、地図の場所を探すボタン（［住所から探す］［住所を探す］など）を押したときだけ、
>   郵便番号と住所を、場所を調べるサービスへ送ります。名前などほかの項目は送りません
> - このデモ版は、お試しのためのものです。実在のお客様の名前や住所を入れる前提では作っていません。
>   お試しの間は、この説明書のサンプル CSV か、名前と住所を置き換えた CSV をお使いください

# 1. 困りごとと、このアプリでできること

伺った困りごとと、アプリでの対応を並べました。詳しい手順は、右の欄の章にあります。

| 困りごと（今のやり方） | このアプリでは | 章 |
|---|---|---|
| 日ごとに入る予約に、だれが行くかを毎回考えている | 予約の CSV を読み込むと、予約が「担当なし」の訪問として入ります。予定の画面の［要対応を組む］で、担当を自動で付けます | 3・5 |
| シッターは直行直帰。家からの近さ・性別・相性で選んでいる | シッターの自宅とお客様のお宅の緯度・経度を入れ、近さを見て組みます。**性別の求め** と **相性**（× 担当にしない など）を入れておけば、それを守ります | 4 |
| 予約システムと、同じことを二度入力したくない | 予約システムの「顧客」「スタッフ」「予約」の CSV を、列を直さずに読み込めます。パスワードやユーザーID などの列は読みません | 3 |
| 予約の日時が変わる。キャンセルも入る | 同じ予約番号の予約は、読み直すと日時を直します。二重には入りません。キャンセル済みの予約は入れません | 6 |
| シッターの急な欠勤のたびに、代わりを探して連絡している | ［欠勤・キャンセルを登録］で休む人を選ぶと、代わりの案が出ます。決めたあと、人ごとの連絡文をコピーできます | 7-1 |
| お客様の当日キャンセルがある | 訪問を「当日キャンセル」として取り消すと、その時間が空きます。回数も数えます | 7-2 |
| シッターが辞めるとき、先の予約の担当を替える | スタッフの CSV の **退職日** を「最終勤務日」として読みます。翌日からは担当に入りません | 7-3 |
| 新しい依頼に応えられるか、その場で分からない | **空き状況** の画面で、曜日・時間帯・所要を選ぶと、受けられる時間と人数の目安が出ます | 7-4 |

次のことは、このデモ版ではできません（9章）。

- 料金の決済・請求
- 予約の受け付け（予約は今お使いの予約システムで受けます）
- シッターへの自動の連絡（連絡文はコピーして、人が送ります）
- 勤怠の記録

# 2. はじめる前に

## 2-1 最初の設定（2つの質問）

初めて開くと「最初の設定」の画面が出ます。

1. 「1. どちらで始めますか」で、**自分のデータで始める** を選びます
   （動きだけ見たいときは **デモで試す** を選びます。架空のデータが入った状態で始まります）
2. 「2. 使い方の近いものはどれですか」で、**単発の予約**（例：ベビーシッター）を選びます
3. ［はじめる］を押します

画面の呼び方は「**お客様**」「**シッター**」になります。
左のメニューは **予定・空き状況・お客様・シッター・設定** の5つです（スマホは下のタブ）。

「自分のデータで始める」を選ぶと、次に「登録の案内」の画面が開きます（3章）。
答えを選び直したいときは、登録の案内の画面の下の［始め方を選び直す］を押します。

## 2-2 最初から入っている機能

「単発の予約」を選ぶと、次の機能が入った状態で始まります。設定を変える必要はありません。

| 機能 | 使う場面 |
|---|---|
| Excel の入出力 | CSV を読み込む（3章・6章） |
| 郵便番号・住所の検索 | お客様のお宅の緯度・経度を入れる（3章・4章） |
| 相性 | 合わない組み合わせを避ける（4章） |
| 欠勤・キャンセル | 急な欠勤・当日キャンセル（7-1・7-2） |
| 退職・担当替え | シッターが辞めるとき（7-3） |
| 空き状況 | 新しい依頼への答え（7-4） |
| お客様の休み | 入院や帰省などで、しばらく予約が無い期間を入れる |
| 道順のリンク | 訪問先への道順を Google マップで開く |

定期の訪問で使う「繰り返し」「毎月の第N曜日」「訪問先の決まりごと」は入っていません。
単発の予約では使わないので、画面から隠してあります。

## 2-3 前のデータが残っているとき

前にこのアプリを開いたことのあるパソコンでは、前のデータと設定が残っています。
その場合、最初の設定の画面は出ません。

- **空のデータから始め直すとき**
  1. **設定 › データ** を開きます
  2. 一番下の「最初からやり直す」の［始め方を選び直す］を押します
  3. 確かめる画面で［2つの質問へ戻る］を押します
  4. 2-1 の2つの質問に答えます

  今のデータは消えます。要るデータがあれば、先に控えを書き出してください（8章）。

- **データはそのままで、機能だけそろえるとき**
  1. **設定 › 管理者設定** を開きます
  2. 「ひな形」の［詳しく ▾］を開きます
  3. 「単発の予約」の［適用］を押します
  4. 確かめる画面で、入る機能・切れる機能を見て［適用］を押します

  機能を切っても、入れたデータは消えません。画面から隠れるだけです。

# 3. 3つの CSV を読み込む

## 3-1 読み込む順番

「登録の案内」の画面は、上に「1/3」「2/3」「3/3」と出る3段の画面です。次の順で読み込みます。

| 段 | 画面の見出し | 読み込む CSV |
|---|---|---|
| 1/3 | ① お客様の名簿を読み込む | 予約システムの **顧客** の CSV |
| 2/3 | ② シッターの名簿を読み込む | 予約システムの **スタッフ** の CSV |
| 3/3 | ③ 予定を登録する | 予約システムの **予約** の CSV |

**お客様を先に** 読み込んでください。予約は、お客様の名前で突き合わせて入れます。
お客様が入っていないと、予約を入れられません。

> 「登録の案内」の画面を閉じてしまったときは、
> お客様は **お客様** の一覧の［Excel・CSV］、シッターは **シッター** の一覧の［Excel・CSV］、
> 予約は **設定 › データ** の「予約の CSV」から読み込めます。中身は同じです。

## 3-2 ① お客様の名簿を読み込む（顧客の CSV）

1. ［CSV・Excel を読み込む］を押します（まだ1人もいないので、「名簿の読み込み方」の選択肢は出ません。追加・更新で読み込みます）
2. ［ファイルを選ぶ］を押し、`ベビーシッター_顧客_サンプル.csv` を選びます
3. 「お客様の名簿を読み込みますか？（追加・更新）」と出ます。次のことを確かめます
   - 読んだ形：「**予約システムの顧客** の形の CSV ファイルを読みました。」
   - 読まなかった列：「読まなかった列：メールアドレス・国番号・会員種別・…」
   - 人数：「追加 5人（市役所 あかり・資料館 ゆい・野草園 れん ほか）・更新 0人・変更なし 0人・終了にする 0人」
   - 最後の行：「読み込んだあと、住所から緯度・経度を探します（住所を郵便番号の検索と国土地理院の地図の検索に使います）」
4. ［名簿を読み込む］を押します
5. 続けて、緯度・経度が未登録の3人の分を、住所から探して入れます。
   「終わりました：3／3人（入れた 3人・見つからない 0人）」と出たら終わりです（4-1）
6. 画面に「いま登録されているのは 5人です」と出ます。［次へ］を押します

### 顧客の CSV の列の読み方

| 顧客の CSV の列 | アプリでは |
|---|---|
| 姓・名 | 名前（あいだに空白を1つ入れます。例：「市役所 あかり」） |
| 姓（カナ）・名（カナ） | よみ（ひらがなにして入れます。名前を探すときに使います） |
| 住所 | 住所。先頭の郵便番号は、郵便番号の欄に分けます |
| 緯度・経度 | 緯度・経度（入っていれば、そのまま入ります） |
| 電話番号 | メモの1行目（「電話 080-…」） |
| 顧客メモ | メモ（電話の次の行） |
| 会員状況（有効／無効） | 「無効」なら **終了**（予定に入りません）。それ以外は利用中 |
| 駐車場・駐車場番号など | 駐車場のメモとして残します（単発の予約では画面に出しません） |
| 顧客ID | 同じ名前の人がいるときだけ、「名前（顧客ID）」として分けるのに使います |
| メールアドレス・会員種別・会費・パスワード・性別・年代・緊急連絡先・世帯全員の情報・住所2 など | **読みません**（アプリに残しません） |

世帯の情報（お子さんのアレルギーなど）は読みません。
シッターに伝えたいことは、顧客メモに書いておくと、メモとして入ります。

## 3-3 ② シッターの名簿を読み込む（スタッフの CSV）

1. ［CSV・Excel を読み込む］を押します
2. ［ファイルを選ぶ］を押し、`ベビーシッター_スタッフ_サンプル.csv` を選びます
3. 「シッターの名簿を読み込みますか？（追加・更新）」と出ます。次のことを確かめます
   - 読んだ形：「**予約システムのスタッフ** の形の CSV ファイルを読みました。」
   - 読まなかった列：「読まなかった列：TEL・入社日・ユーザーID・パスワード(暗号化)・管理者・…・性別」
   - 人数：「追加 4人（県庁 ことね・公民館 みのり・ホール みずき ほか）・…」
   - 勤務：「勤務する曜日・時間の列が無い 4人は、既定（毎日 7:00〜22:00）にしました。シッターの画面の勤務時間で直せます」（4-2）
4. ［名簿を読み込む］を押します
5. サンプルでは、「シッターの名簿を読み込みました。最終勤務日の入ったシッターがいます。…」と出ます。
   「ミュージアム あやめ」さんの退職日（2026年12月20日）が入っているためです（7-3 で使います）
6. ［次へ］を押します

サンプルのシッターは、CSV に自宅の緯度・経度が入っています。そのため、住所から探すことはしません。
緯度・経度の無いシッターがいるときは、お客様と同じように、読み込んだあとに自宅の緯度・経度を探します。

### スタッフの CSV の列の読み方

| スタッフの CSV の列 | アプリでは |
|---|---|
| 氏名 | 名前（同じ名前の人がいれば「氏名（ID）」で分けます）。氏名が空の行は飛ばします |
| 住所 | 自宅の住所（直行直帰の出発点） |
| 緯度・経度 | 自宅の緯度・経度 |
| mail address | メールアドレス（連絡文をメールで開くときに使います） |
| 退職日 | **最終勤務日**（翌日から担当に入りません）。今日より前に辞めた人は **休止** で入ります |
| TEL・入社日・ユーザーID・パスワード・管理者・性別 など | **読みません**（アプリに残しません） |

性別の列は読みません。性別は 4章で、アプリの中で入れます。

## 3-4 ③ 予定を登録する（予約の CSV）

1. 「予約の CSV」の欄の［ファイルを選ぶ］を押し、`ベビーシッター_予約_サンプル.csv` を選びます
2. 「訪問を読み込みますか？」と出ます。次のことを確かめます
   - 読んだ形：「「ベビーシッター_予約_サンプル.csv」を訪問として読み込みます（**予約システムの予約** の CSV）。」
   - 件数：「追加 11件・更新 0件・変更なし 0件」
   - キャンセル：「取り消し済みで、まだ入れていない 1件は入れません。」
     （サンプルの予約番号 R90006 は、状況が「キャンセル」です）
   - 読まなかった列：「読まなかった列：予約種類・支払金額（合計）・消費税・オプション・…・住所・…」
   - 「担当は空のままです。」
3. ［読み込む］を押します
4. 「訪問を読み込みました（追加 11件・更新 0件）。担当は予定の上の要対応の帯の「要対応を組む」で組めます」と出ます
5. 画面の下に「いま登録されている訪問は 11件です」と出ます

ここで、予約はまだ **担当なし** です。担当は 4章の確認のあと、5章で付けます。

### 予約の CSV の列の読み方

| 予約の CSV の列 | アプリでは |
|---|---|
| 予約番号 | 予約の見分け（読み直したとき、同じ予約番号の訪問を直します） |
| 予約日 | 訪問の日 |
| 予約時 | 始まる時刻（「AM枠 10:00～12:00」なら 10:00） |
| 所要時間(分) | 訪問の長さ。空なら、予約時の終わりの時刻から数えます |
| 氏名 | どのお客様の予約か（お客様の名前と突き合わせます） |
| 状況 | 「キャンセル」「取消」などの言葉があれば、取り消しの予約として扱います |
| メニュー名 | 訪問のメモ |
| 予約種類・支払金額・消費税・オプション・新規登録者・住所 など | **読みません** |

訪問先の住所は、予約の CSV からではなく、お客様の住所を使います。

### 入らなかった予約があるとき

確かめる画面に、次のような行が出ることがあります。

| 出る文 | わけ | 直し方 |
|---|---|---|
| 入れなかった行（お客様に名前が無い・同じ名前が2人以上）：〇〇（2件） | 予約の氏名と同じ名前のお客様がいない。または、同じ名前の人が2人いて、どちらか分からない | 顧客の CSV を読み込み直してから、予約の CSV をもう一度読み込みます。同じ名前の人は、予定の画面から1件ずつ入れます（5-3） |
| 読めなかった行：5行目：予約日「…」が日付として読めません | 日付・時刻・所要時間が読めない | 予約システムの中で直して、書き出し直します |
| 日をまたぐ予約は入れられません | 夜から翌朝までの予約 | 日ごとに分けて、予定の画面から入れます |

入らなかった予約のほかは、そのまま入ります。

# 4. 読み込んだあとに確かめること

担当を付ける前に、次の4つを確かめます。

## 4-1 お客様のお宅の緯度・経度が入ったか確かめる

アプリは、シッターの自宅とお客様のお宅の近さを見て担当を選びます。
緯度・経度が無いお客様は、名簿を読み込んだあとに、住所から自動で探して緯度・経度を入れます（3-2）。

探す前の確かめる画面に「読み込んだあと、住所から緯度・経度を探します」と出ます。
このとき、郵便番号と住所を外へ送ります。名前などほかの項目は送りません。

見つからなかった人がいたら、次のように直します。

1. メニューの **お客様** を開きます
2. 一覧の上の絞り込みの **緯度・経度なし** を押します。緯度・経度の無い人だけが並びます。行には「緯度・経度なし」の印が付きます
3. 住所を直したときは、行の［住所から探す］を押します。その人だけ、もう一度探します
4. 地図を押して入れるときは、行の［緯度・経度を編集］を押します。お客様の画面の住所の欄が開くので、地図を押して入れます

探している途中で［止める］を押したときは、一覧の上の［続きを探す（N人）］で続けます。
市区町村の名前が無い住所は、見つからないことがあります。

緯度・経度が無いままでも、担当は付けられます。そのときは、その人への移動を30分とみて組みます。

遠くのお客様（新幹線で行くお宅など）は、距離から見積もると移動が長くなりすぎて担当が付きません。お客様の画面の住所の欄で **移動時間（片道・分）** に分数を入れると、そのお宅への行き帰りはその分数とみます。**遠方（出張）** に印を付けると、その予約がある日は、担当のシッターにほかの予約を入れず、予約を押して開く詳細に「家を出る目安」が出ます。

## 4-2 シッターの勤務する曜日と時間

CSV から入ったシッターは、最初は **毎日（月〜日）・7:00〜22:00** です（勤務する曜日・時間の列が無いとき。名簿の確認に「勤務する曜日・時間の列が無い N人は、既定（毎日 7:00〜22:00）にしました」と出ます）。
この曜日と時間の外には、担当を付けません。実際の勤務に合わせて、1人ずつ直してください。

予約の CSV を読み込むときは、確認に「N件はどのシッターの勤務日・時間にも入りません（例：11/5（木）17:00〜20:00）。シッターの勤務時間を広げると組めます」と出ることがあります。そのときは、下の手順で勤務時間を広げてから組みます。

1. メニューの **シッター** を開き、一覧で人を押します
2. **勤務時間** のタブを開きます
3. 「ふだんの勤務」で、**勤務する曜日**・**勤務開始**・**勤務終了** を直して保存します

その日だけ時間が違う日や、前から決まっている休みも、同じ **勤務時間** のタブで入れられます。

## 4-3 性別

予約システムの CSV の性別は読みません。そのため、CSV から入ったシッターの性別は「未確認」です。
「女性のシッターを必ず」と決めたお客様には、性別が未確認の人は付きません。

- **シッターの性別**：シッターの画面の **基本情報** の「特性」（［詳しく ▾］の中）で、**性別** を選びます
- **お客様の求め**：お客様の画面の **基本情報** の「シッターに求めること」（［詳しく ▾］の中）で入れます

| 伺った言い方 | 入れる所 | 組み方 |
|---|---|---|
| 女性のシッターを必ず | **必要条件** の「性別」で女性 | 合わない人は担当にしません |
| できれば女性 | **希望** の「性別」で女性 | 合わない人は選ばれにくくなります（ほかに人がいなければ入ります） |

## 4-4 相性

**お客様**（または **シッター**）の画面の上の **相性** のタブを開きます。
行がお客様、列がシッターの表です。マスを押して選びます。

| 伺った言い方 | 選ぶ印 |
|---|---|
| この組み合わせは合わない | **× 担当にしない** |
| できれば避けたい | **△ 選ばれにくい** |
| とくに決まりはない | 未入力（ふつう） |
| 相性がよい・指名がある | ○ やや選ばれやすい／◎ 選ばれやすい |

相性は、伺ってみて分かることが多いです。分かったときに直してください。次に担当を組むときから使います。

# 5. 担当を決める

## 5-1 要対応を組む（担当を自動で付ける）

1. メニューの **予定** を開きます
2. 予定の画面（週・日・月のどれでも）の上に、「**要対応** 担当なし 11件」の帯が出ます
3. 帯の右の［要対応を組む］を押します
4. 組み終わると「〇件の担当を組みました」と出ます。担当が付いた訪問は、シッターの名前で並びます

組んだ結果を取りやめたいときは、出てきた知らせの［元に戻す］を押します。

［要対応を組む］が組むのは、**今日から来月末まで** の訪問です。
担当なしのほか、「間に合わない」「重なり」「休みの人」の訪問も組み直します。ほかの訪問の担当は動かしません。

組むときに守ること・よくすること：

- 必ず守る：シッターの勤務する曜日・時間・休み・最終勤務日、お客様の必要条件（性別など）、相性の「× 担当にしない」
- よくする：移動の近さ（自宅や前の訪問先からの距離）、希望、相性、受け持ちのかたよりの少なさ

## 5-2 残った要対応を1件ずつ見る

担当を付けられなかった訪問は、帯に残ります（例：「担当なし 1件」）。

1. 帯の［見に行く ›］を押します。その訪問のある日の予定が開きます
2. 2件目からは「1/3」のように位置が出ます。［‹ 前へ］で戻れます


担当なしの訪問には、組めない理由が出ます。

- 帯：「（担当なしの理由：勤務時間外 6・勤務日外 5）」のように、理由ごとの件数
- 組んだあとの知らせ：「66件の担当を組みました。担当なしのまま 11件（勤務時間外 6・勤務日外 5）」と［理由を見る］
- 訪問の詳細（［見に行く ›］［理由を見る］で開きます）：上の方の「組めない理由」の枠に、短い理由・人数の内訳・直し方と、直す画面へのボタン
- 日の予定：担当なしの訪問の下に「組めない理由：勤務時間外 9人・欠勤 2人」

| 理由 | どういうとき | 直し方（枠のボタン） |
|------|--------------|----------------------|
| 勤務日外 | その曜日に勤務するシッターがいない（土日など） | シッターの勤務する曜日を足すか、勤務時間（シフト）でその日だけの勤務を足す |
| 勤務時間外 | 勤務の時間に訪問が収まらない（例：勤務 9:00〜18:00、訪問 17:00〜20:00） | 勤務の終わりを 20:00 以降にする（枠に時刻が出ます） |
| 欠勤・最終勤務日の後 | 入れる人が休み・辞めたあと | 勤務時間（シフト）・シッターの画面で直すか、ほかの人の勤務を足す |
| 担当できる人の限定 | お客様の「担当できる人」で絞った人が入れない | お客様の画面の担当できる人を足す |
| 必須の条件・相性× | 性別・資格などの必須の条件に合う人がいない、相性が × | お客様の条件・シッターの項目・相性の表を見直す |
| 重なり・1日の上限 | 入れる人は、その時間に別の訪問が入っている | 時間をずらす・人を足す・ほかの訪問を動かす |
| 移動が間に合わない・遠方（出張）の日 | 遠くて、勤務の始めに家を出ても間に合わない | ［移動時間・遠方を設定］でお客様の「移動時間（片道・分）」と「遠方（出張）」を入れる（例：東京へ新幹線で行くなら 片道 120〜180分、遠方（出張）に印） |
| 位置なし | 緯度・経度が無く、移動を30分とみると間に合わない | 緯度・経度を入れる |
| 入れられる人あり | 入れられる人はいるが、ほかの訪問との兼ね合いで外れた | 「担当を替える」で選ぶか、もう一度［要対応を組む］ |

担当を手で替えるときは、日の予定で訪問を押し、［担当を変える］から「ほかのシッターへ移す」の人を選びます。
手で替えた担当は、あとの自動の組みでは変わりません。

付かなかったときによくあるわけ：

- その曜日・時間に勤務するシッターがいない（4-2）
- お客様の必要条件に合うシッターがいない（4-3）
- 相性がすべて「× 担当にしない」（4-4）

## 5-3 予約を1件ずつ足す

電話で受けた予約などを、予定の画面から1件ずつ入れられます。

1. **予定** の週か月の画面で、［予約を追加］を押します
   （日の画面では、ボタンが［訪問を1件追加］になります。その日の訪問を1件足せます）
2. 右に出た欄で、**お客様**・**日付**・**時刻**・**所要（分）** を入れます
3. ［追加］を押します
4. 「予定を入れました（…・担当を自動で組みます）」と出て、その訪問に担当が付きます

予約システムでも同じ予約を受けている場合は、6章の読み直しで二重にならないよう、どちらか一方で入れてください。

## 5-4 予定の見方

- **週**：シッターごと・お客様ごとの時間の流れで見ます。帯をつかんで動かすと、日時を変えられます
- **日**：シッターごとの列と地図で見ます。訪問と訪問の間（家との行き帰りも）には、移動の分数が点線と小さな字で出ます（緯度・経度が無い所は「30分（見込み）」、着く時刻が間に合わない所は三角の印）。訪問を押すと、「ここへ道案内」（Google マップ）が出ます
- 操作の行の［元に戻す］［やり直す］（矢印のアイコン）で、ひとつ前に戻す・やり直すができます
- **月**：1日1マスで、訪問の数と要対応の数を見ます

担当や時刻があとで変わった訪問には、黄色い「**変更あり**」の印が付きます。
日の予定の連絡の一覧に、連絡の要る人が並びます。連絡したら「連絡した」を押してください。

# 6. CSV を読み直すとき

予約システムで予約が増えたり変わったりしたら、予約の CSV を書き出して、もう一度読み込みます。

## 6-1 予約の CSV を読み直す

次のどちらかから読み込みます。

- **予定** の週か月の画面の［予約を追加］→ 欄の下の「CSV でまとめて追加」→［ファイルを選ぶ］
- **設定 › データ** の「予約の CSV」→［ファイルを選ぶ］

読み直したときの動き：

| 予約の様子 | アプリでは |
|---|---|
| 新しい予約 | 担当なしの訪問として足します（「追加」） |
| 同じ予約番号で、日付・時刻・所要・メニュー名が変わった | 訪問を直します（「更新」）。担当はそのまま残します |
| 同じ予約番号で、何も変わっていない | そのままです（「変更なし」） |
| 前に入れた予約が、キャンセルになった | 訪問を取り消します（「更新」） |
| まだ入れていない予約が、もうキャンセル済み | 入れません（「取り消し済みで、まだ入れていない N件は入れません。」） |
| CSV に無い予約（書き出す期間の外など） | 消さずに、そのまま残します |

- 同じ予約番号の予約は直すだけなので、何度読み込んでも **二重には入りません**
- 日時が変わった訪問は、担当の都合が合わなくなることがあります。読み直したら、予定の上の要対応の帯を確かめて、［要対応を組む］を押してください
- アプリで取り消した訪問は、CSV で「予約確定」のままでも、取り消したままです（CSV では元に戻せません）

## 6-2 お客様・シッターの CSV を読み直す

新しいお客様やシッターが増えたら、顧客・スタッフの CSV を読み直します。

1. **お客様**（または **シッター**）の一覧の［Excel・CSV］を押します
2. 「名簿の読み込み方」は **追加・更新（ファイルに無い人はそのまま）** のままにします
3. ［ファイルを選ぶ］で CSV を選び、確かめて［名簿を読み込む］を押します

- 名前で同じ人を見分けます。変わったところだけ直し、新しい人は足します
- 名前が変わった人は、別の人として足されます。先にアプリで名前を直してから読み込んでください
- 訪問の担当・相性・勤務時間は、読み直しても変わりません
- CSV で空になっている住所・緯度・経度・メールアドレスは、今の値を残します

## 6-3 読み込みを取り消したいとき

CSV を読み込む前のデータは、1つだけ控えてあります。
ファイルを取り違えたときは、**設定 › データ** の［直前の状態に戻す］で戻せます。

# 7. 場面別の使い方

## 7-1 シッターが急に休む

朝、「子どもが熱を出したので休みます」と連絡があったとき。

1. 予定の画面の［欠勤・キャンセルを登録］を押します
2. 「休み・キャンセルを選ぶ」で **シッターが休む** を選びます
3. 「休む人」で、その人を選びます
4. 時間を選びます（終日・午前だけ・午後だけ・時間帯）
5. 「入らなくなる訪問 N件」と、おすすめの案が出ます
   （例：「おすすめ：空き時間に入れます（案A。ほかの人の担当・順番・時刻は変えません）」）
6. ［この案で決める］を押します。欠勤の登録と、代わりの担当が一度に入ります
7. 「変更を伝えて確定する」に、連絡が要る人ごとの文が出ます。［文をコピー］を押し、LINE などに貼って送ります
8. 送ったら「連絡した」に印を付けます
9. ［終わる］を押します

決めたあとで戻したいときは、［振り直す前に戻す］を押します。
その日にまだ担当の付いた訪問が無いときは、［欠勤だけ登録（振り直さない）］で休みだけを入れます。

## 7-2 お客様がキャンセルする

1. 予定の画面の［欠勤・キャンセルを登録］を押します
2. 「休み・キャンセルを選ぶ」で **お客様がキャンセル** を選びます
3. 「訪問」で、取り消す訪問を選びます
4. 「取り消しの種類」を選びます
   - **当日キャンセル**（その日になって、お客様の都合で取りやめ）
   - **ふつうの取り消し**（前もって決まった予定の変更など）
5. ［当日キャンセルとして取り消す］（ふつうの取り消しなら［取り消す］）を押します
6. 担当のシッターへの連絡文が出ます。［文をコピー］して送ります

その時間は、担当の予定から外れて空きます。ほかの訪問は変わりません。
当日キャンセルは、月の予定とお客様ごとの月の集計に回数が出ます（請求はしません）。

予約システムでキャンセルを受けたときは、予約の CSV を読み直しても取り消せます（6-1）。
ただし、CSV の読み直しで取り消した訪問は「当日キャンセル」には数えません。当日キャンセルとして数えたいときは、この手順で取り消してください。

## 7-3 シッターが辞める

サンプルの「ミュージアム あやめ」さんは、退職日が 2026年12月20日です。

1. スタッフの CSV を読み込むと、退職日が **最終勤務日** として入ります
   （アプリで入れるときは、シッターの画面の「最終勤務日」の欄に入れます）
2. 最終勤務日の翌日（12月21日）からは、その人を担当に付けません
3. すでにその人が担当になっている翌日以降の訪問は、予定の上の要対応の帯に出ます。
   ［要対応を組む］を押すと、ほかの人で組み直します
4. **シッター** の一覧の上の「最終勤務日のあるシッター」の欄に、その人と、振り直しが残っているかが出ます。
   ［担当の振り直しを開く］を押すと、その人が担当している先の訪問を一覧で見られます

## 7-4 新しい依頼に応えられるか見る

「平日の午前に、2時間来てもらえますか」と聞かれたとき。

1. メニューの **空き状況** を開きます
2. 曜日・時間帯・所要のチップを選びます
3. 受けられる時間と、入れるシッターの人数の目安が出ます
4. ［要約をコピー］を押すと、答えの文をコピーできます

「場所」にお宅の住所を入れると、移動の時間も含めて数えます。
計算は、今の予定のすき間に入るかで見ます。ほかの人の予定は動かしません。

# 8. データの控え

データは、このパソコンのブラウザの中にだけあります。

- 別のパソコンや別のブラウザでは見えません
- ブラウザの閲覧データを消すと、データも消えます

控えの取り方：

1. **設定 › データ** を開きます
2. 「控え（バックアップ）」の［ファイルに書き出す］を押します
3. 書き出した控えのファイルを保管します。ファイルの名前は「staff-assign-demo-」で始まります

週に1回を目安に書き出してください。
別のパソコンで続けるときは、同じ欄の「読み込む控えのファイル」で、そのファイルを選びます（今のデータと置き換わります）。

# 9. このアプリでできないこと

このデモ版は、「どのシッターが、どの予約に行くか」を決めることに絞っています。次のことはしません。

- 料金の決済・請求・入金の管理
- 予約の受け付け（お客様からの予約は、今お使いの予約システムで受けます）
- 決めた担当を、予約システムへ書き戻すこと
- シッターやお客様への自動の連絡（連絡文はコピーするか、メールアプリを開くところまでです）
- 勤怠の記録（出勤・退勤の打刻や、働いた時間の集計）
- ログインや、何台ものパソコンでの同時の編集
- 実際の道のりでの移動時間（移動は、まっすぐの距離からの目安です）

# 10. よくある質問

**Q. 予約システムから書き出した CSV を、Excel で開いて保存し直しても読めますか。**
A. 1行目の列名を変えなければ読めます。

**Q. 予約の CSV を読み込んだら、「入れなかった行」と出ました。**
A. 予約の氏名と同じ名前のお客様が、アプリにいません。顧客の CSV を読み込み直してから、予約の CSV をもう一度読み込んでください（3-4）。

**Q. 同じ名前のお客様が2人います。**
A. 「名前（顧客ID）」の形で、別の人として入ります。予約はどちらの人か分からないので入りません。予定の画面の［予約を追加］から1件ずつ入れてください。

**Q. 同じ予約の CSV を2回読み込んでしまいました。**
A. 同じ予約番号の予約は直すだけなので、二重には入りません。

**Q. 自動で付いた担当を替えたい。**
A. 日の予定で訪問を押し、［担当を変える］から選びます。手で替えた担当は、あとの自動の組みでは変わりません。

**Q. 担当なしのまま残る予約があります。**
A. 帯の［見に行く ›］か、組んだあとの知らせの［理由を見る］で訪問の詳細を開き、「組めない理由」の枠を見てください。理由（勤務日外・勤務時間外・移動が間に合わない など）と直し方、直す画面へのボタンが出ます（5-2）。東京など遠くのお客様は、［移動時間・遠方を設定］から移動時間（片道・分）と遠方（出張）を入れると組めます。

**Q. 緯度・経度が無いお客様がいても、担当は付きますか。**
A. 付きます。緯度・経度の無い人への移動は30分とみて組みます。担当の理由には「お客様の緯度・経度が未登録（移動は30分とみる）」のように出ます。近さで選べるよう、できるだけ緯度・経度を入れてください（4-1）。

**Q. 予約システムの CSV が無いときは、どうしますか。**
A. お客様（またはシッター）の一覧の［Excel・CSV］を押します。まだ1人もいないときは、［テンプレートをダウンロード（Excel）］か［テンプレートをダウンロード（CSV）］を押します。
できたファイルの2行目から、1行に1人ずつ書いて読み込みます。名前だけ書いても読めます。
空の欄は決まった値で入ります（シッターの勤務は毎日・7:00〜22:00、移動は車 など）。
Excel のテンプレートには「書き方」「記入例」のシートが付いています。何を書くかと、書き方の例が見られます（読み込みでは見ません）。

**Q. お客様の住所は、どこかへ送られますか。**
A. 名簿を読み込んだあとと、［住所から探す］［住所を探す］［続きを探す］などを押したときだけ、郵便番号と住所を場所を調べるサービスへ送ります。名簿のときは、読み込む前の確かめる画面に「読み込んだあと、住所から緯度・経度を探します」と出ます。名前などほかの項目は送りません。
