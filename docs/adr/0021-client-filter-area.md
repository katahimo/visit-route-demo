# ADR-0021：〈利用者さん〉の絞り込みを共通の欄にし、地区は住所から取り出す

- 日付：2026-10-18
- 状態：採用

## 背景
週の〈利用者さん〉×曜日の表と〈利用者さん〉の一覧が「人を選ぶ」形で、全員を見にくかった。地区の項目はデータに無い。

## 決定
表と一覧は「選ぶ」でなく「絞り込む」。共通の部品 `ClientFilter` と純粋関数 `lib/clientFilter`。
- 週の表は時間軸と選択を分け、最初からこの週に訪問がある人を全員出す（チップ既定オン）。状態は URL の `?cf=`。時間軸へは先頭8人を引き継ぐ
- 絞り込みはすべて AND。チップの人数は「押したら何人になるか」、0人は押せない。判定の集まりは `filterFacts` で週の訪問から作る
- 地区は住所から毎回取り出す（`lib/area`：政令市＋区／市・町・村と町名）。取り出せない人は「住所なし」。データの項目は作らない
- 段階のボタンは「終了の人も出す」のチェック1つ
- 訪問の種類で絞る欄（種類の中は OR）。種類が0件なら出さない
- `ClientPicker` は週の時間軸と月間だけ

## 捨てた案
`ClientPicker` を表でも使う（全員を見にくい）・地区の項目を足す（データの版が上がる）。

## トレードオフ
- 失うもの：表で好きな数人だけは並べられない。住所の書き方が崩れると地区がずれる
- 見直す条件：表記ゆれで地区が割れる声。〈利用者さん〉が数百人で判定が重くなったとき
