# ADR-0019：相性・稼働時間などを人ごとにまとめ、比較は日の画面から開く

- 日付：2026-10-18
- 状態：採用（メニューの並びは ADR-0027・ADR-0034・ADR-0047 で置き換え）
- 関連：PRD D102

## 背景
メニューは「登録（〈利用者さん〉・〈スタッフ〉・稼働時間）／決まり（条件・項目・種類・相性）／その他（比較・データ）」だった。利用者から「相性は決まりより登録の方が自然。稼働時間も〈スタッフ〉に付く」と指摘を受けた。

- 相性は〈利用者さん〉×〈スタッフ〉の組み合わせのデータで、社内の決まりではない
- 稼働時間・稼働の見込みは〈スタッフ〉ごとのもの
- 比較はその日の案どうしを比べる画面で、単独で開いても「どの日の、どの案か」が決まらない

## 選択肢
1. 案A：人ごと（〈利用者さん〉／〈スタッフ〉）と「割当の設定」に分け、比較はメニューから外して日の画面からだけ開く
2. 案B：案A と同じで、比較を「予定」の「日」の下に置く
3. 案C：案A と同じで、比較を「割当の設定」の隣に置く

## 決定
案A。相性は〈利用者さん〉の下、稼働時間・稼働の見込みは〈スタッフ〉の下に置く（「誰の何を直すか」でたどる）。比較は使う流れ（日の画面・欠勤の振り直し）から開く。画面の見出しはメニューの名前にそろえる。
今のメニューの並び・比較の置き場は ADR-0027・ADR-0034・ADR-0047 に従う。

## 理由とトレードオフ
- 得るもの：「誰の何を直すか」でたどれる。比較は使う流れと入口が一致する
- 失うもの：比較をメニューから直接開けない（`#/compare` の URL は残る）
- 見直す条件：比較を日をまたいで使いたい要望が出たら、メニューに戻すかを考える

## 影響
- 主なモジュール：`src/app/App.tsx` のメニュー、画面の見出し。ルートの URL・データ・版は変えない
