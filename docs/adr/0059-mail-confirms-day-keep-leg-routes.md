# ADR-0059：日のメールを作ったら確定にし、区間ごとの道順を残す。週のメールは見通しで確定にしない

- 日付：2026-10-23
- 状態：採用
- 関連：ADR-0017・0018・0053

## 背景
「組む → メールで送る → 確定を押す」で確定を押し忘れやすく、日のメールの区間の道順は長さの目安で最初に外れていた。

## 決定
- 日のメールの欄：送れる人（アドレスがあり `tooLong` でない）の「メールを作る」を全員分押したら1回だけ確定する（`confirmByMail`。確認は出さず知らせに「元に戻す」）。欄の下に「確定（伝えた）にする」も残す
- 週のメールは見通しで、確定にしない。確定していない日があれば冒頭に1回だけ書く
- 日のメールの本文は区間ごとの道順を残す段を先に試す（要点・全行程・区間の短い行の順に削り、最後に区間を外す）

## 捨てた案
週のメールで週を全部確定（途中の欠勤で未連絡の変更が増える）。

## トレードオフ
- 失うもの：メールアプリを開いただけで送らなくても確定になる
- 見直す条件：送信をアプリが知れるようになったら送ったで数える
