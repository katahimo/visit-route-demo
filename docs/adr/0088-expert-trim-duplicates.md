# ADR-0088：エキスパート機能の重なった入口・表示を1つに寄せる

- 日付：2026-11-02
- 状態：採用・一部を ADR-0100 で置き換え（標準・段まわり。重なった入口を1つに寄せる方針は残る）
- 関連：ADR-0005・0008・0035・0048・0065・0066・0067・0072・0074

## 背景
UX レビューで「過剰な機能は省く・簡略化」を検討した。利用回数は測れないので、利用者の判断で「機能（できること）は残し、使い道が重なるものだけ削り、画面の数と項目を減らす」とした。エキスパート機能（`expert` が入のときだけ出る 条件の重み `#/rules`・プリセット・案を比べる `#/compare`・組み方の標準 `#/standard`・担当を組む `#/arrange`・基本情報 `#/basics`）を 1366×768 で撮り、同じ情報・同じ操作が2か所以上にある所を洗った。

| 見つけた重なり | どこ |
|---|---|
| 点数の基準を選ぶラジオの並びと、プリセットの一覧が同じプリセットを2回並べる（一覧の行にも「点数の基準」の札） | 条件の重みのプリセットの節 |
| 点数の基準のプリセットの重み・必須の読み取り専用の表と、すぐ下の条件の表が同じ値 | 条件の重み |
| 節の見出しの説明（ⓘ）とラジオの「点数の基準」の説明（ⓘ）が同じ文を2つ | 条件の重み |
| 「重みを変えても今の担当は変わりません…組み方の標準・担当を組むへ」の文と、保存の確認の本文・見出しの［組み方の標準へ戻る］ | 条件の重み |
| 見出しの段（4 担当を組む）と［担当を組むに戻る］が同じ行き先 | 提案を比べる |
| 案を比べるのカードの日付の欄と、比べる画面の上の帯の日付 | 担当を組む・提案を比べる |
| ［日の予定を見る］と、提案の帯の日のリンク・メニューの予定 | 担当を組む |
| 要件 D24（重みをプリセットとして保存）が D286 と同じ | PRD |

## 選択肢
1. 案A：重なった入口・表示を1つに寄せ、機能は全部残す（迷うものは残す）
2. 案B：使い道の重なる画面ごと畳む（案を比べるを担当を組むに、条件の重みを組み方の標準に入れる）
3. 案C：変えない

## 決定
案A。

| 削るもの | 寄せ先 |
|---|---|
| 条件の重みの「点数の基準」のラジオの並び（`ScoreRulerChoice`）と行の「点数の基準」の札 | プリセットの一覧の各行の左の丸（`score-ruler-radio`。一覧は `fieldset.preset-list`＝`score-ruler-choice`） |
| ラジオの説明（ⓘ） | 節の見出しの説明（ⓘ）に1つにまとめる |
| 点数の基準のプリセットの中の重みの読み取り専用の表 | 下の条件の表（行には「重み・必須は下の条件の表のとおりです（点数の基準）」）。ほかのプリセットは今のまま表を出す |
| 条件の重みの次の段の案内（`rules-next-note`） | 保存の確認の本文（今の担当は変わらない・担当を組むで反映）と見出しの［組み方の標準へ戻る］ |
| 提案を比べるの見出しの段の表示（`ArrangeSteps`） | ［担当を組むに戻る（〈日〉）］。条件の重みと同じ「寄り道」の形。メニューの印は担当を組むのまま |
| 担当を組むの案を比べるのカードの日付の欄（`arrange-compare-date`） | 比べる画面の上の帯の日付（開く日は範囲の今日以降の最初の訪問のある日） |
| 担当を組むの［日の予定を見る］（`arrange-day-open`） | 提案の帯の日のリンク・メニューの予定 |
| PRD D24 | D286（廃止した D番号に置き換え先を書く） |

残すもの（同じに見えて目的が違う・迷うもの）：
- 点数・理由の表示（日の予定の「詳しく ▾」・提案を比べるの合計点と理由・組み方の標準の案のカードの点）：見る物が違う（その日の今の担当／その日の案どうし／標準の週の案）
- メニューの「組む」の子と段の表示：行き先は同じだが、メニューはどの画面からでも、段は組むの画面の中の順。QUESTIONS に残す
- 提案を比べるの「担当を組むの提案」の［反映する］（その日だけ）と提案の帯の［反映する］（範囲すべて）：その日だけ反映するのはここだけ。QUESTIONS に残す
- 担当を組むの範囲の呼び名（月・日のときは欄の値と同じ）：担当を組むはエキスパート切でも日の予定から開く画面で、切の画面は変えないので残す
- 基本情報のタブ（相性・勤務時間（シフト））と〈スタッフ〉・〈利用者さん〉のタブ：行き先は同じだが、基本情報の段の中で前提を確かめる道。QUESTIONS に残す

## 捨てた案
- 案B（画面ごと畳む）：担当を組むに地図つきの比較を入れると1画面が重く、条件の重みを組み方の標準に入れると段が増える。画面の数は減るが項目は減らない
- 点数の基準をプリセットの行の札を押して選ぶ：札は押せる物に見えず、読み上げで選べることが伝わらない。丸（ラジオ）にした
- 基準のプリセットの行を一覧から外して表の上に出す：一覧の順と数（N/6）がずれる

## 理由とトレードオフ
- 得るもの：条件の重みの節がプリセットの数の行だけになる（3つなら6行→3行）。説明（ⓘ）・案内の文・段・欄が1つずつ減る。行き先が1つになり迷わない
- 失うもの：担当を組むから比べる日を先に選べない（比べる画面で日を送る）。比べる画面から段で基本情報・組み方の標準へ直に移れない（戻ってから段で移る）

## 影響
- 実装：`src/pages/presetSection.tsx`（ラジオを各行に。`ScoreRulerChoice` を消す）・`settings.css`（`.score-ruler*` を消し `.preset-list`・`.preset-row`）・`rulesParts.tsx`（`rules-next-note` を消す）・`compareParts.tsx`（段を外す）・`arrangeParts.tsx`・`ArrangePage.tsx`（案を比べるのカードの日付の欄・日の予定）
- PRD：D20・D233・D235・D331・D356・D361 の該当を直し、D24 を廃止（置き換え先 D286）
- 設計書：`docs/design/pages-rules.md`・`pages-arrange.md`・`pages-nav.md`
- e2e：`e2e-dialog`・`e2e-arrange`・`e2e-nav`・`e2e-mobile`
- エキスパート切の画面は変えない（案を比べる・条件の重みは切では使えず、担当を組むの案を比べるのカードも切では出ない）
- 見直す条件：比べる日を担当を組むで選びたい・比べる画面から段で移りたいという声が出たとき
