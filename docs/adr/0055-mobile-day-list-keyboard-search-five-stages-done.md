# ADR-0055：スマホは日ごとのリストと下から出る欄、広い画面は帯をキーで動かし、パレットで担当と要対応を引く

- 日付：2026-10-22
- 状態：採用（下のタブは ADR-0074・0080）
- 関連：ADR-0024・0051・0052・0054

## 背景
390px の日の予定は最初の画面に訪問がほとんど見えず、欄のボタンも小さかった。キーボードで訪問を動かせず、パレットは〈利用者さん〉の名前でしか引けなかった。スマホは見る・取り消す・担当替えまで。

## 決定
### スマホの日ごとのリスト（`components/dayList.tsx`）
- 600px 以下の日の予定の既定。行は時刻・〈利用者さん〉・担当の印と名前・印。取り消し・休みの回も薄く出す
- 日の送りは日付の切り替えと左右のスワイプ（横 60px 以上・縦 40px 以内。タッチ・ペンだけ）
- 行を押すと訪問の詳細の欄。長押し（500ms）か「選ぶ」で複数選択
- 表示の切り替え（日ごとのリスト・順番・一覧）は「その他 ▾」

### 下から出る欄（`SidePanel` の `sheet`）
- 600px 以下で `VisitPanel` を下に寄せ、高さは内容（上は 88% まで）。中身は要約と4つのボタン：担当を替える・取り消す・道順・日の予定で見る
- 日時の変更・範囲・新規は出さない。複数選択の帯も同じ置き場所で、時刻をずらすを出さない

### キーボード（`lib/visitKeys.ts`・`components/visitKeys.tsx`）
- 時間軸の帯で ↑↓ 15分・←→ 1日・Shift+←→ 隣の担当（`nextStaffFor`）・Enter で欄・Delete で取り消し（確認）
- 書き込みは `applyVisitEdit`・`cancelVisitOp`。「この回だけ」で、update は1回（全体の元に戻すの1手）
- 動いた先を `output`（aria-live）で読み上げる
- 繰り返しの回は小さな帯（`KeyMoveBand`）で「これ以降も／すべての回も」を選べる（直前の手を戻して範囲つきで当て直す）

### パレットの訪問の検索（`lib/commandPalette`）
- 語を日付・「担当なし」「要対応」・名前（〈利用者さん〉か担当の〈スタッフ〉。部分一致）に分ける（`VisitIndex`）
- 「要対応」は `visitIssues` を1日ずつ間を空けて計算し、終わった日から出す。日付の語が無ければ今日から31日先まで

## 捨てた案
今の画面を詰めるだけ（訪問が見えない）・週・月もスマホでリスト（まとめて見る手段が無くなる）・キーで動かすたびに範囲のモーダル。

## トレードオフ
- 失うもの：スマホの日の予定で担当ごとの1日・理由がすぐには見えない。下から出る欄はなぞって閉じられない
- 見直す条件：スマホで移動・追加をしたい声が出たら、下から出る欄に日時の候補を足す
