# ADR-0002：相性・特性・希望は「項目＋条件の型＋重み0〜5＋必須」で表す

- 日付：2026-10-11
- 状態：採用

## 背景
割当で見るもの（性別・資格・経験・相性・いつもの担当・負担の偏りなど）は事業所ごとに違う。PoC本体は性別希望と NG しか持たない。

## 決定
利用者が定義する**項目**（あり/なし・1つ・複数・数値）と、決まった**条件の型**（必要条件・希望（〈利用者さん〉側・〈スタッフ〉側）・相性・いつもの担当・負担の均等・待ち）に、重み0〜5か必須を付ける。
- 費用は移動時間と同じ「分」に換算（重み1＝移動10分ぶん）
- 必須で候補ゼロになった訪問は理由を出す（matching の `infeasible`）
- PoC本体の性別希望・NG は「性別」項目＋必要条件、相性 × に写す

## 捨てた案
固定のフィールドを増やす（事業所ごとに合わない）・自由な式（利用者が書けない）。

## トレードオフ
- 得るもの：コードを変えずに事業所の考え方を表せ、理由を同じ物差しで説明できる
- 失うもの：型にない考え方は表せない
- 見直す条件：協力法人の考え方の2割以上が型で表せないとき
