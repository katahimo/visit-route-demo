# ADR-0035：条件の重みの画面を「点数の基準（ふだんの考え方）を直す画面」にする

- 日付：2026-10-19
- 状態：採用（確定するまで保存しない点は ADR-0048）
- 関連：ADR-0008・0010

## 背景
条件の重みの画面は `data.rules` を直していたが、AI で組むのは点数の基準のプリセットの重みで、直しても案が変わらなかった。

## 決定
- 「ふだんの考え方」＝点数の基準のプリセット（`scorePresetId`）。データの形は変えない
- 表の名前・種類・並びは `data.rules`、重み・必須は基準のプリセット（`scoreRulesOf(data)`）。変えると `setBasisWeight` で基準のその型を直す（同じ型の条件は同じ重み）
- `data.rules` の重み・必須は `withBasisRules` で基準にそろえる（store の repair も）。AI で組む・訪問ごとの検査・点数はこの重みで計算する
- Excel の「条件」シートの重みは `data.rules`（＝基準）

## 捨てた案
`data.rules` のまま文で説明する（直した重みが効かない問題が残る）。

## トレードオフ
- 失うもの：同じ型の条件を別々の重みにできない。基準を直すと点数も変わる
- 見直す条件：同じ型の条件に別の重みを付けたい声が出たとき
