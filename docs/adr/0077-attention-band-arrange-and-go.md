# ADR-0077：要対応の帯から担当なしを組み、「見に行く」を日の予定でも動かす

- 日付：2026-10-31
- 状態：採用
- 関連：PRD D403・D402・D404・D405（置き換えた既存の要件：D388・D391・D374）、ADR-0072（入れた分の自動の組み）・ADR-0073（切の画面の整理）・ADR-0074（入の画面）・ADR-0075（他のソフトの CSV）

## 背景
- 利用者の声（2026-10-31）：予約システムの予約78件を読み込むと、日の予定の上の要対応の帯が「担当なし 176件・重なり 2件　見に行く ›」になる（エキスパート機能は切）。
  - 日の予定で帯の「見に行く ›」を押しても画面が変わらない
  - 担当なしを組む操作が予定の「その他 ▾」→「担当なしの訪問を組む」に隠れていて分からない
- 原因（「見に行く」）：帯の行き先は3種類の中でいちばん早い訪問で、ふつうは今日の担当なしの訪問。日の予定で今日を見ているときは移る先が今の画面と同じ（同じ URL・同じ日）。日の予定は渡された訪問を「選んで見える所へ巻く」が、担当なしの訪問は担当の列に無いので選べず（`d.owner` に無い）、すでに見えていれば巻きもしない。結果、何も変わらない。重なり 2件は担当なし 176件の後ろに隠れ、帯からは行けない
- 制約：主ボタン（濃い朱）は画面に1つ。帯は月・週・日の予定で共通（`lib/attentionBand`・`useAttentionBand`）。組む処理と範囲は今の「担当なしの訪問を組む」（`lib/autoArrange`・`autoArrangeBatch`。今日〜翌月末）と同じにする

## 選択肢
1. 組む入口：A＝帯に従のボタン「担当なしを組む」を置き、「その他 ▾」と日（スマホ）の主ボタンからは外す／B＝帯にも置き「その他 ▾」にも残す／C＝操作の行の主ボタンにする
2. 「見に行く」の先：a＝重なり・休みの人を先に、無ければ担当なし。担当なしの訪問は欄（受けられる人）を開く／b＝今のまま（いちばん早い訪問）で、日の予定では欄を開くだけ足す

## 決定
1-A・2-a。

1. 帯は 文・［担当なしを組む］（切で、組める担当なしが1件以上のときだけ。枠の従のボタン）・［見に行く ›］。帯全体を1つのボタンにするのをやめ、2つのボタンを持つ箱にする
2. ［担当なしを組む］は `requestUnassignedArrange`（今の「担当なしの訪問を組む」と同じ）。組んでいる間は「組んでいます…」で押せない。入（エキスパート機能が入）は「担当を組む」の画面で組むので出さない（今の「その他 ▾」の項目と同じ出し分け）
3. 「担当なしの訪問を組む」は「その他 ▾」と操作の行（スマホの日の主ボタン）から外す（入口は帯の1か所。`useSimpleMore`・`lib/simpleMore`・`mainTools` の `arrange` を消す）
4. ［見に行く ›］は 重なり・休みの人を先に見せ（担当なしはボタンで組めるので、人の目が要るものを先に）、無ければ担当なし。日の予定は、担当のある訪問は選んで巻き、担当なしの訪問は欄を開く。同じ日を見ていても押せば変わる

## 理由とトレードオフ
- 得るもの：担当なしを組む入口が帯の件数のすぐ横にあり、月・週・日で同じ。重なり 2件が担当なしの陰に隠れない。日の予定で押しても反応がある
- 失うもの：スマホの日の予定から主ボタンが無くなる（担当なしを組むは帯にある）。帯の文の並び（担当なし 先頭）と「見に行く」の先（重なり・休みの人 先頭）がずれる

## 影響
- PRD：D388→D402、D391→D404、D374→D405 に置き換え、D403 を足した（`docs/prd.md`「廃止した D番号」）
- 設計：design.md §4 pages（例外だけ見せる・担当なしの［組む］）、design/pages-nav.md（要対応の帯）
- e2e：帯を押す所は data-testid `attention-band-go`（帯の箱は `attention-band`）。「その他 ▾」の `more-auto-arrange`・操作の行の `toolbar-arrange` は無くなり、帯の `attention-band-arrange` で組む
- 見直す条件：入でも帯から組みたいという声が出たとき（入は組み方の標準で組むので、どちらの組み方かを決めてから）
