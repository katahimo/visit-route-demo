# ADR-0077：要対応の帯から担当なしを組み、「見に行く」を日の予定でも動かす

- 日付：2026-10-31
- 状態：採用
- 関連：ADR-0072・0073・0074

## 背景
担当なしを組む操作が「その他 ▾」に隠れていた。日の予定で今日を見ているとき帯の「見に行く ›」を押しても画面が変わらず（担当なしの訪問は担当の列に無く選べない）、重なりは担当なしの陰に隠れていた。

## 決定
- 帯は 文・［担当なしを組む］・［見に行く ›］の2つのボタンを持つ箱（帯全体を1つのボタンにしない。data-testid `attention-band`・`attention-band-arrange`・`attention-band-go`）
- ［担当なしを組む］はエキスパート機能が切で、組める担当なしが1件以上のときだけ（枠の従のボタン）。`requestUnassignedArrange`（今日〜翌月末）。組んでいる間は「組んでいます…」で押せない
- 「担当なしの訪問を組む」は「その他 ▾」と操作の行から外す（入口は帯の1か所）
- ［見に行く ›］は重なり・休みの人を先に、無ければ担当なし。日の予定は担当のある訪問は選んで巻き、担当なしの訪問は欄を開く

## 捨てた案
「その他 ▾」にも残す（入口が重なる）・主ボタンにする（主ボタンは画面に1つ）。

## トレードオフ
- 失うもの：スマホの日の予定から主ボタンが無くなる。帯の文の並びと「見に行く」の先がずれる
- 見直す条件：入でも帯から組みたい声が出たとき
