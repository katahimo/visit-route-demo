# ADR-0042：AI で範囲を組む計算を画面の外（モジュールの入れ物）で回す

- 日付：2026-10-20
- 状態：採用（結果は提案で「反映する」で書く点は ADR-0053・0054、使う画面は ADR-0063）
- 関連：ADR-0039

## 背景
範囲（日・週・月）を1日ずつ Worker で組むと一月で1〜2分かかり、画面の state に置くと画面を離れると止まる。ページを閉じたあとの再開はしない。

## 決定
計算をモジュールの入れ物（`lib/monthBatch`。`createValueStore` の値）に置き、App の直下の `MonthBatchHost` が store の `data`・`update` をつなぐ。画面は始める・止める・進み具合を読むだけ。
- `createMonthBatch(solve)`：`start`（作っている間は false）・`stop`・`abort`・`connect`。進み具合（`run`）・終わり（`done`）・提案（`proposal`）を外の値で持つ
- 結果は提案としてその場だけ持ち、「反映する」で組み始めたときのままの日だけを1回の update で書く
- データを丸ごと差し替える操作（読み込み・初期化・直前に戻す・別のタブ）では store の `replacedCount` の変化を見て `abort()`
- 上の帯（`BatchBand`）は担当を組むの画面・月の予定では出さない

## 捨てた案
画面に置いて離れる前に確認（待つ間に何もできない）・App 直下の Provider（進みのたびに下を描き直す）。

## トレードオフ
- 失うもの：作っている間に別の画面で同じ日を直せる（反映のとき変わった日は書かない）。ページを閉じると提案は消える
- 見直す条件：再開を求める声・ほかの長い計算も画面の外へ出すとき
