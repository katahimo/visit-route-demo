# ADR-0106：メールと Excel の入出力を入り切りせず、いつも入にする

- 日付：2026-11-06
- 状態：採用
- 関連：ADR-0028・0090・0091・0092

## 背景
管理者設定の機能の入り切り（ADR-0028）に「メール」（`mail`）と「Excel の入出力」（`excel`）があった。
- メールはどのひな形でも切で、「すべての機能」でしか出なかった。予定・連絡を端末のメールアプリで開く機能で、デモで紹介したい
- Excel の入出力を切ると、名簿の読み込み・予約の CSV・Excel のブックが隠れる。どれもデータを入れる主な入口で、切る理由が無い。定期で切ると予約の CSV を読める所が登録の案内だけになっていた（PR #170 のレビュー）

## 選択肢
1. 案A：今のまま入り切りを残し、抜けた所（予約の CSV）だけ入り切りの外に出す
2. 案B：2つの入り切りをなくし、いつも入にする

## 決定
案B。
- 契約の `FEATURE_IDS` から `mail`・`excel` を消す（機能は20）。前の版のデータ・控えに残る `mail`・`excel` の値は、知らない ID として読むときに捨てる（`featuresSchema`。保存データの版は変えない）
- 画面の分岐（`useFeature('mail')`・`useFeature('excel')`・`mailOn`・`excelOn`）を消し、メールのボタン・欄・メールアドレスの欄・メールの予約送信の設定、データの画面の Excel・予約の CSV、一覧の名簿の欄をいつも出す
- ひな形の表から `excel` を外す（入れる機能の一覧に出ない）

## 理由とトレードオフ
- 得るもの：どのひな形でもメールを紹介できる。データの入口が隠れない。管理者設定の行が2つ減る
- 失うもの：メールを使わない事業所でも、メールのボタン・メールアドレスの欄が出る（「その他 ▾」の中と、〈スタッフ〉の基本情報の1行）

## 影響
- PRD D210・D211・D216 と設計の機能の一覧、e2e（e2e-features2・e2e-simple-menu）を直す
- 送信はしない（メールアプリを開くだけ・予約送信は事業所自身の Google Apps Script。ADR-0017・ADR-0069）ので、外部送信の決まりは変わらない
