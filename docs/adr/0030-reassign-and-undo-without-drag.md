# ADR-0030：担当替えをドラッグ以外（キーボード・タッチ）でもできるようにする

- 日付：2026-10-19
- 状態：採用（戻す操作は全体の元に戻す。ADR-0054）
- 関連：ADR-0004・0051

## 背景
担当替えはドラッグだけで、キーボード・読み上げ・タッチでできなかった。

## 決定
訪問の詳細に「担当を変える ▾」（`MenuButton`）を置く。
- まとまり：今の担当（押せない）／ほかの〈スタッフ〉へ移す（押せる人が先、必須の条件に合わない人は押せず理由）／そのほか（「入らなかった訪問へ」）
- 選ぶとドラッグと同じ手直し（最も費用の少ない位置に入れてピン。入らなかった訪問へ移すとピンが外れる）
- 説明の文は `lib/reassignMenu`（「受けられる人」の `candidatesFor` と matching の理由を使う）

## 捨てた案
`select`（候補ごとの説明・押せない理由を出せない）・キーボードのドラッグ（タッチで使えない）。

## トレードオフ
- 失うもの：必須の条件を破って移すのはドラッグだけ。「移動 +N分」は目安
- 見直す条件：メニューからも条件を破って移したい声が出たとき（確認付きで押せるようにする）
