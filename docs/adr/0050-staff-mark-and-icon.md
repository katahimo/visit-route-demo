# ADR-0050：〈スタッフ〉の印を1つの部品にそろえ、任意のアイコン（1〜2文字）を持たせる

- 日付：2026-10-22
- 状態：採用

## 背景
〈スタッフ〉の印が画面ごとにまちまちだった。アイコンを登録したい要望（既定は苗字の最初の文字）。画像は容量を圧迫するので持たない。

## 決定
〈スタッフ〉専用の部品（角の丸い四角に1〜2文字）。〈利用者さん〉の丸とは形で見分ける。
- `components/StaffMark.tsx`・`lib/staffMark.ts`。色は `staffColorMap(data.staff)` の1か所（地図の線・週の帯の縁も）
- 大きさは4段（xs 16・sm 20・md 28・lg 44px）
- 印は `aria-hidden`。文字は CSS の `attr(data-text)` で描き、周りの textContent・読み上げを変えない
- 契約：`Staff.icon`（前後の空白なし・32コード単位まで・`default('')`）
- 2文字まで（書記素、`Intl.Segmenter`）の検査は画面の保存（`staffIconError`）と Excel の読み込みだけ。保存データの読み込みでは見ない
- 既定の文字：名前を空白で区切った先頭の語の最初の1文字
- Excel：〈スタッフ〉のシートの「メールアドレス」の次に任意の「アイコン」列

## 捨てた案
〈利用者さん〉と同じ丸（見分けられない）・色の点のまま。

## トレードオフ
- 失うもの：色は名前の順で決まり、人を足すと替わる
- 見直す条件：9人以上で色が重なって困る声があれば色の欄を足す
