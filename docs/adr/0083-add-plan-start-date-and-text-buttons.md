# ADR-0083：「予定を入れる」に開始日と毎月の第N曜日を足し、絵だけのボタンを文字にする

- 日付：2026-11-02
- 状態：採用
- 関連：ADR-0012・0013・0051・0072

## 背景
新しい〈利用者さん〉は「○日から開始」で決まる（ヒアリング 2026-09-24・2026-10-15）。「予定を入れる」（D402）の定期の欄には開始日が無く、今日から入る。くり返しは毎週〜4週ごとだけで、月1回・第3と第4日曜のような定期は〈利用者さん〉の画面の繰り返しまで行かないと入れられない。〈スタッフ〉の一覧の行の端は目と携帯の絵だけのボタンで、意味が分かりにくい。〈スタッフ〉のスマホ画面は今日だけで、明日の準備に使えない。

## 決定
- **開始日**：「予定を入れる」の定期の欄に「開始日」（既定は今日。今日より前は選べない）。繰り返しの開始（`from`）に入れ、自動の組み（D372）も開始日から翌月末まで
- **くり返しを1つの選択に**：毎週／隔週／3週ごと／4週ごと／毎月（第N）。毎月を選ぶと 第1〜第5 のチップ（複数可。1つ以上必須）を出す。契約（`repeat`・`everyWeeks`・`monthWeeks`）は変えない
- **文字のボタン**：〈スタッフ〉の一覧の行の端の2つを「詳しく」（その人の画面）と「今日の画面」（スマホ画面）の文字のボタンにする（アイコンは文字の前に残してよい）。390px のカードでも文字を出す
- **スマホ画面の日送り**：〈スタッフ〉のスマホ画面（D16）の日付の横に［‹ 前の日］［次の日 ›］と［今日］（今日のときは出さない）

## 捨てた案
- 開始日を「詳しく」に畳む：新規はほぼ毎回使う
- 第N曜日を〈利用者さん〉の画面だけに残す：月1回の利用者の登録で画面を行き来する

## トレードオフ
- 得るもの：新しい〈利用者さん〉の定期が「予定を入れる」1か所で入る。ボタンの意味が文字で分かる
- 失うもの：欄が1行増える。一覧の行の端の幅が広がる
- 見直す条件：開始日を毎回直す手間が出るとき（既定を翌週にするか検討）
