# ADR-0068：名簿の書き出し・読み込みを〈利用者さん〉一覧・〈スタッフ〉一覧へ移し、CSV（文字コードの自動判別）を足す

- 日付：2026-10-27
- 状態：採用（ADR-0020 の置き場所を置き換え。読み方・突き合わせ・総入れ替えは ADR-0020 のまま）

## 背景
名簿の入出力がデータの画面にあり、人を直す画面から離れていた。Excel の無い端末もあり、CSV は Shift_JIS・UTF-8 などが混ざる。

## 決定
- 名簿は各一覧の見出しの「Excel・CSV」で開く欄（`components/RosterCard`）。データの画面は全体のブックだけ
- 文字コードは BOM → UTF-8・Shift_JIS・EUC-JP の順に誤りなく読めるもの → どれも誤りがあれば読めない文字の少ないほう（`lib/csv`）
- CSV は名簿のシート1枚のブックに写し、名簿と同じ読み方（`rosterRows`）に渡す（`excel/rosterCsv`）
- 書き出しは BOM 付き UTF-8・カンマ・CRLF。数式と読まれる先頭（= + - @。数は除く）には「'」を付け、読み込みで外す
- 郵便番号の数字だけの値は先頭を0で埋めて7桁に戻す
- 形は中身で決める（先頭が「PK」なら .xlsx、ほかは CSV）。区切りは1行目のカンマとタブの数
- 確認の本文に読んだ形（「CSV（文字コード Shift_JIS）として読みました。」など）を出す
- 最終勤務日の入った〈スタッフ〉は一覧の「最終勤務日のある〈スタッフ〉」の欄（ADR-0015）に出るので、データの画面の知らせの帯は無くし、トーストでその欄を指す
- 機能の入り切りは `excel` のまま

## 捨てた案
両方に置く（迷う）・文字コードを選ばせる（知らないと選べない）・CSV 用の読み取りを別に作る（決まりがずれる）。

## トレードオフ
- 失うもの：CSV には書式・プルダウンが無い。文字コードの見分けは推定
- 見直す条件：取り違えの声があれば確認の画面で文字コードを選び直せるようにする
