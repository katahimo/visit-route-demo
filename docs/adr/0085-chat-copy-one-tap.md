# ADR-0085：日の予定をチャット用の文にして1タップでコピーする

- 日付：2026-11-02
- 状態：採用
- 関連：ADR-0017・0069・0082

## 背景
現場への共有は LINE WORKS が中心で、予定をカイポケから見て打ち直している（ヒアリング 2026-10-15）。このアプリには日の予定のメール（D92）と印刷（D70）があるが、チャットに貼る短い文は無い。メールの文は件名・挨拶つきで長い。

## 決定
- 日の予定の「その他 ▾」の書き出しを 行き先ごとに1つずつ並べる：「チャット用にコピー」・「メールで送る」（D92）・「印刷」
- **チャット用の文**：1日の全員分を1つの文に。「11/3（火）の予定」の下に担当ごとに「■〈名前〉」、訪問ごとに「 9:00 〈利用者さん〉様（60分）」。担当なしは「■担当なし」。決まりごと（入り方・駐車場・注意。D66）は初めての訪問先（D415）の行の下だけに添え、鍵はメールと同じ「鍵の情報も入れる」を選んだときだけ（既定は入れない）。住所は入れない
- 文は伝えた内容（無ければ今の担当）から作る（D92 と同じ）。作る処理は lib の純粋関数で、メールの文と共通の部分（担当ごとの並び・決まりごとの行）を使い回す
- 押すとクリップボードへコピーし、知らせ「チャット用の文をコピーしました」。送るのは人（アプリは送らない）

## 捨てた案
- LINE WORKS の API で送る：外部送信とキーが要る（ADR-0001・0017）
- 〈スタッフ〉ごとの文に分ける：グループに1回貼る使い方が多い。個別はメール（D92）がある

## トレードオフ
- 得るもの：日の予定をチャットに貼るまでが1タップになる
- 失うもの：「その他 ▾」の項目が1つ増える
- 見直す条件：〈スタッフ〉ごとに貼りたい声が出たとき
