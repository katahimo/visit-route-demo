# ADR-0109：資格・研修の選択肢は職員台帳から足す

- 日付：2026-11-07
- 状態：採用（PRD D422 を D443 に置き換え）

## 背景
PRD D422 で、職員台帳（D421）の資格・研修の列をすべて初期の項目に入れた（資格27・研修14）。
ベビーシッターなど介護でない事業所では、使わない選択肢が並び、条件・名簿・Excel の列が多すぎる。

## 選択肢
1. 案A：初期の選択肢を網羅したまま（今の D422）
2. 案B：初期の選択肢を減らし、台帳を読み込んだときに値のある列だけを選択肢に足す
3. 案C：事業所の種類（介護・保育など）ごとに初期の選択肢を分ける

## 決定
案B。初期の「資格」は以前の7つ（介護福祉士・看護師・保育士・初任者研修・理学療法士・作業療法士・言語聴覚士）、初期の項目に「研修」を置かない。
職員台帳の資格・研修の列の名前は `excel/staffLedgerItems` に辞書として持ち、職員名のある行に値が1つ以上ある列で、まだ選択肢に無いものを「資格」「研修」の後ろに足す（項目が無ければ作る）。

## 理由とトレードオフ
- 得るもの：台帳を使わない事業所は初期の項目が少ない。台帳を使う事業所は、実際に持っている人のいる資格だけが並ぶ
- 失うもの：台帳を読む前は、准看護師などを条件に選べない（項目の画面で足せる）。辞書に無い列（台帳の版が変わって増えた列）は足さず、読まなかった列に出る
- 案C は最初の2問に問いが増えるので採らない

## 影響
- 足す選択肢は名簿の読み込みの確認に出し、名簿と一緒に入る（取り消しも名簿と一緒）
- 今のデータの項目は変えない（新しく始めるデータ・初期データだけ）
