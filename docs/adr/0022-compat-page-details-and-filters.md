# ADR-0022：相性の画面に詳細の吹き出しと列・行の絞り込みを足し、予定などの名前からも詳細を開く

- 日付：2026-10-18
- 状態：採用
- 関連：PRD D113〜D117・D122〜D126・D205〜D209、ADR-0021（`ClientFilter`）

## 背景
相性の画面（行＝〈利用者さん〉、列＝〈スタッフ〉。セルで ◎○△× を入れる）は、列の見出しの名前が切れてだれの列か分からず、相性を入れるとき〈スタッフ〉の特性・稼働や〈利用者さん〉の条件・担当を確かめるには別の画面を探すしかなかった。人数が増えると表が大きく、「女性で看護師の列」「まだ相性を入れていない行」だけを見たい。浮かせて出す部品は `MenuButton` だけで、詳細の吹き出しの部品が無かった。
予定（月・週・日）や、日の画面の「入らなかった訪問」・欠勤の受けられる人・拘束超過の帯・休みの帯・担当の振り直しの欄でも、名前から条件・特性・稼働を確かめられなかった。その名前の多くはすでに操作（ドラッグできる帯・カード、選ぶチップ、列へ移る行）になっている。週の時間軸・日の画面は描画が重い。

## 選択肢
- 相性：A 名前のボタン＋吹き出し（`DetailPopover`）＋`StaffFilter`／共通 `ClientFilter`／B hover のツールチップ＋相性だけの絞り込み／C 縦書きの名前＋他画面へのリンクだけ
- 予定などの名前：A 中身を共通部品にし、状態を React の外の入れ物で持つ／B 画面ごとの `useState`／C Context に状態を入れる
- 最終勤務日の知らせ（名簿の読み込み後）：A データの画面に閉じられる帯＋名前のリンク／B トーストにリンクを入れる／C 知らせの名前も吹き出し経由

## 決定
詳細は吹き出し（`DetailPopover`）で出し、列は `StaffFilter`、行は共通の `ClientFilter` で絞る。中身は共通部品にし、開いている状態は画面全体で1つの小さな入れ物に持つ。

相性の画面
- 見出し・行の名前をボタンにし、押すと吹き出し（`role="dialog"`）で詳細を出す。Esc・外を押す・もう一度押すで閉じ、フォーカスをボタンに戻す。「〈スタッフ〉／〈利用者さん〉の画面で開く」で編集の欄へ移れる
- 列の絞り込み `StaffFilter`（名前・特性のチップ）。行は `ClientFilter` に画面ごとのチップ（「相性がまだ入っていない組がある人」「× がある人」）を足す。AND、人数は「押したら何人になるか」、0人は押せない。数値の項目では列を絞らない
- 相性のチップの判定は絞り込みを変えたときの相性の写しで行い、セルを押しても行は消さず、写しが古くなったら「表を並べ直す」を出す

予定などの名前
- 中身を `components/personDetail` に切り出して相性と共通にし、開いている状態は React の外の入れ物（`lib/personPopover`）に持つ。名前のボタンは自分が開いているかだけを購読し、吹き出しは App の中の1つの部品が出す。相性の画面は自分の state のまま（絞り込みで見出しが消えたら閉じる決まりを保つため）
- 名前が操作でない所は名前をボタンにし、押すと別の動きがある所（チップ・日の列の見出しなど）は横に小さな「i」を置く。ボタンを入れ子にしない。同じ人の名前が何か所あっても押したボタンで区別し、閉じたらそのボタンへフォーカスを戻す
- 最終勤務日の知らせは、読み込む前後の名簿を比べて引き（`lib/personLinks` の `lastDayChanged`）、データの画面の Excel の欄に閉じられる帯で出す（保存しない）。名前は閲覧の欄を開く普通のリンク
- 契約・store・excel・matching・データの版は変えない

## 理由とトレードオフ
- 得るもの：表・予定の画面を離れずに確かめられる。キーボード・タッチ・読み上げで開ける。行の絞り方・URL が他画面と同じ。開け閉めで描き直すのは押したボタン・前のボタン・吹き出しだけで、重い画面でも同時に1つが守られる。判定は純粋関数でテストできる
- 失うもの：
  - 相性のチップで絞っているとき、セルを押しても表が今の相性とずれる（「表を並べ直す」まで）
  - 〈スタッフ〉によみが無いので列の検索は名前のみ。数値の項目（経験年数など）では列を絞れない
  - 吹き出しの部品が `MenuButton` と別に増え、相性の画面だけ別の state（持ち方が2つ）
- 捨てた案：相性B はキーボード・タッチで開けず、絞り込みの作りが他画面とずれる。C は表を離れないと確かめられない。名前B は開け閉めで画面全体が描き直る（時間軸・日の画面が重い）。C は Context の下が全部描き直る。知らせB はトーストが2.5秒で消え押せない
- 見直す条件：数値の項目で絞りたい要望（「3年以上」などの段階を項目ごとに決める）。吹き出しをほかでも使うなら `MenuButton` と位置の決め方をまとめる。相性の画面も同じ入れ物に移すときは、絞り込みで見出しが消えたら閉じる決まりをボタンの後始末で代える

## 影響
- 主なモジュール：`components/DetailPopover`・`PersonPopover`・`personDetail`・`StaffFilter`、`lib/personPopover`・`lib/personLinks`、相性・予定・データの画面
