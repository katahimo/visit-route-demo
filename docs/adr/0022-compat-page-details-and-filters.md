# ADR-0022：相性の画面に詳細の吹き出しと列・行の絞り込みを足し、予定などの名前からも詳細を開く

- 日付：2026-10-18
- 状態：採用（最終勤務日の知らせの帯は ADR-0068 で無くした）
- 関連：ADR-0021

## 背景
相性の表で列の名前が切れ、特性・稼働・条件を確かめるには別の画面を探すしかなかった。予定の名前からも確かめられなかった。

## 決定
- 相性の画面：見出し・行の名前をボタンにし、吹き出し（`DetailPopover`。`role="dialog"`）で詳細。Esc・外・もう一度押すで閉じ、フォーカスを戻す。「〈スタッフ〉／〈利用者さん〉の画面で開く」
- 列は `StaffFilter`（名前・特性のチップ）、行は `ClientFilter` に「相性がまだ入っていない組がある人」「× がある人」を足す。数値の項目では列を絞らない
- 相性のチップの判定は絞り込みを変えたときの写しで行い、セルを押しても行を消さず「表を並べ直す」を出す
- 予定などの名前：中身は `components/personDetail` で共通、開いている状態は React の外の入れ物（`lib/personPopover`）。名前のボタンは自分が開いているかだけを購読し、吹き出しは App の中の1つが出す。相性の画面は自分の state のまま
- 名前が別の操作を持つ所は横に小さな「i」を置く（ボタンを入れ子にしない）

## 捨てた案
hover のツールチップ（キーボード・タッチで開けない）・画面ごとの `useState` や Context（開け閉めで重い画面全体が描き直る）。

## トレードオフ
- 失うもの：〈スタッフ〉は名前でしか検索できない。吹き出しの部品が `MenuButton` と別に増える
- 見直す条件：数値の項目で絞りたい声。吹き出しをほかでも使うなら位置の決め方をまとめる
