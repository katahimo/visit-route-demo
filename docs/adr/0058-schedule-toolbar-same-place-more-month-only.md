# ADR-0058：予定の操作の行を日・週・月で同じ位置にし、「その他 ▾」は月とスマホだけにする

- 日付：2026-10-23
- 状態：採用
- 関連：PRD D344、ADR-0054（予定の共通の部品）・ADR-0045（「その他 ▾」）

## 背景
- 日・週・月は同じ操作の行（欠勤・キャンセルを登録／元に戻す・やり直す／表示／その他 ▾）を使うが、日の予定だけ操作の行が「担当ごとの1日」などの下にあり、週・月より大きく下にずれていた。［月｜週｜日］を切り替えるとボタンの位置が変わる
- 日・週の「その他 ▾」の中身は2つ以下で、たたむほどの数が無く、1回余計に押させていた

## 選択肢
1. 案A：今のまま
2. 案B：日の操作の行を「今の担当」の1行のすぐ下へ上げ、日・週の「その他 ▾」をやめて中身を出す（月は項目が多いので残す）
3. 案C：3画面とも見出しのすぐ下（状態の1行より上）に操作の行を置く

## 決定
案B。
- 日：操作の行は `plan-summary` のすぐ次。担当ごとの1日・提案の帯などはその下
- 日（601px 以上）：「訪問を追加」「使い方」を操作の行のボタンにし、「その他 ▾」は出さない。日（600px 以下）は操作の行を1段にするため、訪問を追加・表示・使い方を「その他 ▾」に入れる（D334）
- 週：「その他 ▾」を出さない
- 月：「その他 ▾」を残す（表示・印刷・勤務の見込み・マスの見方の説明）

## 理由とトレードオフ
- 得るもの：［月｜週｜日］を切り替えても操作の行がほぼ同じ高さにあり、押す所を探さない。日の「訪問を追加」「使い方」が1回で押せる。週の重なったメニューが消える
- 失うもの：日の操作の行のボタンが2つ増える（広い画面では1段に収まる）
- 案C は状態の1行が操作の行の下になり、ADR-0054 の「見出し→状態→操作の行」の並びを崩すので取らない

## 影響
- `pages/PlanPage.tsx`（操作の行の位置・ボタン）・`pages/WeekPage.tsx`・`components/scheduleParts.tsx`
- 見直す条件：日・週の操作がまた増え、操作の行が1段に収まらなくなったら「その他 ▾」に戻す
