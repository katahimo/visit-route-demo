# ADR-0010：点数の物差しを「点数の基準のプリセット」で固定する

- 日付：2026-10-13
- 状態：採用（基準の重みを直す画面と試す重みの扱いは ADR-0035・0053）
- 関連：ADR-0005・0007・0008

## 背景
その日の条件で採点すると、プリセットを押すたびに同じ案の点が変わり比べられない。

## 決定
- 点数の基準は `DemoData.scorePresetId`。無い・存在しない id は `repair` が先頭のプリセットにする。プリセット0件なら条件そのもの
- 物差しの条件＝`applyPreset(data.rules, 基準のプリセット)`（重み・必須だけ基準にする）
- 基準で出す：点・内訳・必須の違反・条件ごとの達成・提案の比較・計算中の「いまの最良 N点」（Worker が `bestRoutes` を送り画面が採点し直す）
- その日の条件のまま：solver の費用と探索・訪問ごとの理由・ドラッグ時の警告
- 基準のプリセットを消すと残りの先頭へ。Excel の「プリセット」シートに「点数の基準」列（○ は1行）
- evaluate・useDayModel が基準の物差し（`scoreProblem`・`scoreScale`）を使い、matching・solver は変えない

## 捨てた案
各案を作った条件で採点（案どうしを比べられない）・その日の条件のまま（押すたびに動く）。

## トレードオフ
- 失うもの：基準と違う考え方の案は点が低く見えうる。訪問ごとの理由と点の物差しが違うことがある
- 見直す条件：基準と違う必須のプリセットで違反の数え方が分かりにくいと言われたとき
