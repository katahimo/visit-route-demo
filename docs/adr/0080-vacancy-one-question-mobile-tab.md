# ADR-0080：空き状況を「チップで聞いて答えを先頭に」し、スマホの下のタブに出す

- 日付：2026-11-01
- 状態：採用
- 関連：ADR-0012・0073・0078

## 背景
ケアマネジャーからの電話で「何曜日の何時が空いているか」を即答したい（ヒアリング 2026-10-15）。いまの空き状況は入力が7つ（種類・所要・開始の幅2つ・週の回数・開始日・週数）で、開始の幅は 0:00〜23:30 の48項目のプルダウン。答えの文は結果の中ほど、「要約をコピー」は下にあり、画面はボタン約200・縦 2000px を超える。電話はスマホで受けることが多いのに、スマホの下のタブに空き状況が無い（ADR-0078 の見直す条件）。

## 決定
- **入力はチップ3つ**（入切とも）：曜日（いまのまま。選ばなければどの曜日でも）・時間帯（指定なし／午前 8:00〜12:00／午後 12:00〜17:00／夕方 17:00〜20:00。複数選べる。時間帯は訪問の開始の時刻の幅）・所要（30／45／60／90分。ほかの分は「くわしい条件」）。種類・週の回数・開始日・週数・開始の幅（30分刻み）・必要な条件は「くわしい条件 ▾」（閉じて始める。既定はいまの既定）。くわしい条件で開始の幅を変えたら時間帯のチップは「指定なし」に戻す
- **答えを先頭に**：答えのカード（D258）を結果の一番上に置き、カードの中に主ボタン［要約をコピー］。曜日×時刻の表・希望の曜日×週のマス（D79）・凡例は「詳しく ▾」（閉じて始める。開閉は端末に覚える。D393 の部品）。仮押さえ・案内文・紹介元へメールは今の「次の一手」のまま
- **スマホの下のタブ**（切）：予定・空き状況・〈利用者さん〉・〈スタッフ〉・探す・メニュー。設定は引き出しとパレットから。空き状況（`vacancy`）が切なら空き状況の代わりに設定。入の下のタブはいまのまま

## 捨てた案
- 自然文で聞く（「火曜の午前、1時間」）：表記ゆれの解釈がいる。チップの方が押す数が少ない
- 開始の幅のプルダウンを15項目に縮める：電話中に2つのプルダウンを選ぶ手間は残る
- 下のタブを7つにする：390px で押しにくい

## トレードオフ
- 得るもの：既定のままなら空き状況を開くだけで答えが出て、条件を1〜2回押してコピーできる。スマホで1タップで開ける
- 失うもの：細かい開始の幅は畳みの中。スマホで設定が下のタブから消える（1手増える）
- 見直す条件：時間帯の境（12:00・17:00）が事業所で合わない声が出たとき（設定にするか検討）
