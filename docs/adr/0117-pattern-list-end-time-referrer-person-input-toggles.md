# ADR-0117：今の繰り返しが分かる一覧・終わりの時刻での入力・紹介元の相談員・特性と時間の決め方の入り切り

- 日付：2026-11-21
- 状態：採用
- 関連：ADR-0006・0012・0020・0028・0052・0053・0092

## 背景
公開版を使っている事業所から、〈利用者さん〉の画面と繰り返しの欄について4件のご意見が来た。

- #7（全員向け）「繰り返しで直した過去の分は消して欲しい。何が残っているかわからない」：繰り返しを「いつから」で直すと、前の中身は前の日までの繰り返しとして残る（`splitPattern`）。一覧で同じ曜日・時刻の行が2つ並び、どれが今のものか分からなかった。直前の変更（終わった繰り返しを「終わった繰り返し（N件）」に畳む）で今日から直した分は畳まれるが、後の日から直したときは2行とも今の一覧に残る
- #12（全員向け）「所要時間を分で出すのに慣れていない。開始 7:00〜終了 8:30 のように終わり時間を入れたい」
- #5（ある事業所＋全員向け）「ペット情報などの特性欄は使わないので不要。紹介元は、相談員が誰か分かるように入力できるのが理想」
- #6（ある事業所）「利用時間はちょうどから始まる契約なので、『時間の決め方』を選べる欄は不要」

ほかの事業所はこの公開版を使っている。データの版（`DATA_VERSION`）は上げられず、事業所ごとの好みはほかの事業所の動きを変えずに入れる。

## 選択肢
#7
1. 案A：直す前の中身（終わった繰り返し）を本当に消す
2. 案B：消さずに、今の一覧から外して畳み、今の行には「いつから・いつまで」の札を付け、直したあとの知らせで前の中身の行き先を言う

#12
1. 案A：所要（分）の欄を終わりの時刻の欄に置き換え、データも終わりの時刻で持つ
2. 案B：データは所要（分）のまま、所要の隣に「終わり」の時刻の欄を足し、どちらで入れても他方に映す

#5（紹介元の相談員）
1. 案A：紹介元のメモに書いてもらう
2. 案B：紹介元に省略可の欄 `person`（相談員）を足し、画面・Excel に出す

#5・#6（欄を隠す）
1. 案A：事業所の設定（`org`）に見せ方の項目を足す
2. 案B：機能の入り切り（ADR-0028）に2つ足す（既定は入）

## 決定
- #7 は案B。終わった繰り返しは消さない。ADR-0053 で繰り返しの回は見るときに計算するので、前の中身を消すと今日より前の日の予定（伝えた内容・月の予定・勤務の見込み）からその回が消える。代わりに
  - 今の一覧（今日からも続く繰り返し）の行に札：まだ始まっていない＝「11/23から」、終わりの決まった＝「11/22まで」、終わりの翌日に同じ〈利用者さん〉の繰り返しが始まれば「11/22まで（11/23から変わります）」（`lib/patternText` の `patternPhaseText`）
  - 「終わった繰り返し（N件）」の畳みに「直す前の中身・終わらせた繰り返しです。今日より前の回の記録として残し、今日からの予定には出ません」
  - 直したあとのトースト（`lib/patternConfirm` の `patternSplitText`）：今日から分けたら前の中身は「終わった繰り返し」に残る、後の日から分けたらその日から変わると言う
  - 単発になった回（消した繰り返しの、この回だけ変えた回）は今までどおりカレンダーに出す
- #12 は案B。`components/DurationEndFields`（読み替えは `lib/durationEnd`）を繰り返しの欄・訪問の詳細の欄・「定期の予定を追加」で使う。開始を変えたら所要を保って終わりを動かす。終わりが開始より後でないときは欄の下に誤りを出し、所要を空にして保存で止める。その日のうちに終わらない所要なら終わりは空。幅のときは開始（早）からの終わり（見出し「終わり（開始（早）のとき）」）。空き状況の試算の所要は今回変えない（問い合わせの長さを分で聞く欄のため）
- #5 の相談員は案B。`Referrer.person`（任意・50字まで。空は欄ごと省く）。段階と紹介元の節に「紹介元の相談員（任意）」の入力と「相談員」の表示。Excel（ADR-0006・0020）にも足す：全体のブック・名簿のブックの列「紹介元の相談員」（「紹介元」の次）。列の無い古いブックは空（名簿は今のまま）。紹介元を名前で探す・メールの宛名には使わない
- #5・#6 の欄を隠すのは案B。機能 `clientTraits`（〈利用者さん〉の特性）・`timeWindow`（時間の決め方（ちょうど・幅））を「入力の補助」のグループに足す（22 の機能）
  - 既定は入（今の見え方のまま）。どのひな形でも入にする（足す前のひな形の見え方を変えず、ひな形を選び直した事業所でも隠れない。切るのは事業所ごとの好み）
  - `clientTraits` を切ると〈利用者さん〉の画面の「特性」の節と一覧のくわしい列の「特性」を出さない。入れた特性は消さず、AI で組むときに効き続ける（切るときの確認に人数）。〈スタッフ〉の特性・〈利用者さん〉の「スタッフに求めること」は隠さない
  - `timeWindow` を切ると繰り返しの欄の「時間の決め方」と訪問の詳細の欄の「時間の約束」を出さず、既定のちょうどで入れる。幅で入れてある繰り返し・訪問を直すときは選ぶ欄を出す（黙ってちょうどに変えない）。幅の繰り返しは今どおり作る（切るときの確認に件数）

## 理由とトレードオフ
- 得るもの：今の繰り返しと前の中身・これからの中身が見分けられ、過去の記録は残る。分に直さずに終わりの時刻で入れられ、データと計算は変わらない。相談員を残せ、Excel でも渡せる。使わない欄を事業所ごとに隠せ、ほかの事業所の画面は変わらない
- 失うもの：前の中身は「終わった繰り返し」に残り続ける（消したい人には1つ畳みが増える）。所要と終わりの2つの欄で欄が1つ増える。機能のスイッチが2つ増える
- 捨てた案：#7 の案A は今日より前の日の予定・伝えた内容が変わる（ADR-0053）。#12 の案A は版を上げるか読み替えが要り、計算・Excel・CSV の所要（分）の列もすべて変わる。#5 の案A はメモと混ざり、一覧・Excel で相談員だけを読めない。欄を隠す案A は機能の入り切り（ADR-0028）と別の仕組みが増え、切ったときの確認（データは残る）を作り直すことになる
