# ADR-0082：欠勤・キャンセルを2段にし、初めての訪問先には決まりごとを添える

- 日付：2026-11-01
- 状態：採用
- 関連：ADR-0011・0013・0038・0044

## 背景
欠勤・キャンセルの欄は5段（起きたこと→休む人→影響→振り直し→連絡・確定）で、朝の電話を受けながら押す数が多い。影響と振り直しの段は「おすすめで決める」がほとんど。代わりに入る人が初めての家では、鍵・入り方・駐車を LINE WORKS で探し直している（ヒアリング 2026-10-15）。決まりごと（D66）はアプリにあるのに、連絡文に載らない。

## 決定
- **2段にする**（入切とも）：1「何が起きたか」＝種類（〈スタッフ〉が休む／〈利用者さん〉がキャンセル）・人（または訪問）・時間（終日／午前だけ／午後だけ／時間帯）。選んだ時点で影響とおすすめの振り直しを計算し、同じ段の下に担当が移る訪問の一覧（D265）を出す。主ボタン［この案で決める］で欠勤の登録と振り直しを1手で書く（元に戻せる）。ほかのやり方（案A だけ・案B も作る・欠勤だけ登録）と案B の「変更を減らす」は「ほかのやり方 ▾」に畳む。2「連絡・確定」＝今の5段目（D244）のまま
- 登録済みの欠勤は、人を選んだときに「この日の欠勤：…」と出して直せる（種類の「登録済みの欠勤」は無くす）
- **初めての訪問先**：振り直しで新しく入る〈スタッフ〉が、その〈利用者さん〉を過去8週に担当していなければ、連絡文の「お願いします」の行の下に決まりごと（入り方・鍵・駐車場・注意。入っているものだけ）を添え、行に「初めて」の印。日の予定の訪問の詳細とスマホ画面（D16）にも「初めて」の印と決まりごとを先頭に出す
- 文はコピー・メールの前に画面で見える（送るのは人。アプリは送らない）

## 捨てた案
- 影響の段だけ残す（3段）：影響は振り直しの一覧と同じ情報で、段を分ける理由が無い
- 決まりごとをいつも添える：毎回の連絡が長くなり、鍵の情報が要らない人にも渡る

## トレードオフ
- 得るもの：急な欠勤が「選ぶ→決める→連絡」の3手前後になる。代わりの人が鍵・駐車を探さなくてよい
- 失うもの：影響を見てから振り直すかを決める段が無くなる（一覧を見てから［この案で決める］を押す）。鍵の暗証番号などがコピー・メールの文に入る（D246 の範囲を広げる）
- 見直す条件：鍵の情報を文に入れたくない声が出たとき（鍵だけ「決まりごとあり」にする）
