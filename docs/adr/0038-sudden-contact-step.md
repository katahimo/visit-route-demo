# ADR-0038：欠勤・キャンセルの欄に「連絡」の段を置き、連絡文のひな形と載せる範囲を決める

- 日付：2026-10-20
- 状態：採用（5段目で連絡と確定を一緒に行う点は ADR-0053。連絡を確定の前に置くのはこの流れ）
- 関連：PRD D243〜D247、ADR-0011・ADR-0017・ADR-0025

## 背景
欠勤・キャンセルの欄は、確定のあとに要る「だれに何を伝えるか」を欄の外（日の予定の差の欄の連絡の一覧）に任せていた。キャンセルでは担当への中止の連絡が一覧に出なかった。連絡文のひな形（敬語・載せる範囲）も未決で、〈利用者さん〉あての文に前の担当の名前や「本日」が入っていた。管理者は当日の朝にスマホで欠勤の電話を受けることが多いが、スマホのホームでは入口が「いつでも」の中にあった。

## 選択肢
1. 案A：欄は変えず、差の欄の連絡の一覧を開いてもらう
2. 案B：欄に「連絡」の段を足し、差と取り消した訪問から1人に1行の一覧を出す。［連絡した］は欄の中の状態だけ
3. 案C：案B に加え、［連絡した］を `DemoData` に残す。捨てた理由：契約・版・Excel を変える割に、記録・勤怠はやらないこと（PRD §4）の範囲に近い

## 決定
案B。

- 段階は 起きたこと→休む人（訪問）→影響→振り直し方（確かめ）→連絡と確定。連絡の一覧は差の欄の連絡の一覧と同じ文
- 一覧の差は、伝えた日なら「伝えた内容 → 今の担当」、伝えていない日なら「振り直す前の担当（キャンセルは取り消す前の担当の並び）→ 今の担当」。キャンセルは取り消した訪問（取り消す前の担当・開始）も含める。純粋関数 `lib/contacts` の `contactRows`。キャンセルの「前」は取り消す前の担当の並びから時刻を出す（並びが違うと偽の「時刻が変わる」が出る）
- 1人に1行。種類は 担当が外れる・新しく入る・時刻が変わる・中止・〈利用者さん〉あて。キャンセルした〈利用者さん〉には作らない
- 各行に［文をコピー］・〈スタッフ〉あてのメール（`mailto:`）・［連絡した］。［連絡した］は欄の中の状態だけで、欄を閉じると消える（印の鍵は宛先と文）
- ひな形：〈スタッフ〉あては丁寧語の短文、〈利用者さん〉あては敬語（名乗り・お詫び・結び）。日付は「10月21日（水）」（「本日」と書かない）。〈利用者さん〉あてはどの訪問かを約束の開始で書き、新しい開始は「ごろ」（見込みの時刻は約束と違って見えるため）
- 載せる範囲：住所・所要は〈スタッフ〉あての「お願いします」の行だけ。〈利用者さん〉あては担当の姓と時刻だけ（前の担当・住所・代わる理由は書かない）
- スマホ（860px 以下）のホームは、欠勤・キャンセルの入口を見出しのすぐ下に置き「いつでも」から外す。見た目はほかの入口と同じカードで、アイコンだけ朱

## 理由とトレードオフ
- 得るもの：連絡までが1つの流れで終わり、キャンセルの担当への中止も漏れない。差の欄と欄の中で文が同じ。〈利用者さん〉へ〈スタッフ〉の欠勤や前の担当を伝えずに済む（個人情報を最小に）。契約・データの版・Excel を変えない
- 失うもの：［連絡した］は欄を閉じると消え、あとから見返せない。〈利用者さん〉にはメールアドレスが無いので文のコピーだけ。姓は名前の空白の前で取るので、空白の無い名前はそのまま出る
- 見直す条件：［連絡した］を見返したい声が出たとき（データに足す。契約・版の追加が要る）、〈利用者さん〉の宛先を持つとき、ひな形を事業所ごとに変えたいとき
