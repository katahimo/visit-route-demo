# ADR-0038：欠勤・キャンセルの欄に「連絡」の段を置き、連絡文のひな形と載せる範囲を決める

- 日付：2026-10-20
- 状態：採用（最後の段で連絡と確定を一緒に行う点は ADR-0053）
- 関連：ADR-0011・0017・0025

## 背景
欠勤・キャンセルの欄は「だれに何を伝えるか」を欄の外に任せ、キャンセルの中止の連絡が出なかった。〈利用者さん〉あての文に前の担当の名前が入っていた。

## 決定
欄に「連絡」の段を足し、1人に1行の一覧を出す。［連絡した］は欄の中の状態だけ（保存しない）。
- 段階：起きたこと → 休む人（訪問）→ 影響 → 振り直し方 → 連絡と確定
- 差：伝えた日なら「伝えた内容 → 今の担当」、伝えていない日なら「振り直す前の担当 → 今の担当」。キャンセルは取り消す前の担当の並びから時刻を出す（`lib/contacts` の `contactRows`）
- 種類：担当が外れる・新しく入る・時刻が変わる・中止・〈利用者さん〉あて。キャンセルした〈利用者さん〉には作らない
- 各行に［文をコピー］・〈スタッフ〉あてのメール（`mailto:`）・［連絡した］
- ひな形：〈スタッフ〉あては丁寧語の短文、〈利用者さん〉あては敬語。日付は「10月21日（水）」（「本日」と書かない）。新しい開始は「ごろ」
- 載せる範囲：住所・所要は〈スタッフ〉あての「お願いします」の行だけ。〈利用者さん〉あては担当の姓と時刻だけ

## 捨てた案
差の欄の一覧を開いてもらう（流れが切れる）・［連絡した］を保存する（契約・版が変わり、記録はやらない範囲に近い）。

## トレードオフ
- 失うもの：［連絡した］は欄を閉じると消える。〈利用者さん〉あては文のコピーだけ
- 見直す条件：［連絡した］を見返したい声・ひな形を事業所ごとに変えたい声
