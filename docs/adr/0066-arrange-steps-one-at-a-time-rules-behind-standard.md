# ADR-0066：「予定を組む」を1段ずつ進む4段にし、条件の重みを組み方の標準の奥へ下げる

- 日付：2026-10-26
- 状態：採用
- 関連：PRD D349・D355・D359・D360・D233、ADR-0065（3段のタブ。この ADR でタブと段の出し方を置き換え）・ADR-0038（欠勤・キャンセルの欄の段階）

## 背景
- 利用者の声：「予定を組む」が複雑で、どう進めればよいか分からない。欠勤・キャンセルのように手順を順に進めたい
  - 予定を組むはタブ3つ（条件の重み・組み方の標準・担当を組む）。組み方の標準の中も3枚のカード（案をくらべる・表で直す・標準にする）が縦に全部並び、どこから手を付けるか分かりにくい
  - 条件の重みは触らなくても組める（初期の3つの考え方で案を作ってくらべられる）のに、タブの1段目にあり、まずそこを直す画面に見える
  - 条件の重みの画面は、プリセットの節（点数の基準のラジオ）が重みの表の下にある。プリセットを選ぶと表の重みが替わるのに、並びが逆

## 選択肢
1. 段の出し方
   - A：欠勤・キャンセルの欄と同じく、上に段の表示を置き、今の段だけを出して［戻る］［次へ］で進む（組み方の標準の3段＋担当を組む＝4段）
   - B：カードは今のまま縦に並べ、タブを段の表示に替えて最後に［次へ］を置くだけ
2. 条件の重みの入口
   - A：タブ・メニューから外し、組み方の標準の「1. 案をくらべる」の段に小さなリンク（触らなくても組めることを添える）。条件の重みの画面には「組み方の標準へ戻る」
   - B：設定のタブへ戻す
3. 条件の重みの画面の並び
   - A：プリセットの節（点数の基準を選ぶ）を重みの表の上へ
   - B：今のまま

## 決定
1-A・2-A・3-A（利用者が決めた。2026-10-26）。

### 予定を組むの4段（`ArrangeSteps`。ADR-0065 の `ArrangeTabs` を置き換え）
| 段 | 画面 | 中身 |
|---|---|---|
| 1 案をくらべる | `#/standard`（段 `proposals`） | 考え方ごとの案を作ってくらべる（カード・表で見る・日で見る）。［この案から作る］で 2 へ。条件の重みへの小さなリンク |
| 2 表で直す | `#/standard`（段 `draft`） | 下書きの表を直す。下書きが無ければ［今の標準から作る］ |
| 3 標準にする | `#/standard`（段 `register`） | いつから・入れ替える／残す・［この表を標準にする］。登録した直後は完了の表示と［次へ：担当を組む］ |
| 4 担当を組む | `#/arrange`（比較の画面 `#/compare` も 4） | 範囲を選んで標準で埋まらない所を AI で組む（ADR-0065 のまま） |

- 段の表示は見出しの下（`PageHeader` の nav）に `ol`（`aria-label`「予定を組むの段」・今の段に `aria-current="step"`）。各段は押して移れる（欠勤の欄と違い、前の段を終えていなくても移れる。標準がある人は 4 だけ使う）
- 組み方の標準の画面は今の段のカードだけを出し、カードの下に［戻る］（2・3）と［次へ：〈次の段〉］を置く。今の段は画面の外の入れ物（`standardWork.step`）に置き、ほかの画面へ移っても残る。開いたときの既定は、登録した直後なら 3、下書きがあれば 2、無ければ 1
- 段を移ると、その段の見出しへフォーカスして巻く
- 主ボタンは画面に1つ：1 は「案を作る」（案があれば［次へ］は枠）、2 は［次へ：標準にする］（下書きがあるとき）、3 は［この表を標準にする］か、登録した直後の［次へ：担当を組む］
- メニューの「予定を組む」の子は 組み方の標準・担当を組む の2つ（組み方の標準の印は条件の重みの画面でも付ける）。コマンドパレットからは条件の重みを引ける

### 条件の重み（`#/rules`）
- 予定を組むのタブ・メニューの子から外す。入口は組み方の標準の 1 のリンク（「考え方の重みを細かく直す（条件の重み）」と「触らなくても、初期の考え方で組めます」）とコマンドパレット。URL は変えない
- 見出しの右に［組み方の標準へ戻る］（`/standard`）。段の表示は出さない（1 の寄り道）
- プリセットの節を重みの表の上へ置く（選んだ考え方の重みが下の表に出る）

## 理由とトレードオフ
- 得るもの：画面に出るのは今の段だけで、次に押すものが1つになる。欠勤・キャンセルと同じ「段を順に進む」形で覚えやすい。条件の重みは寄り道になり、触らなくても組めることが分かる。プリセットを選ぶ → 重みを見る・直す の順になる
- 失うもの：
  - 組み方の標準の3段を1画面で見渡せない（段の表示を押して移る）
  - 条件の重みをメニューから直接開けない（組み方の標準の 1 かパレットから）
  - 段を移るたびに1手増える
- 1-B は縦に長いまま。2-B は ADR-0065 で予定を組むへ移した理由（考え方と標準の流れが1本）に反する
