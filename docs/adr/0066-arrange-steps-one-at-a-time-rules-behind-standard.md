# ADR-0066：「予定を組む」を1段ずつ進め、条件の重みを組み方の標準の奥へ下げる

- 日付：2026-10-26
- 状態：採用（段の並びは ADR-0067、段を出す画面は ADR-0074）
- 関連：ADR-0038・0065

## 背景
予定を組むが複雑でどう進めればよいか分からないという声。条件の重みは触らなくても組めるのに1段目にあった。

## 決定（利用者が決めた）
- 段の表示は見出しの下（`PageHeader` の nav）の `ol`（`aria-label`「予定を組むの段」、今の段に `aria-current="step"`）。各段は押して移れる（前の段を終えていなくてもよい）
- 組み方の標準の画面は今の段のカードだけを出し、下に［戻る］と［次へ：〈次の段〉］。今の段は画面の外の入れ物（`standardWork.step`）に置く。段を移るとその見出しへフォーカス
- 主ボタンは画面に1つ
- 条件の重み（`#/rules`）は段・メニューから外し、入口は案をくらべるの段の小さなリンク（触らなくても初期の考え方で組めることを添える）とパレット。見出しの右に［組み方の標準へ戻る］
- 条件の重みの画面はプリセットの節を重みの表の上に置く

## 捨てた案
カードを縦に並べたまま最後に［次へ］（縦に長いまま）・条件の重みを設定のタブへ戻す（考え方と標準の流れが切れる）。

## トレードオフ
- 失うもの：標準の段を1画面で見渡せない。条件の重みをメニューから直接開けない
