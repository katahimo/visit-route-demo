# ADR-0060：予定の日・週・月の上に同じナビの行を置き、上の帯に貼り付ける

- 日付：2026-10-24
- 状態：採用（確定のボタンは ADR-0074 で操作の行へ）
- 関連：ADR-0044・0054

## 背景
日付の送りが2か所にあり、［月｜週｜日］・確定・メールのボタンの位置も画面ごとに違った。

## 決定
- `components/ScheduleNav.tsx` を見出しのすぐ下に置く：「今日」・期間の select（‹ ›）・［月｜週｜日］、右に状態の印
- 送る単位は表示している単位（月・週・日）
- 上の帯の日付の選択（`DateSwitcher`）は `/plan`・`/week`・`/month` では出さない（`lib/nav.ts` の `DATE_PAGES`）
- 861px 以上で上の帯の下に貼り付ける。高さ `--sched-nav-h` は `ResizeObserver` で測る。860px 以下は貼り付けず折り返す。印刷では期間の文だけ
- キーボードの送りは札のキーとぶつかるので入れない

## 捨てた案
上の帯の日付で送る（［月｜週｜日］と送りが離れたまま）。

## トレードオフ
- 失うもの：広い画面で1行（約 64px）を使い続ける。予定以外の画面とは日付の場所が違う
