# ADR-0044：次の一手を1つに絞り、押した結果を確定の前に見せる

- 日付：2026-10-21
- 状態：採用（ホームの並び・予定の表示の細部は ADR-0053・ADR-0054・ADR-0063 のあと、design/*.md が正）
- 関連：PRD D263〜D272、ADR-0025（ホーム・欠勤の欄）・ADR-0033（狭い画面の表）・ADR-0036（ボタンの3段）・ADR-0038（スマホのホームの先頭の欠勤）

## 背景
主な作業（月の案を作って確定・急な欠勤・問い合わせ）を実機で通して評価した。文言や手順はよくできているが、次に押すものが1つに決まらない所と、押した結果が見えずに確定を求められる所が残っていた。

- ホームの「次にすること」が作業の順と逆で、どのカードも同じ大きさだった
- 欠勤の欄の3段目に主ボタンと枠のボタンが並び、どれが勧めか読まないと分からない。4段目は件数だけで、誰のどの訪問が誰へ移るかを見ずに確定を押すことになる
- 点数が、入らない0・違反0でも朱の太字で、要対応に見える（赤は要対応だけ、という決まりと食い違う）
- 日付に関係しない画面にも上の帯の日付の選択が出ていた
- 細部：知らせのボタンが今いる画面を指す、日の予定の列の名前が切れる、左のメニューが 768px の高さに収まらない、条件の名前がいつも入力欄で誤って書き換わる、スマホの相性・勤務時間の表で名前の列が広い

制約：契約・データの版・計算は変えない。

## 選択肢
- ホーム：A 並びを作業の順にし、先頭の1枚を「まずこれ」として幅いっぱい・主ボタンの塗りにする／B 月ごとに1枚にまとめる／C 「今日の1枚」だけにする
- 欠勤の3段目：A 主ボタンは「登録して振り直す（おすすめ）」の1つ、もう一方の案と「欠勤だけ登録」は「ほかのやり方」に文字のボタンで置く／B ラジオで案を選ぶ／C 今のまま
- 欠勤の4段目：A 振り直しの差から、担当が変わる訪問と入らない訪問を1行ずつ出し、「変更を減らす」は畳む／B 差の欄へ移ってから確定させる

## 決定
いずれも A。

- ホームの並びは作業の順（要対応 → 月ごとに組む → 確定していない日 → 今日）。先頭の1枚は「まずこれ」。同じ内容を2枚のカードに重ねて書かない
- 欠勤の3段目は主ボタンが1つ。振り直しの元が無い日（計算中など）は押せない振り直しを出さず、「欠勤だけ登録」を主ボタンにする。4段目は確定の前に、誰の何がどう変わるかを1行ずつ見せる
- 点数の色は、入らない・必須の違反があるときだけ要対応の色（赤）。点が低い理由は注意の色の文で示す
- 上の帯の日付の選択は、選んでいる日付で中身が変わる画面だけに出す。ほかの画面では出さない（日付は覚えたまま）
- 知らせ：行き先が今いる画面と同じボタンは出さない。ボタン付きは文の長さで表示時間を延ばし、マウスを重ねている間・フォーカスがある間は消さない
- 日の予定の時間軸は列の最小幅を詰め、名前は折り返して切らない。右に続きの列がある間は端に影
- 左のメニューは高さ 860px 以下でさらに詰め、1366×768 で最後の項目まで見せる（タッチできる端末は 44px のまま）
- 条件の名前はふだん文字で、［名前を変える］で入力欄にする。必須の条件を消す確認には「守らなければ担当にしない決まりが無くなる」と書く
- 狭い画面（600px 以下）の相性・勤務時間は名前の列を詰めて折り返す

## 理由とトレードオフ
- 得るもの：ホームを開くと押すものが1つに決まり、作業の順に押していける。欠勤は主ボタンだけでおすすめの振り直しになり、確定の前に変わる中身を見られる。赤が要対応だけに戻る
- 失うもの：ホームの今日のカードが最後になる（今日の手当ては要対応が先頭に出るので、困るのは「今日を見るだけ」のとき）。欠勤の別の案は文字のボタンを探すことになる。「変更を減らす」は1手多く開く。日付の無い画面で日付を変えるには予定の画面へ移る
- 捨てた案：ホームの B は押した先が1つに決まらない。C は月の準備がホームから見えなくなる。欠勤の B（ラジオ）は選ぶ前に違いを読む必要が残る。4段目の B は確定の前に欄を閉じることになり、連絡の段へ続かない
- 見直す条件：今日のカードが最後で困る声が出たら、今日に手当てが要るときだけ要対応の次へ上げる。欠勤で別の案を選ぶ人が多ければ、ほかのやり方を枠のボタンにする
