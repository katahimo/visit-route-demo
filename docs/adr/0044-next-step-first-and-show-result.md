# ADR-0044：次の一手を1つに絞り、押した結果を確定の前に見せる

- 日付：2026-10-21
- 状態：採用・一部を ADR-0082 で置き換え（欠勤の3段目・4段目は1段目の見込みと［この案で決める］に。ホームの並びは ADR-0074 でホームごと無くした。上の帯の日付は ADR-0060）
- 関連：ADR-0025・0036・0038

## 背景
次に押すものが1つに決まらない所と、押した結果を見ずに確定を求められる所が残っていた。

## 決定
- 欠勤の3段目は主ボタン1つ（「登録して振り直す（おすすめ）」）。ほかの案と「欠勤だけ登録」は「ほかのやり方」に文字のボタン。振り直しの元が無い日は「欠勤だけ登録」が主
- 欠勤の4段目は確定の前に、担当が変わる訪問と入らない訪問を1行ずつ見せる。「変更を減らす」は畳む
- 点数の色は、入らない・必須の違反があるときだけ赤。点が低い理由は注意の色の文
- 上の帯の日付の選択は日付で中身が変わる画面だけ（`lib/nav` の `showsDateSwitch`）
- 知らせ：行き先が今いる画面と同じボタンは出さない。ボタン付きは文の長さで表示を延ばし、マウス・フォーカスがある間は消さない
- 日の予定の時間軸は列の最小幅を詰め、名前は折り返す。右に続きがあれば端に影
- 左のメニューは高さ 860px 以下でさらに詰める（タッチ端末は 44px のまま）
- 条件の名前はふだん文字で、［名前を変える］で入力欄

## 捨てた案
欠勤の案をラジオで選ぶ（違いを読む必要が残る）・差の欄へ移ってから確定（連絡の段へ続かない）。

## トレードオフ
- 失うもの：欠勤の別の案は文字のボタンを探す
- 見直す条件：別の案を選ぶ人が多ければ枠のボタンにする
