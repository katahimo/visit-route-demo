# ADR-0086：「基本」のひな形に毎月の第N曜日と決まりごとを入れる

- 日付：2026-11-02
- 状態：採用（「基本」の中身は ADR-0091 で置き換え。Excel の入出力・退職・担当替え・〈利用者さん〉の休みを足した）
- 関連：ADR-0013・0028・0073・0082・0083

## 背景
最初の2問で「定期の訪問が中心」を選ぶと「基本」のひな形になる（D379）。「基本」では毎月の第N（`patternMonthly`）と訪問先の決まりごと（`visitNotes`）が切で、管理者設定で入れるまで「予定を入れる」の毎月（第N。D416）と、初めての訪問先に添える決まりごと（D415・D419）が出ない。ヒアリング（2026-10-15）では、月1回・第3と第4日曜のような定期と、鍵・入り方・駐車の共有がどちらも要ると分かっている。

## 決定
- 「基本」に `patternMonthly` と `visitNotes` を入れる。「月次予定・現場共有」は基本を含むので中身は変わらない（説明から2つと、同じ機能の「曜日ごとの時刻」を外す）
- 「労務・契約管理」も基本を含むので、2つが入る（基本に足す4つは変わらない）
- 「単発のみ」は今のまま（基本から `patterns`・`patternMonthly`・`visitNotes` を外す）
- すでに保存されたデータの機能の入り切りは変えない（ひな形は「適用」したときだけ書く。D212）

## 捨てた案
- 最初の2問に「第N曜日を使うか」の問いを足す：問いが増える
- 機能の入り切りをやめて常に出す：使わない事業所には欄が増える

## トレードオフ
- 得るもの：定期の事業所が設定を開かずに毎月の第N と決まりごとを使える
- 失うもの：「基本」の画面に毎月の選択肢と決まりごとの欄が増える
- 見直す条件：「基本」の欄が多いという声が出たとき
