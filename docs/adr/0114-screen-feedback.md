# ADR-0114：画面への意見をボタンで残し、パスワードで閉じた1つのファイルにまとめて送ってもらう

- 日付：2026-11-12
- 状態：採用
- 関連：ADR-0001・0017・0032・0112・0113

## 背景
事業所が実際に使い、意見を聞く段階に入った。使っている最中に「この画面のここ」をその場で残してもらい、あとでまとめて受け取りたい。サーバーは無く（ADR-0001）、アプリからの外部送信は決めたものだけ（AGENTS.md）。事業所とは秘密保持契約があり、画面の画像に〈利用者さん〉の名前・住所が写ってよい。ただしメール・LINE で運ぶあいだは中身を読めないようにしたい。

## 選択肢
- 残し方
  1. 案A：画面のボタンで、その画面を自動で撮り、意見を書いて端末に溜める
  2. 案B：端末のスクリーンショットを貼ってもらう
  3. 案C：文だけ残す
- 送るファイル
  1. 案a：パスワードで開く1つの HTML（Web Crypto で暗号にし、開く処理をファイルの中に持つ）
  2. 案b：HTML をパスワード付き zip にする
- 渡し方
  1. 案ア：端末の共有の画面（Web Share）で渡し、使えない端末はファイルを保存してメール（mailto）を開く
  2. 案イ：メールアプリを開いてファイルを自動で添付する

## 決定
- 残し方は案A。どの画面にも左下に「意見を書く」（件数の印つき）。押すと見えている範囲を JPEG に撮り（`modern-screenshot`。DOM を SVG に写して描く。外へ送らない）、ダイアログで意見を書いて［残す］。画像は外せる。撮れなければ文だけ残す
- 置き場所は IndexedDB（`store/feedback`）。DemoData・localStorage には入れない（画像が大きい。控え・Excel・作り直しの対象外）。領域（`?space=`）ごとに別の DB。IndexedDB が使えなければ開いている間だけ覚え、意見の画面で知らせる
- 送るファイルは案a。意見の画面（`#/feedback`）で、送る人がパスワード（8文字以上）を入れて［ファイルを作る］。PBKDF2（SHA-256・31万回）で鍵を作り AES-GCM（256ビット）で暗号にする。受け取った人はファイルをブラウザで開いてパスワードを入れる。パスワードは保存しない
- 渡し方は案ア。共有できる端末（スマホなど）は［共有する］（LINE・メールなどは押した人が選ぶ）、ほかは［保存してメールを開く］（ファイルを保存し、件名と本文の入ったメールを開く。添付は人がする）。宛先はアプリに持たない
- パスワードはメールの本文に書かない。本文には「別の手段で伝える」と書く
- 送ったあと［送った意見を消す］（確認つき）。自動では消さない
- 外部送信には当たらない：送るのは押した人（共有の画面・メールアプリ）で、アプリは送らない（ADR-0017 と同じ扱い）

- 追記（2026-11-12）：呼び名を「ご意見」にする。左下に［ご意見一覧］を並べ、書かなくても一覧（#/feedback）へ行ける。残すとき、直す・再現するための記録（meta：完全な URL・見出し・見えている data-testid・操作中の部品・巻き位置・端末と環境・データの版と各一覧の件数・直前のエラー10件）を付ける。名前・住所・入力欄の中身は入れない。報告の HTML には各ご意見の「調べる手がかり」（details）と、画像なしの JSON（script#feedback-data、schema feedback-report/1）を入れる。エラーの控えは src/lib/errorLog（外へ送らない）

## 理由とトレードオフ
- 得るもの：その場で1押しで残せ、画面の名前・URL・時刻・版・端末が自動で付く。受け取る側は1つのファイルで一覧でき、修正の台帳になる。運ぶあいだは読めない
- 失うもの：依存が1つ増える（`modern-screenshot`。使うときだけ読む別のチャンク）。撮るのに2〜3秒かかる。地図のタイルなど外の画像は写らないことがある。確認ダイアログ・メニューの引き出しが出ているあいだは押せない。PC はファイルの添付が手作業
- 捨てた案
  - 案B は手数が多く意見が減る。案C はどこの話か伝わらない
  - 案b（zip）：共有の画面（Web Share）は zip を渡せない。Windows の標準で開ける zip の暗号（ZipCrypto）は弱く、強い暗号（AES）の zip は標準では開けない。zip を作る依存も増える
  - 案イ：ブラウザからメールアプリへファイルを添付する方法が無い（mailto は添付できない）
  - パスワードを同じメールの本文に書く：メールを見られた人はファイルも開けるので、閉じた意味が無くなる
