# ADR-0009：日の予定の編集と割当の手直しを1画面（日の予定）にまとめる

- 日付：2026-10-13
- 状態：採用（AI で組む操作は ADR-0063 で「予定を組む」へ）

## 背景
「予定」と「AI案」の2画面で同じ日の割当を触れ、どちらが正か分からなかった。

## 決定
1画面（`#/plan`。古い `#/schedule` はここへ）にまとめる。
- 訪問の編集・取り消し・担当の手直し・確定・地図・理由を同じ画面で扱う
- 訪問を押すと理由を出す。担当を変えるのはドラッグか担当を変えるメニュー
- 担当の列の見出しにその日の稼働時間帯と「この日だけ変更」、列の最後に「自宅まで N分」
- 「入らなかった訪問」を未割当の列にし、ドラッグ中は0件でも出す。落とすと担当と固定が外れる
- 担当ごとの順番と地図の部品（`lib/routeView.ts`・`components/routeView.tsx`）は予定と比較で共通

## トレードオフ
- 失うもの：画面が縦に長い。休みの人の列は出ない。ドラッグ中の予告は必須の条件だけ（時刻の不一致は移したあとに違反として出る）
- 見直す条件：AI を使わずに担当を決めたい声が多いとき
