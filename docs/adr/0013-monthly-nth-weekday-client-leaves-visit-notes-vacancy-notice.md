# ADR-0013：第N曜日・曜日ごとの時刻、〈利用者さん〉の休み（派生で外す）、訪問先の決まりごと、空き枠の案内文

- 日付：2026-10-17
- 状態：採用
- 関連：ADR-0012

## 背景
ヒアリングで出た困りごと：第N曜日を表せない・曜日ごとに時刻が違う・入院などの休みで予定が残る・鍵や駐車場の情報が別管理・空き枠の案内を手で作っている。

## 決定
- 定期パターン：`repeat: 'weekly' | 'monthly'`、`monthWeeks`（その月のその曜日の何回目。第5の無い月は作らない）、`dayTimes`（曜日ごとの開始）
- 週間のドラッグで「以降すべて」：毎月の繰り返しは第N を差の分ずらす。できない組み合わせは「この回だけ」を勧める
- 休み：`DemoData.clientLeaves`（両端を含む）。訪問は消さず、期間の訪問を派生で「休みのため無し」（domain の `leaveOn`）。compile が問題に入れないので、AI で組む・空き状況・振り直しから外れる。画面では薄く印付き、件数に数えない
- 決まりごと：`entryNote`・`keyNote`・`parkingNote`・`cautionNote`（各200字）。割当の条件には使わない
- 案内文：vacancy の `vacancyNotice(result, input)`。今週・来週は日付ごと、先4週は曜日ごとに、受けられる開始時刻の範囲
- 新項目は zod の既定値。Excel に任意の列と「訪問先の休み」シート

## 捨てた案
第N曜日を別の型にする（展開が二重）・休みで訪問を取り消す（戻す処理が要る）・決まりごとを特性にする（出す場所が定まらない）。

## トレードオフ
- 失うもの：日付指定（毎月15日）・祝日は扱わない。休みを入れても担当は自動で直らない。案内文は入れ替えれば入る枠を出さない
- 見直す条件：日付指定・祝日の要望（`repeat` に足す）
