# ADR-0013：第N曜日・曜日ごとの時刻、利用者さんの休み（派生で外す）、訪問先の決まりごと、空き枠の案内文

- 日付：2026-10-17
- 状態：採用
- 関連：PRD D64〜D67、ADR-0012（定期パターン）

## 背景
訪問看護事業所のヒアリング（2026-10-15）で出た困りごと。
1. 「第3・第4木曜」のような毎月の第N曜日は、毎週〜4週ごとのパターンで表せない
2. 同じ利用者さんでも曜日ごとに時刻が違う（月曜 9:30、木曜 15:00）
3. 入院・ショートステイで利用者さんが休んでも予定が残り、振替の漏れ・空振りが起きる
4. 鍵の場所・インターホン・駐車場の情報を別に管理していて、訪問の直前に探している
5. ケアマネから「空いている枠は？」と聞かれても即答できず、手で文を作っている

決めること：第N曜日・曜日ごとの時刻・利用者さんの休み・決まりごと・案内文の持ち方。

## 選択肢
- 第N曜日：A パターンに `repeat`・`monthWeeks` を足す／B 別の型 `monthlyPattern`／C 日付の一覧を手で選ぶ
- 曜日ごとの時刻：A `dayTimes` で曜日ごとに上書き／B 曜日ごとにパターンを分ける
- 休み：A 別の記録で派生に外す／B 期間の訪問を取り消す／C 利用者さんを休止中にする
- 決まりごと：A 固定4項目／B 自由な項目（特性）／C メモに書く
- 案内文：A 空き状況の結果から文を作る／B 問い合わせの試算の要約をそのまま使う

## 決定
第N曜日・曜日ごとの時刻は既存パターンに足す。休みは別の記録にして派生で外す。決まりごとは〈利用者さん〉の固定4項目。案内文は空き状況の結果から純粋関数で作る。

- 定期パターン：`repeat: 'weekly' | 'monthly'`、`monthWeeks`（第N＝その月のその曜日の何回目。第5の無い月は作らない）、`dayTimes`（曜日ごとの開始。無ければ共通の時刻）を持つ。回の ID・「以降すべて」・この回だけの変更は毎週のパターンと同じ
- 週間の「以降すべて」（ドラッグで曜日を変える）：毎月のパターンは第N を「落とした日の第N − 元の日の第N」だけずらす。新しい日にできない組み合わせでは「以降すべて」を断り「この回だけ」を勧める
- 利用者さんの休み：`DemoData.clientLeaves`（期間は両端を含む）。訪問は消さず、期間に入る訪問を「休みのため無し」と派生で扱う（domain の `leaveOn`）。compile は休みの訪問を問題に入れないので、AI で組む・空き状況・混み具合・振り直しから外れる。画面では薄く印付きで出し、件数には数えない。休みを消せば元に戻る
- 決まりごと：`entryNote`（入り方）・`keyNote`（鍵）・`parkingNote`（駐車場）・`cautionNote`（注意）。各200字。スタッフ画面・訪問の詳細に出す。割当の条件には使わない
- 案内文：vacancy の `vacancyNotice(result, input)`。今週・来週は日付ごとに、その日に1人以上が受けられる開始時刻の範囲。先4週は曜日ごとに、どの週も受けられる開始時刻の範囲。案の無い日は文に入れず注記する
- データの版・Excel：新項目は zod の既定値。Excel は「定期パターン」に任意の列、〈利用者さん〉に4項目、新シート「訪問先の休み」

## 理由とトレードオフ
- 得るもの：月の手入力をやめられ、引き継ぎがパターンの一覧で読める。休みは訪問を書き換えないので、消すと元に戻りパターンの計算とも重複しない。compile の1か所で漏れなく外れる。案内文は画面の表と食い違わず、単体テストで固定できる
- 失うもの：
  - 日付指定（毎月15日）・祝日は扱わない
  - 休みの訪問はデータに残る（判定は毎回）。休みを入れても担当は自動では直らない
  - 決まりごとは割当の条件にならない（「駐車場なし → 自転車の人」は特性・条件で表す）
  - 案内文は開始できる時刻の目安で、入れ替えれば入る枠は出ない
- 捨てた案：第N曜日B は展開・画面が二重になる。休みB は休みを消すとき取り消しを戻す処理が要り、取り消しの記録と混ざる。決まりごとB は出す場所が定まらない
- 見直す条件：日付指定・祝日の要望（`repeat` に足す）。休みの訪問を本当に消したい声。案内文の敬語・載せる範囲はデモの反応で直す

## 影響
- 主なモジュール：contracts（`clientLeaves`・`clientSchema` の4項目・パターンの `repeat` 他）、`src/patterns/`、domain（`leaveOn`）、matching、vacancy（`vacancyNotice`）、excel
- PRD §4：日付指定（毎月15日）・祝日はやらない
