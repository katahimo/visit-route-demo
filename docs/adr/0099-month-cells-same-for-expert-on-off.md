# ADR-0099：月のマスはエキスパート機能の入切で同じ表示にする

- 日付：2026-11-04
- 状態：採用
- 関連：ADR-0079（月のマスは例外だけ。この部分を置き換える）・ADR-0073・0077

## 背景
ADR-0079 は初回の「担当なしの赤で埋まる」印象を避けるため、切の月のマスを例外だけ（日付・件数・要対応の札・休 N）にし、種類の積み上げ・混み具合・理由の旗・吹き出し・右の要対応の一覧を入だけに残した。その後、デモは組み終えて始まる（ADR-0079 の前半）ので初回の赤は減り、切だけマスの中身が少ないことが次の問題になった。入切で同じ月が違って見え、切で理由（担当なし N など）や混み具合を見たいとき入にするしかない。入切の差は `lib/exceptionView` の `monthCellView` に集まっていたが、マス・一覧・右の欄・見出し・「詳しく」の凡例に分岐が散っていた。

## 選択肢
1. 案1：月のマスは入切とも同じ表示にし、差は確定の段階（鍵・確定の言葉）だけにする
2. 案2：切のままにして、出すものを設定で選ばせる
3. 案3：入も例外だけにそろえる

## 決定
案1を採る（PRD D433。D410 を置き換え）。
- 種類の積み上げ・混み具合・休みなどの印・理由の旗・マスの吹き出し・日ごとの一覧の行・右の欄の要対応の一覧・「詳しく」の凡例を、入切とも出す。`MonthCellView`・`monthCellView`・`MONTH_ASIDE_PICK_TEXT`・見出しの ⓘ（`MonthCellHint`・`monthCellHint`）は無くす
- 切は確定の段階が無く、日が自動で「伝えた」扱いになるので、確定の鍵・「まだ伝えていない」「確定済み」「未連絡」の言葉は出さず、決まったあとの変更だけ「変更あり」で出す（`lib/settledView` の `shownDayState`・`dayStateText`・`changesText`）。読み上げ・吹き出し・マスの見方の説明・凡例も同じ
- 切の月の要対応の数え方は上の帯とそろえたまま（`useMonthDays` の `exceptionStatus`。D404）

## 理由とトレードオフ
- 得るもの：入切で月の見え方が同じになり、分岐が1か所の確定の段階だけになる。切でも理由と混み具合が月で見える。画面の分岐とテストが減る
- 失うもの：切の月のマスの情報量が増え、ADR-0079 が狙った「読む量が少ない」は戻る（デモは組み終えて始めるので、初回の赤の量は増えない）
- 見直す条件：切の利用者から月のマスが読みにくいという声が出たとき
