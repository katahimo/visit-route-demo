# ADR-0052：〈利用者さん〉・〈スタッフ〉の画面を全画面にし、予定のカレンダーと節ごとの「直す → 保存」にする

- 日付：2026-10-22
- 状態：採用（タブのまとめ方は ADR-0054）
- 関連：ADR-0026・0048・0051

## 背景
人の画面は右の欄で、その人のこれからの訪問が見えず、繰り返しと休みだけ押した時点で保存されていた。

## 決定
- ルート：`#/clients/:id`（`pages/ClientPage`）・`#/staff/:staffId`（`pages/StaffPersonPage`）。`new` は新しい人。古い `?id=` は一覧が `replace` で移す
- 殻：名前と状態・一覧へ戻るリンク・タブ（`PersonTabs`。`?tab=`）
- 予定のタブ：`components/PersonCalendar`（週の時間軸・月のマス・狭い画面の日ごとのリスト）。回は `lib/personPage` で作り、押すと訪問の詳細の欄。〈利用者さん〉の広い画面だけ空き枠から新規・回のドラッグで日時を変えられる
- 繰り返し・休みも保存を押すまで書かない
- 節：`EditSection`（読む ⇄ 直す → 保存・取り消し・Esc）。保存した項目だけ重ねる（`mergeFields`）。検査・正規化は節をまたいで同じ
- 変更の確認：取り消す・Esc・別の節・タブ・リンク（`useLeaveGuard`）・別の人の URL・再読込で確かめる。ブラウザの戻る・進むは黙って捨てる

## 捨てた案
右の欄のまま一覧を足す（狭い）・閲覧と編集を別の形に分ける（画面と経路が増える）。

## トレードオフ
- 失うもの：隣の人を開くのに1手多い。新しい人は基本の節だけで作る。〈スタッフ〉のカレンダーでは足す・動かすをしない
