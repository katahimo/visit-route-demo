# ADR-0107：〈スタッフ〉の休みを Google カレンダーの書き出しから毎日取り込む

- 日付：2026-11-07
- 状態：採用（取り込み直しの動きは ADR-0108 で入れ替えに改めた）
- 関連：ADR-0011・0014・0073・0084・0016

## 背景
事業所は〈スタッフ〉ごとに Google カレンダーを持ち、休みを「休み」「AM休み」「PM休み」などの予定で入れている（時刻つき・終日・毎日の繰り返しと1回だけの直しが混じる）。同じ休みをこのアプリにも入れ直すと手間と入れ忘れが出る。休みは日々変わるので、取り込みは毎日する。Google カレンダーは「設定 → エクスポート」で、カレンダーごとの .ics をまとめた zip を書き出せる。中身に実在の人の名前が入るので、公開リポジトリには置かない。

## 選択肢
1. 案A：書き出しの zip をそのまま選んで読み、カレンダーから入れた欠勤をカレンダーに合わせる（入れる・直す・外す）
2. 案B：Google カレンダー API で直接読む
3. 案C：貼り付け（ADR-0084）に、カレンダーの予定を文にして貼ってもらう

## 決定
案A。
- 入口は予定（月・週・日）の操作の行の「休みを取り込む」（入切とも）と、登録の案内②（〈スタッフ〉の名簿の下）。毎日使うので「その他 ▾」に入れない（「主ボタン1つ＋ボタン1つまで」の例外。ボタンは主ボタンにしない）
- カレンダーの名前を〈スタッフ〉の名前に当てる（空白・全角半角・かなの違いは問わない）。合わないカレンダー（事務所の共有など）は読まず名前を出す
- 件名に 休み・休業・産休・育休・欠勤・希望休・有休・有給・公休 のある予定を、今日から93日分、その日の欠勤にする。終日は終日（AM・PM は午前・午後）、時刻つきは30分単位に広げる
- カレンダーから入れた欠勤は ID を `cal-〈スタッフ〉-日付` にして見分ける（契約の型は変えない）。取り込み直すと同じ日は直し、カレンダーから消えた日は外す。手で入れた欠勤・過ぎた日は変えない
- zip は依存を足さずにブラウザ標準の `DecompressionStream` で開く。ファイルは端末の中で読むだけで送らない
- `.gitignore` に `*.ics`・`*.ical.zip` を足し、実データを誤って置かない。テストは架空のカレンダーだけ

## 理由とトレードオフ
- 得るもの：書き出した zip を選ぶだけで休みが入り、毎日の取り込み直しで直した・消した休みも合う。サーバー・ログイン・外部送信なし（ADR-0001・0016）
- 失うもの：書き出しは手で行う（自動では取りに行かない）。名前がアプリとカレンダーで違うと当たらない。件名の決まりから外れた休みは読まない。手で入れた欠勤とカレンダーの休みが同じ日にあれば手のほうを残す
- 案B を捨てた理由：OAuth・API キーが要り、ログインしない・外へ送らない決まりに反する
- 案C を捨てた理由：カレンダーの予定を文にする手間が残り、繰り返しを読めない

## 影響
- PRD D440。PRD §4 の「欠勤の複数日の一括入力をしない」をこの入口に限って外す（ADR-0084 と同じ）
- 見直す条件：名前の当たらないカレンダーが多いとき（当てる表を持つ）、取り込みの日数が足りないとき
