# ADR-0057：訪問の札を3段の大きさと3種類の入れ物にし、週の表のマスに札を積み、月のマスは右のリストへつなぐ

- 日付：2026-10-23
- 状態：採用
- 関連：ADR-0051・0054・0056

## 背景
週の表は訪問が多いとマスが縦に長く、月はマスを押すと日の予定へ移るしかなかった。帯の見せ方の決まりが無く、画面ごとに形が増えていた。月のマス（42個）は軽い描き方のままにする。

## 決定
- 札は3段：大（`data-size="l"`。時間軸の帯）・中（`VisitRow`。`m`）・小（`VisitChip`。`s`）。印・選ぶ・キー・ドラッグ・元に戻すは同じ部品
- 入れ物は時間軸・表（`ChipStack`）・リスト。キーの読み方は入れ物で決める（`KeyLayout`）：時間軸とリストは ↑↓ 15分、表は ↑↓ で隣の担当
- 週の表：マスに小さな札（時刻と頭文字・担当の印）を時刻順に3件まで積み、残りは「+N」（モーダルにしない浮いた欄）。別のマスへドラッグすると担当（行）と曜日（列）が変わる。〈スタッフ〉×曜日の3段バーと件数は残す
- 月：マスは「その日のまとめ」のまま。押すとその日の訪問を右の欄の先頭にリストで出し、もう一度押すと日の予定。リストの行を別の日のマスへドラッグ、または複数選んで「別の日へ」（`moveManyToDate`。この回だけ・今日より前へは移さない）
- スマホの月は下から出る欄にその日の行（担当替え・取り消しまで）

## 捨てた案
今のまま（困りごとが残る）・1本の本体に作り直す（分岐が増える）。

## トレードオフ
- 失うもの：〈利用者さん〉×曜日の3段の帯は無い。月のマスを1回押しても日の予定へ移らない。札は名前の頭文字だけ
- 見直す条件：「+N」を押す回数が多ければ1マスの件数を見直す
