# ADR-0011：当日の急な欠勤を別の記録で持ち、他の人の予定を変えずに空き時間へ振り直す

- 日付：2026-10-13
- 状態：採用（振り直しの結果を訪問に書く形は ADR-0053、入口の欄は ADR-0025・0038）
- 関連：ADR-0007・0010

## 背景
当日の欠勤（終日・途中）で、他の人の予定を極力変えずに欠勤者の訪問を振り直したい。全部組み直すと無関係な人まで変わり、連絡が増える。

## 決定
欠勤は別の記録で持ち、案A（挿入だけ）で振り直し、「少し動かしてよい」案B を選べるようにする。処理は `reassign` に置く。
- データ：`DemoData.absences`（`{ id, staffId, date, from, to, note }`。null は始業から／終業まで、両方 null で終日）。30分単位、1人1日1件。Excel に「欠勤」シート
- 差し引き：働ける時間帯を決めるのは `domain/availability.ts` だけ。compile が欠勤を差し引き、`Problem` の形は変えない
- 元の案：確定した割当があればそれ、無ければ今の担当
- 振り直す訪問：欠勤と重なる欠勤者の訪問すべて・欠勤で可でなくなる訪問・残すと strict で回れない訪問
- 案A：他の人の担当・順番・開始時刻を変えず、入れられる人の少ない順に、費用の増えが最小の strict の位置へ1件ずつ入れる。時刻は変えず、件数の上限は超えない。決定的で Worker 不要
- 案B：`Problem.stay` の重み w（0〜5・既定3。担当替え1件＝w×10点、開始のずれ1分＝w×0.2点）を solver の費用にだけ足す。採点には入れない。案A を初期解に渡す
  - 案A に入った訪問は落とさない（`ProblemStay.keep` は `KEEP_DROP_POINTS`＝`DROP_POINTS`×10）
  - 保険（`settleAnneal`）：keep が欠ける・案A の費用が有限でない・案B が案A より高い なら案A を返す
  - 案A に可でない組・回れない・上限超えの列がある人はその列を案A のまま外し「手で直してください」
- 結果：担当のいる訪問をすべて固定。続けて振り直すときは最初の元の案を引き継ぐ（差・「元に戻す」も最初の元の案に対して）。欠勤の取り消しでは担当を戻さない
- 候補から入れる（`placeVisit`）：後ろの訪問が遅れる件数・最大の分を出し、押したとき確認
- 連絡の一覧：元の案と今の案の差から、担当・時刻が変わる訪問先と増減するスタッフ、連絡文（コピー・印刷のみ）
- 「いまの時刻」は扱わない（過去の欠勤は登録しない運用）
- 欠勤者のまま残る訪問に数えるのは欠勤のせい（absence・unreachable）だけ。notAllowed は必須の違反で出す

## 捨てた案
稼働時間の上書きに書く（元に戻せず理由が残らない）・全部組み直す（無関係な人まで変わる）。

## トレードオフ
- 失うもの：案A は全体最適でない。他の訪問を外さないと入らない訪問は案B でも入らない。時刻は30分単位に丸める
- 見直す条件：手で入れる手間が大きいとき。1日に複数の欠勤が要るとき。案B が遅い（30人・150件で数秒超）とき
