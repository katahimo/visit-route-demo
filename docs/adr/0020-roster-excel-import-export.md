# ADR-0020：Excel の名簿（〈利用者さん〉・〈スタッフ〉のシート1枚）を、予定を消さずに足す・直す

- 日付：2026-10-18
- 状態：採用（置き場所と最終勤務日の知らせは ADR-0068 で置き換え）
- 関連：ADR-0006

## 背景
全体の読み込みは全シートの置き換えで、人を1人足すたびに組んだ予定が消えた。

## 決定
名簿（シート1枚）の書き出し・読み込みを足し、今のデータに当てて足す・直す。全体の読み込みは今のまま。
- 名簿のブックは全体のブックの同じシートと同じ列・書式。全体のブックもそのシートだけを名簿として読める
- 読み込み方は「追加・更新」（既定）と「総入れ替え」。総入れ替えでもブックに無い人は消さず、〈利用者さん〉は段階「終了」、〈スタッフ〉は休止
- 同じ人：ID があれば ID、空なら名前（全角半角・空白を同一視）
- ブックに無い列は今の値のまま。知らない列・いない人の名前・名前の重なりは場所付きのエラーで止め、何も変えない
- excel は純粋な変換（新しい DemoData と件数を返す）。画面が件数を確かめて store の `update` で入れ、`migrate`（repair）で整える
- 確認に、休止で「担当できる人」から外れる〈利用者さん〉を出す。総入れ替えで半分を超えて外すときは強い注意
- 新しい人の空の段階は利用中
- 契約は `RosterKind`・`RosterMode`・`RosterImportResult` だけ足す

## 捨てた案
全体の読み込みに「予定を残す」を足す（突き合わせが重い）・名簿も全置き換え（その人を指す訪問の扱いが難しい）。

## トレードオフ
- 失うもの：ID を消して名前を変えた行は別の人になる。総入れ替えでも人は減らない
- 見直す条件：ほかのシートも部分的に入れたい声。名前の取り違えが起きたら ID を必須に
