# ADR-0074：エキスパート機能が入の画面も切の作りを土台にする

- 日付：2026-10-31
- 状態：採用・一部を ADR-0078・0080・0100 で置き換え（メニューと下のタブの空き状況。「組む」の子・基本情報のタブ・段）。担当なしを組む入口は ADR-0077
- 関連：ADR-0029・0041・0053・0067・0072・0073

## 背景
入の画面はメニュー13項目・ホームのカード20枚・同じ件数の重複・日の予定の操作31個などで、ごちゃごちゃしていた。入では専門の機能（点数・移動・守れない条件・確定（伝えた）・組み方の標準・案を比べる・条件の重み）を消さない。

## 決定（利用者が決めた）
画面の骨組みは切と同じにし、切の部品（`exceptionView`・`peopleView`・要対応の帯・「詳しく ▾」・「その他 ▾」）をそのまま使う。入の差は部品の中の1か所に足す。機能は消さず、場所を変える・畳む・既定で閉じる。

### メニュー・帯
- 入のメニューは 予定・空き状況・〈利用者さん〉・〈スタッフ〉・組む・設定（空き状況は ADR-0078。判定は `lib/nav` の `menuSections` の1か所）。「組む」だけが子（基本情報・組み方の標準（登録後は出さない）・担当を組む）を持つ
- 件数の印は「組む」の親の行に1つ（組み直しの知らせ、無ければ担当なしの日の数）
- 下のタブは 予定・〈利用者さん〉・〈スタッフ〉・組む・探す・メニュー（`bottomTabKeys(features)`）
- ホームは無い。`#/home`・`#/`・知らない URL・切った機能の URL は `homePath(features)`（繰り返しを使うなら月、使わないなら週）
- 要対応の帯（`lib/attentionBand`）に入だけの種類：条件に合わない・拘束超・組み方の標準が無い・基本情報が変わった（標準の登録後だけ）・未確定 N日（今日から翌月末）。押した先は並びの先頭の種類
- ツアーは 予定・欠勤 の2枚

### 予定の操作の行と「詳しく ▾」
- 操作の行は切の `ToolbarRow` を入にも使い、差は `lib/exceptionView` の `mainTools(zoom, avail, expert)` の1か所。月・週＝主「予定を入れる」（`AddPlanPanel`）＋「担当を組む」、日＝主「予定を入れる」＋「確定（伝えた）」（`AdoptButton`）。スマホの日は確定が主
- 「その他 ▾」の入の中身：欠勤・キャンセルを登録・元に戻す／やり直す・表示の切り替え・使い方・メールで送る（週・日）・印刷・勤務の見込み
- 「詳しく ▾」は `components/DetailsFold`。閉じて始め、開け閉めは月・週・日ごとに端末に覚える（`store/navOpen` の `details:<画面>`）。入は見出しの1行に数（`lib/detailsHeading`）：月＝担当・確定の日数、週＝未確定・要対応、日＝点数・移動・入らない・守れない条件
- 畳むもの：月＝進み具合の帯・件数・凡例、週＝状態の1行・凡例、日＝今の担当の1行・担当ごとの1日・要対応の訪問の帯
- 札のピン・資格✗・限✗の印、日の時間軸の移動・待ちの線は残す。担当なしの札の理由は「理由 N ▾」
- 画面の上の説明は入切とも1行・初回だけ（`useIntro`）
- 入の日の予定の地図は全幅のカードのまま（凡例と大きさを持つため）

### 人
- 人のタブは入切とも同じ（`PeopleTabs`）：〈スタッフ〉＝一覧・勤務・相性、〈利用者さん〉＝一覧・相性。相性は来た側のタブ（`components/peopleSide`）
- 予定を組むの段は「組む」の画面（`/basics`・`/standard`・`/arrange`・`/compare`）だけ。基本情報のタブは 予定と相性・相性・勤務時間（シフト）の3つ（`basicsTabs(features)`）
- 一覧は入切とも3列（`clientColumns(detailed)`・`staffColumns(detailed)`）。入だけ「くわしい列」（`components/DetailColumns`）で専門の列を足し、一覧ごとに端末に覚える（`columns:clients`・`columns:staff`）
- 一覧の見出しはメニューの名前（「利用者さん」「スタッフ」。`org.terms`）

### 設定
- スイッチの行は名前と1行の説明。「切ると隠れるもの」と依存の注記（入のとき）は ⓘ（`Hint`）の中。押せない理由は行に出す（`lib/settingsView` の `featureRowText`）
- ひな形は見出しの横に今のひな形の名前（`currentTemplateName`）、一覧と「適用」は `DetailsFold` の中
- メールの予約送信は説明1行、詳しい説明は ⓘ、手順4つは `DetailsFold`
- 設定の開け閉めは覚えない

### e2e
- 共通の手 `scripts/lib/ui.cjs`（画面へ行く・メニューを押す・操作の行のボタン・「その他 ▾」・「詳しく ▾」）。画面が変わっても表の1か所を直す。位置は `pressTool` の `where: 'row'`・`'more'`

### 週のナビの行・畳み
- 週のナビの行の状態（`week-next-status`）は「未確定 N日」「確定済み」だけ、理由（`week-next-why`）は1行。詳しい数は「詳しく ▾」と要対応の帯
- 畳みの計測（`components/useChipFold.ts`）の測り直しの鍵は `lib/fold` の `chipFoldKey`・`nextFullHeight`（幅・中身の高さ・書体・チップの表示）

## 捨てた案
入の画面を個別に削る（二つの画面が残る）・表示の密さを別の切り替えにする（組み合わせが倍）・ホームを残す・入は「詳しく」を既定で開く（縦の長さが戻る）。

## トレードオフ
- 失うもの：入の人は進み具合・日の状態を開く手間が1回増える。ホームの「今日やること」は無い
- 見直す条件：入の人が「点数・移動・確定が見つからない」と言うなら見出しの数・覚えを見直す
