# ADR-0034：画面名をメニューの名前にそろえ、欠勤の入口の呼び名を1つにする

- 日付：2026-10-19
- 状態：採用（メニューの項目は ADR-0074・0078）

## 背景
同じ画面に名前が2つ3つあり（月・月間・月の画面など）、欠勤の入口の呼び名も4通りあった。

## 決定
- 画面名はメニュー・見出し・本文・ツアー・パレットで「月の予定／週の予定／日の予定」。人の画面は「勤務時間（シフト）」（〈スタッフ〉の働ける時間の値・Excel の「稼働時間」は今のまま）と「勤務の見込み」（交通費の入り切りで変えない）
- 欠勤の入口はみな「欠勤・キャンセルを登録」、列の見出しは「この人の欠勤を登録」「欠勤を直す」
- 管理者設定の機能のグループ（`lib/features.ts` の `FEATURE_GROUPS`）はメニューとは別に持つ
- パレットは前の名前も別名で引ける
- 変えないもの：URL（`#/month`・`#/week`・`#/plan`・`#/workload`・`?do=absence` ほか）・データ・機能の ID・Excel のシート名・［月｜週｜日］の切り替え・欄の見出し「欠勤・キャンセル」

## 捨てた案
見出しを「月／週／日」に（本文で指しにくい）・「勤務と交通費の見込み」（入り切りで画面名が変わる）・「急な欠勤」（希望休と同じ登録なのに「急な」が付く）。

## トレードオフ
- 見直す条件：狭い画面で名前が入らないならメニューだけ短くする
