# ADR-0036：画面の見出しを1つの型にし、ボタンを塗り・枠・文字の3段に分ける

- 日付：2026-10-20
- 状態：採用（予定の3画面の切り替えは ADR-0060）

## 背景
見出しの段が積まれて本体が下に押し出され、主ボタンに見えるものが複数あった。

## 決定
- 見出しは `PageHeader`（題名・1行の説明・右に主ボタン1つまで）。タブは画面が移るリンクのナビ（`aria-current="page"`）
- ボタンの3段：塗り＝主（`.btn-primary`。1画面に1つ）／枠＝副（`.btn`）／文字＝ついで（`.btn btn-text`。灰 `--sub`）。押せる大きさは同じ
- 「欠勤・キャンセルを登録」は枠にし、アイコンだけ朱
- 日の予定の主は「この割当で確定」。確定済みの日は主ボタンを置かない
- 行を詰めるのはタッチ・ペンを持たない端末（`pointer: fine` かつ `not any-pointer: coarse`）だけ。どれか1つでもタッチがあれば押せる所を 44px
- 左のメニューは項目 34px・グループの間 10px（1440×900 で巻かずに見せる）

## 捨てた案
塗りを2色（どちらが主か迷う）・担当ごとの1日を畳む（開かないと見えない）。

## トレードオフ
- 見直す条件：〈スタッフ〉が多く担当ごとの1日が本体を押し出すとき
