# ADR-0045：見せる量を減らす：設定を1つのタブ群に、操作の行の「その他 ▾」

- 日付：2026-10-21
- 状態：採用（初回の問いは ADR-0073、ツアーは ADR-0073・0074、操作の行は ADR-0058・0074 で置き換え）
- 関連：ADR-0024・0028・0036

## 背景
メニューの項目・初回の案内・操作の行のボタンが多かった。たまにしか開かない設定がメニューに独立して並んでいた。URL と保存データのある人の入り切りは変えない。

## 決定
- 設定はメニューの「設定」1項目と、画面の上のタブ（今は 訪問の種類・特性の項目・管理者設定・データ。`lib/nav` の `settingsTabs`・`components/SettingsTabs`）。最後に開いたタブを開く。URL は変えず、パレットは1画面ずつ引ける
- 機能の入り切りは案を作る前に入れる（`createInitialData(today, features)`）。「初期状態に戻す」は今の入り切りを残す
- e2e・デモの前準備に、別のキー `vrdemo:features:start` が `all` なら初回もすべて入で始める（画面からは書けない）
- 操作の行は主ボタンと毎日使う操作だけ、ほかは「その他 ▾」（`MenuButton`）

## 捨てた案
契約の既定値を変える（古いデータの画面まで変わる）・設定を1画面にまとめる（URL・部品の作り直し）・メニューのグループを畳む（探す手間が変わらない）。

## トレードオフ
- 失うもの：設定の各画面へは1手増える（パレットでは1手）
