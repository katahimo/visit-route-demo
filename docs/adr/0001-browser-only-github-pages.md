# ADR-0001：デモ版はブラウザ完結の静的サイトにし、新リポジトリで作る

- 日付：2026-10-11
- 状態：採用（公開先は ADR-0071 で置き換え）

## 背景
PoC本体（Firebase・Cloud Functions・Python 最適化）はデモの更新に手順と費用がかかる。触ってもらい、直すサイクルを速く回したい。

## 決定
新リポジトリに画面と純粋関数を写し、保存は localStorage、最適化は Web Worker で動かす静的サイトにする。
- PoC本体の規約（`orgs/{orgId}` 配下・Callable・Firestore ルール）は適用しない
- 置くのは架空データだけ
- デモで固まった仕様は PoC本体の PRD に戻す

## 捨てた案
PoC本体の Firebase デモ環境を使う・PoC本体のモノレポに足す：更新が遅く、PoC本体の CI・規約に縛られる。

## トレードオフ
- 得るもの：費用0円・ログイン不要・PoC本体に縛られない
- 失うもの：記録・勤怠は見せられない。PoC本体とのコードの二重管理
- 見直す条件：記録・勤怠もデモで見せる必要が出たとき
