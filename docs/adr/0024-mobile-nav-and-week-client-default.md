# ADR-0024：スマホは上の帯・引き出し・下のタブでメニューを出し、週の時間軸の〈利用者さん〉は先頭8人を初期値にする

- 日付：2026-10-18
- 状態：採用（下のタブの項目・メニューの並びは ADR-0045・0054・0063）
- 関連：ADR-0021・0033

## 背景
幅860px以下では左のメニューが横一列になり、巻かないと見えなかった。週の時間軸の「〈利用者さん〉で見る」は開くたびに選び直す手間があった。

## 決定
- 狭い画面：上の帯に今の画面の名前、左から出る引き出し（`app/NavDrawer.tsx`）に全メニュー、下によく使う画面のタブ。広い画面は変えない
- 今の画面の判定・帯の名前・タブの選び方は `lib/nav.ts` の1か所。今の項目を押し直しても移り直さない
- 引き出しは `SidePanel` と同じ閉じ込め・フォーカスの戻し方。裏のロックは数を数える `lib/scrollLock`
- 下のタブの高さは `--bottom-tabs-h`。浮く部品・トーストはこれで避ける。safe-area も避ける。印刷では出さない
- 週の時間軸：この週に訪問がある人をチップ（`PickChips`）で並べ、`?client=` が無ければ先頭8人を初期値（URL に書かない）。決まりは `lib/timelineClients.ts`。残りは「あと N人」で畳む（`lib/fold`）

## 捨てた案
横一列のまま見出しだけ出す（巻くのが残る）・下のタブだけ（「その他」がもう1画面になる）。初期値を URL に書く（週を送ると前の週の人が残る）。

## トレードオフ
- 失うもの：下のタブのぶん本文が狭い
- 見直す条件：スマホで予定を直す使い方が増えたとき。訪問のある人が数十人でチップが長すぎるとき
