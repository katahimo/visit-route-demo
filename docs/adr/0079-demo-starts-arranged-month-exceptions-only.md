# ADR-0079：デモは担当を組み終えて始め、月のマスは例外だけにする

- 日付：2026-11-01
- 状態：採用・一部を ADR-0099 で置き換え（月のマスは例外だけ。デモは組み終えて始める点は ADR-0079 のまま）
- 関連：ADR-0072・0073・0074・0077

## 背景
初めてデモを開くと月の予定が「担当なし 418件」の赤で埋まり、第一印象が「エラーだらけ」になる（2026-11-01 の画面の確認）。月のマスには要対応の札・「担当なし N」・理由の行・種類の積み上げ・3段の混み具合・吹き出しが重なり、何も起きていない日まで読む量が多い。右の欄の「要対応」の一覧は上の要対応の帯と同じ数を2か所で見せている。利用者（管理者）が月で知りたいのは「手当ての要る日はどこか」だけ。

## 決定
- **デモは組み終えて始める**：最初の2問で「デモで試す」を選んで「はじめる」・最初の設定をやり直す・デモの初期状態に戻す、のあと、今日〜翌月末の担当なしを今の条件で自動で1回組む（要対応の帯の［担当なしを組む］と同じ処理・知らせ・元に戻す。D403）。組めずに残る訪問はそのまま要対応に出す。「自分のデータで始める」と、e2e の印「all」で始めるときは組まない
- **月のマスは例外だけ**（エキスパート機能が切）：マスに出すのは 日付・訪問の件数・要対応の札（N）・休 N（D295 の決め方）・今日の印だけ。種類の積み上げ・3段の混み具合・「担当なし N」などの理由の行は出さない（理由は押した日の右の欄と日の予定で見る）。マスの読み方は見出しの ⓘ に移し、吹き出しはマスに出さない（読み上げの文は残す）。右の欄は日を押す前は「日を押すとその日の訪問が出ます」の1行で、要対応の一覧は出さない（上の帯が件数の正。D404）
- 入はいまのまま（積み上げ・混み具合・右の要対応の一覧を残す）

## 捨てた案
- アプリを開くたびに自動で組む：PRD §4（ADR-0072）のとおり、黙って担当を変えない。組むのはデモを作った直後の1回だけ
- 初期データ自体に担当を入れて同梱する：条件や日付（今日から）に合わず、すぐ古くなる
- マスの理由の行を残して色だけ弱める：読む量が減らない

## トレードオフ
- 得るもの：初回に「組まれた予定」が見える。月で目に入るのが手当ての要る日だけになる
- 失うもの：デモの開始が組む時間（数秒）だけ遅れる。「担当なしを組む」の体験が初回に出ない（帯は組めずに残った分があれば出る）。切の月で種類の内訳・混み具合が見えない（入にすれば見える）
- 見直す条件：デモで「組む前」を見せたい声が多いとき、切でも混み具合を見たい声が出たとき
