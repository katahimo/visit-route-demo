# ADR-0047：相性を設定から人の側へ移し、設定のトップを訪問の種類にする

- 日付：2026-10-21
- 状態：採用（人の画面のまとめ方は ADR-0054・0074）
- 関連：ADR-0036・0045

## 背景
設定の先頭がめったに触らない「条件の重み」で、ふだん更新する相性が設定の中で見つけにくかった。

## 決定
- 相性は設定から外し、〈利用者さん〉・〈スタッフ〉の側（今は人のタブ。ADR-0074）に置く
- 設定の既定は先頭の訪問の種類（土台で切れない）
- `compat` を切ればメニュー・パレット・タブに相性を出さない

## 捨てた案
並びだけ変える（相性が見つけにくいまま）・相性を一覧の中の欄にする（別の関心が混ざる）。
