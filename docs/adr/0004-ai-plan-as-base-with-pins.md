# ADR-0004：AI の提案を土台に手直しし、手で動かした訪問を「固定」として組み直しに残す

- 日付：2026-10-11
- 状態：採用

## 背景
「AI案をもとに手で調整したい」「1人に件数が偏らないように」という要望。

## 決定
AI案を見ながら手直しでき、動かした訪問を固定（`pinned`）にして、残りだけ AI で組み直す。組み直しは利用者が押す。
- 固定は担当だけを決め、回る順番は AI（または費用の最も少ない位置）に任せる
- AI で組むとき固定の訪問は担当を変えない（matching で「その担当だけ可」）
- 負担の均等は「外れた件数の2乗」、既定の重み3、必須で「目安の上限＋1件まで」（`Problem.balance.cap`）。solver・evaluate は同じ式で数え、cap を超える手は採らない

## 捨てた案
別の画面で手直し（AI の意図が見えない）・手直しのたびに自動で組み直す（他の訪問が勝手に動く）。

## トレードオフ
- 失うもの：2乗の罰則で移動の短縮は少し減る
- 見直す条件：件数ではなく時間（分）で均等にしたい声が出たとき
