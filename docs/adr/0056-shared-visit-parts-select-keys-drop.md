# ADR-0056：訪問の帯の印・選ぶ・キー・ドラッグの落とし先の判定を共通の部品にする

- 日付：2026-10-22
- 状態：採用（週の表・月のマスの見せ方は ADR-0057）
- 関連：ADR-0051・0054

## 背景
印・複数選択・キー・落とし先の判定が画面ごとに別で、判定の食い違いが続いた。

## 決定
本体は画面ごとに残し、次を共通の部品（純粋関数＋小さなフックと部品）にする。
- 印（`lib/visitLook`・`VisitMarks`・`useVisitLooks`）：要対応・資格✗／限✗・未連絡の変更・ピン・この回だけ変更・仮押さえ。資格✗・限✗があれば同じ要対応は重ねない。取り消し・休みの回は未連絡の変更だけ。今日より前の日は要対応・資格✗／限✗を出さない
- 選ぶ（`lib/visitSelect`・`useVisitSelection`）：Shift／Ctrl＋クリック・Enter、Esc で外す。スマホは長押しか「選ぶ」。今日より前・取り消し・休みは選ばない。期間を変えたら外す
- キーで動かす（`lib/visitKeys`・`useVisitKeys`）：休み・取り消し・今日より前の回は動かさない。日時を動かさない所（〈スタッフ〉の画面）は矢印を読まない。スマホではキーを読まない
- 落とし先の判定（`lib/visitDrop`・`useVisitDrag`）：置けない（取り消し・休み・今日より前・ほかの人の行・7:00〜20:00 の外）は灰の影で落とせない。置けるが入らない（入れる人0人・担当できない人の行）は赤い影で、落とせるが要対応になる。落とすと落とした日時の訪問の詳細の欄が開く
- 1行1訪問の行（`VisitRow`）は日ごとのリスト・人の予定表・月のその日のリストで同じ
- データを書くのは store の update だけ。どの操作も全体の元に戻すの1手

## 捨てた案
1つの本体に作り直す（画面固有の部分で分岐だらけ）・画面ごとに足す（食い違いが続く）。
