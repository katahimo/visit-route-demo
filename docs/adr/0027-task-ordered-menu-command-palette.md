# ADR-0027：メニューをやりたいことの順に並べ、コマンドパレット（Ctrl+K）で画面・操作・人へ飛ぶ

- 日付：2026-10-18
- 状態：採用（メニューの並びは ADR-0045・0054・0063・0073・0074。パレットの担当・訪問の候補は ADR-0055）
- 関連：ADR-0024・0025・0034

## 背景
メニューがデータの種類で並び、やりたいことと合わず、同名の項目もあった。名前を知っている画面・人にも2〜3手かかった。

## 決定
- メニューは用途の順にし、項目は名前で見分けられるようにする。並びは `lib/nav.ts` の `menuSections` の1か所から、左のメニュー・引き出し・下のタブ・上の帯・パレットが引く
- コマンドパレット：「探す」と Ctrl+K（mac は ⌘K）で開き、画面・操作・人を名前で絞り込む。中身は `lib/commandPalette.ts`、見た目は `components/CommandPalette.tsx`。行き先は今ある URL だけ
- 〈利用者さん〉はよみでも引け、〈スタッフ〉は名前だけ。画面は呼び方のよみ（`TERM_READINGS`）・前の名前でも引ける
- 入力欄の中の Ctrl+K も開く。mac の Ctrl+K は横取りしない。右の欄・確認・引き出しが開いている間は開かない

## 捨てた案
上の帯に常設の検索欄（狭い画面で帯が2段）。

## トレードオフ
- 失うもの：〈スタッフ〉のよみは持たない（足すとデータの版が変わる）
- 見直す条件：最近使ったものを先に出したい声・〈スタッフ〉をよみで引きたい声
