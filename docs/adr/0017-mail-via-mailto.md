# ADR-0017：メール連携は mailto: でメールアプリを開くだけ（アプリからは送らない）

- 日付：2026-10-17
- 状態：採用（日のメールを作ったら確定にする・区間ごとの道順を残す段階は ADR-0059）
- 関連：PRD D91〜D96、ADR-0016（外部送信の決まり）、ADR-0018（道順リンク）

## 背景
日の予定・週の予定・欠勤の振り直しの連絡・空き枠の案内文（D67）は、画面で見るか、文をコピーして別のメールアプリ・LINE に貼っていた。宛先を選び、件名を書き、本文を貼る手間を減らしたい。
PRD §7・AGENTS.md は外部送信を地図タイルと押したときの検索だけにしており、メールの送り方によってはぶつかる。

決めること：どう送るか、どの場面か、本文の長さ、鍵の情報の扱い、宛先が無い・複数のとき。

## 選択肢
- 送り方：A mailto でメールアプリを開く／B 送信サービスの API を呼ぶ／C コピーだけ
- 長さ：A 目安を超えたら要点→本文なし＋コピー／B 長さを見ずにすべて入れる
- 鍵：A 既定オフで選んだときだけ入れる／B いつも入れる／C 入れない

## 決定
`mailto:` のリンクで OS の標準メールアプリを宛先・件名・本文入りで開くだけにする。送信は人がメールアプリで押す。

- 外部送信の決まりとの関係：mailto はブラウザが OS のメールアプリへ渡すだけで通信は起きない。PRD §7・AGENTS.md の外部送信の決まりは変えない
- 項目：〈スタッフ〉の `email`、〈利用者さん〉の紹介元の `referrer.email`（任意）。形の検査は緩く（空か、空白・@・URL を壊す文字を含まない文字 ＠ 同じ）。全角・前後の空白・「mailto:」は保存・読み込み時に直す。Excel に任意の列
- 場面（どれも主ボタンにしない）：日の予定（担当ごと）、週の予定（担当ごと）、欠勤の振り直しの連絡、空き枠の案内文（紹介元へ。To は空で BCC に並べ、宛先どうしにアドレスを見せない。目安を超えるときは宛先を分けて複数ボタン＋「宛先をコピー」）
- 本文は文字だけ（HTML にしない）。改行は CRLF。件名・本文・宛先は `encodeURIComponent`
- 長さの目安：Windows・判定できない端末は 2000字（2048字付近で切る・開かないことが知られ、余裕を見た）、iOS・Android・macOS は 8000字。`mailLimitFor` が端末から決め、判定を外したら安全側の 2000 に倒す
- 超えたとき：日の予定は要点に段階を落とし、週は曜日ごとの時刻と件数に絞る。それでも超えれば本文を入れず「本文をコピー」を並べる。本文なしでも超える（宛先・件名が長すぎる）ときは押せない（aria-disabled＋理由）
- 鍵の情報：既定では入れない。日の予定の欄の「鍵の情報も入れる」を選んだときだけ入れる（画面の状態のみで保存しない）。週・連絡・案内には入れない
- 宛先が無いとき：aria-disabled＋理由。日・週・連絡は To に1人
- 組み立ては純粋関数 `lib/mailto.ts`・`lib/mail.ts`。画面は `<a href="mailto:…">`

## 理由とトレードオフ
- 得るもの：宛先・件名・本文を書かずに済み、送る前にメールアプリで見直せる（誤送信を止められる）。外部送信・キー・費用が要らず静的サイトのまま。鍵の情報は既定で入らない
- 失うもの：
  - 端末にメールアプリが設定されていないと押しても何も起きない（コピーは使える）。送ったかどうかは分からず記録しない（PRD §4 の「通知・記録はやらない」のまま）
  - Windows の目安 2000字は日本語で本文約200字（1字が9字になる）で、決まりごとの多い日はほぼ要点になる。実機での切れ方は未測定
  - 宛先の形は緩くしか見ない
- 捨てた案：送り方B は個人の予定・住所を外へ送り PRD §7 を大きく変え、キーを公開リポジトリに置けない。C は宛先・件名を毎回書く手間が残る（長いときの逃げ道として残した）。長さB は途中で切れる。鍵B・C は漏れるおそれ／鍵を伝えられない
- 見直す条件：実機（Windows の Outlook・Gmail 既定の Chrome、iPhone のメール、Android の Gmail、macOS のメール）で切れ方を測り、`MAILTO_LIMIT_SAFE`・`MAILTO_LIMIT_LONG` と `mailLimitFor` を見直す。送ったかの記録・自動送信が要るなら別の ADR でサーバー側の送信を考える

## 影響
- 主なモジュール：`lib/mailto`・`lib/mail`、日・週・欠勤・空き状況の画面、contracts（`email`・`referrer.email`）、excel
- PRD：「メールの送信・送った記録はやらない（メールアプリを開くだけ）」。mailto は外部送信に当たらない
