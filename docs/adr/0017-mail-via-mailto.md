# ADR-0017：メール連携は mailto: でメールアプリを開くだけ

- 日付：2026-10-17
- 状態：採用（日のメールで確定にする・区間の道順は ADR-0059、予約送信は ADR-0069）
- 関連：ADR-0016・0018

## 背景
予定・連絡・案内文をコピーして別のアプリに貼っていた。宛先・件名・本文を書く手間を減らしたい。

## 決定
`mailto:` で OS のメールアプリを宛先・件名・本文入りで開くだけ。送信は人が押す。通信は起きないので外部送信の決まりは変えない。
- 項目：〈スタッフ〉の `email`、紹介元の `referrer.email`。形の検査は緩く、全角・空白・「mailto:」は直す
- 場面（主ボタンにしない）：日の予定・週の予定・欠勤の連絡・空き枠の案内文（紹介元へ BCC。長ければ宛先を分ける）
- 本文は文字だけ、改行は CRLF、`encodeURIComponent`
- 長さの目安：Windows・不明は 2000字、iOS・Android・macOS は 8000字（`mailLimitFor`）。超えれば要点に落とし、それでも超えれば本文なし＋「本文をコピー」。宛先・件名だけで超えれば押せない
- 鍵の情報は既定で入れない（日の予定で選んだときだけ）
- 組み立ては `lib/mailto.ts`・`lib/mail.ts`

## 捨てた案
送信サービスの API（個人の予定を外へ送り、キーを置けない）・コピーだけ（手間が残る）。

## トレードオフ
- 失うもの：メールアプリが無いと何も起きない。送ったかは記録しない。Windows では本文が短い
- 見直す条件：実機で切れ方を測り `MAILTO_LIMIT_SAFE`・`MAILTO_LIMIT_LONG` を見直す
