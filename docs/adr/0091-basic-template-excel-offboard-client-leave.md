# ADR-0091：「基本」のひな形に Excel の入出力・退職・担当替え・〈利用者さん〉の休みを入れる

- 日付：2026-11-03
- 状態：採用（Excel の入出力はひな形に入れるのをやめ、いつも入にした。ADR-0106）
- 関連：ADR-0028・0073・0086・0090

## 背景
最初の2問の答えで、定期は「基本」、単発は「単発のみ」（基本から作る）のひな形が当たる（D379）。ADR-0086 の「基本」では Excel の入出力（`excel`）・退職・担当替え（`offboard`）・〈利用者さん〉の休み（`clientLeave`）が切で、管理者設定で入れるまで、台帳の CSV・Excel の取り込み（一覧の名簿の欄・データの Excel の欄）、最終勤務日と担当の一括の振り直し、入院・ショートステイの休みが出ない。定期の訪問介護の顧客向けデモでは、この3つを最初から使い、顧客に管理者設定で機能を入れさせたくない。

## 選択肢
1. 案A：「基本」に3つを足す（ADR-0086 の基本を置き換える）
2. 案B：最初の2問の定期だけ「基本」に3つを足した入り切りを当て、ひな形は変えない
3. 案C：デモの前に管理者設定で入れるよう案内する

## 決定
- 案A。「基本」を 繰り返し・毎月の第N・〈利用者さん〉の休み・欠勤・キャンセル・空き状況・相性・決まりごと・退職・担当替え・道順のリンク・住所の検索・Excel の入出力 にする（ADR-0086 の基本の中身を置き換える。D424）
- 「労務・契約管理」は基本に 勤務の見込み・交通費・段階・紹介元、「月次予定・現場共有」は基本に 希望休・月の印刷・案内文・担当を限る（基本に入った機能を説明と足す分から外す。中身は今と同じか、3つが増える）
- 「単発のみ」は基本から作るので3つが入る（繰り返し・毎月の第N・決まりごとを外すのは今のまま）
- すでに保存されたデータの機能の入り切りは変えない（ひな形は「適用」・最初の設定のときだけ書く。D212）

## 理由とトレードオフ
- 得るもの：定期の訪問介護のデモで、台帳 CSV の取り込み・退職・入院の休みを設定を開かずに使える。案B と違い、最初の設定のあとも「いま：基本」と出て「カスタム」にならない
- 失うもの：「基本」と「単発のみ」の画面に Excel の欄・最終勤務日の欄・休みの欄とタブ・絞り込みのチップ「休み」が増える。単発のみ（ベビーシッター型）には入院・ショートステイの休みは要らないことが多い。前に「基本」「単発のみ」で保存したデータは、管理者設定で「いま：カスタム」と出る（ひな形を適用し直せば戻る）
- 捨てた案：案B は最初の設定の入り切りとひな形がずれ、設定に「カスタム」と出る。案C は顧客の手が増える

## 影響
- `src/lib/features.ts` の `BASIC_ON`・`TEMPLATES`、PRD D212・D379・D424、design.md の features の行
- 見直す条件：「基本」や「単発のみ」の欄が多いという声が出たとき（単発のみから休みを外すなど）
