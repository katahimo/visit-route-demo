# ADR-0008：プリセットを利用者が編集できるデータにする

- 日付：2026-10-13
- 状態：採用（開いた日の自動作成は ADR-0053・0054 で提案を出す形に置き換え）
- 関連：ADR-0002・0010

## 背景
定数のプリセットでは事業所に合わせて名前・重みを変えられない。条件ごとの達成も件数で見たい。

## 決定
- `DemoData.presets: Preset[]`（`{ id, name（1〜20字）, note（0〜60字）, weights: 条件の型 → { weight, hard } }`）。store が持ち主
- 最大6つ。最後の1つは消せない。「初期値に戻す」で初期の3種（`standard`・`travel`・`people`）
- `repair` が直す：id の重複・6つ超え・0件・重み（0〜5、0.5刻み）・必須にできない型の必須。範囲は zod で止めない
- 「重みを写して保存」で足す。同じ型の条件が複数あれば型ごとの最初の重みを残す
- 達成の件数（evaluate の `achievements`）：条件ごとに判定のある訪問を分母、満たした訪問を分子。相性は ◎・○・△・× を数える。重み0は出さない
- Excel に「プリセット」シート

## トレードオフ
- 失うもの：点数はプリセットを作ったときの条件の点と一致しない（ADR-0010）
- 見直す条件：6つより多く使いたい声が出たとき
