# ADR-0064：組み方の標準が無い間は、日の範囲を考え方ごとに組んで並べ、選んだ案を標準にする

- 日付：2026-10-25
- 状態：廃止（ADR-0065 で置き換え。標準は ADR-0100 で廃止）

## 要約
日の画面で考え方ごとの案を並べる道は、標準を決める道を1本にする ADR-0065 に置き換えた。今も有効なのは次の点。
- 初期のプリセット名は「標準」でなく「バランス」（id `balance`）。データの版3
- 提案の帯に変わる訪問の一覧（「時刻 〈利用者さん〉：今の担当 → 提案の担当」、時刻だけなら「今の開始 → 提案の開始」）
- 組み方の標準の画面の「考え方」は今の点数の基準を出す
