# ADR-0051：訪問の詳細の欄を1つにし、日時・担当・取り消し・範囲を同じ欄で扱う

- 日付：2026-10-22
- 状態：採用
- 関連：PRD D301〜D305、ADR-0012（定期パターン）・ADR-0027（コマンドパレット）・ADR-0030（担当を変える ▾）・ADR-0053（訪問が担当を持つ）・ADR-0055（スマホの下から出る欄）

## 背景
- 1つの訪問を見る・直す入口が画面ごとに別の形だった（時刻・取り消しは一覧の鉛筆だけ、担当はドラッグと「担当を変える ▾」、週は移動の欄、繰り返しは〈利用者さん〉の編集の欄）。時間軸の帯を押しても編集の入口が無く、時刻と担当を同時に変えられない
- 決定：訪問を中心に置き、どこから開いても同じ1つの欄にする。訪問の欄はホームとコマンドパレットにも置く（PRD §4 の「訪問の検索はしない」を外す）。スマホは見る・取り消す・担当替えまで（追加・移動はしない）
- デモ版なので互換性・過去データは気にしない

## 選択肢
1. 案A：今の編集フォーム・週の移動の欄・「担当を変える ▾」を残し、入口だけ足す
2. 案B：1つの欄 `VisitPanel` を作り、編集フォームと週の移動の欄を吸収する。データには薄い層 `lib/visitOps.ts` 越しに触る。日の予定の帯・カードの詳細（理由・「担当を変える ▾」）は残し、そこに「詳細・変更」を置く
3. 案C：案B に加えて、帯を押したら詳細を出さずにすぐ欄を開き、「担当を変える ▾」も欄に吸収する

## 決定
案B。
- 部品：`components/VisitPanel.tsx`（`VisitPanelProvider`・`useOpenVisit`）。App の殻に1つ置き、どの画面・パレットからでも開く（画面を移っても欄は残る）。右の欄（`SidePanel`）で、主ボタンは「保存」（新規は「追加」）の1つ。Tab は欄の中で回り、Esc で閉じ、閉じたあとのフォーカスは開いた帯（無ければ開く前の要素）。印刷では出さない
- 中身：〈利用者さん〉・日付・時刻（受けられる時間帯）・所要・種類・担当・繰り返しの回の案内・この回の変更の印（「繰り返しのとおりに戻す」）・メモ・決まりごと・道順。日時と担当は同じ保存で同時に変わる
- 担当を替える候補は「担当を変える ▾」と同じ関数（`lib/reassignMenu` の `reassignChoices`）。欄の日時で計算し直し、選んでいた人が候補から消えたら「変えない」に戻す。保存の前に `staffPickError` で選べない人・働かない人を弾く
- 範囲（繰り返しの回だけ）：「この回だけ」＝`lib/visitEdit` の `savedVisit`、「これ以降」＝`lib/week` の `moveFollowing`、「すべて」＝今日以降で最初の同じ曜日の回から「これ以降」。範囲は**同じ曜日の回**（週のドラッグと同じ処理を共有）。時刻も担当も変えない（メモだけ）なら範囲にかかわらずこの回だけ。確定（伝えた）した日が変わるなら確かめる
- 担当の範囲：この回だけ＝その日の担当の並びに入れてピンにする（「担当を変える ▾」と同じ置き方）。これ以降・すべて＝分けた繰り返しの担当にする。担当なしは「この回だけ」だけ
- 今ある訪問の〈利用者さん〉は欄で変えない（変えるなら取り消して足し直す）
- 開いている間に別のタブ・操作で同じ訪問が変わったら、保存・取り消しをせず「別の操作で変わりました」と出す（古い入力で上書きしない）
- 書き込み：`lib/visitOps.ts`（純粋関数。新しい DemoData を返し、欄が store の `update` で当てる）。データの形を変えても `visitOps` の差し替えで済む
- 開く所：日の予定の帯・カード・一覧の行、週の予定の帯と表の訪問（ドラッグで落とすと落とした日時で欄が開き範囲を選ぶ）、月の予定の「この月の回」、人の画面のカレンダー、ホームの「今日の訪問」「これからの入らない訪問」「訪問を追加」、コマンドパレットの「訪問」（〈利用者さん〉の名前・よみ＋日付。名前だけなら今日以降の近い回）と「訪問を追加」
- 狭い画面（600px 以下）：見る・取り消す・担当替えだけ（日時の変更・範囲の選択・新規は出さない）

## 理由とトレードオフ
- 得るもの：どこから開いても同じ欄で、時刻と担当を同時に、繰り返しの範囲つきで変えられる。週のドラッグと欄が同じ処理（`moveFollowing`）を使う
- 失うもの：
  - 日の予定の帯・カードの詳細が残るので、帯から欄までは2回押す。手直しの動き・e2e を壊さないための割り切り
  - 「これ以降」「すべて」は範囲の回を作り直す（ID が変わる）
  - 曜日が2つ以上の繰り返しでは、範囲は開いた回の曜日だけ
