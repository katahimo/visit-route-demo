# ADR-0051：訪問の詳細の欄を1つにし、日時・担当・取り消し・範囲を同じ欄で扱う

- 日付：2026-10-22
- 状態：採用
- 関連：ADR-0012・0030・0053・0055

## 背景
1つの訪問を見る・直す入口が画面ごとに別の形で、時刻と担当を同時に変えられなかった。

## 決定
1つの欄 `VisitPanel`（`components/VisitPanel.tsx`。`VisitPanelProvider`・`useOpenVisit`）を App の殻に置き、どの画面・パレットからも開く。データには `lib/visitOps.ts`（新しい DemoData を返す純粋関数）越しに触る。
- 右の欄（`SidePanel`）。主ボタンは「保存」（新規は「追加」）。Esc で閉じ、フォーカスは開いた帯へ戻す
- 中身：〈利用者さん〉・日付・時刻・所要・種類・担当・繰り返しの回の案内・この回の変更の印（「繰り返しのとおりに戻す」）・メモ・決まりごと・道順。日時と担当は同じ保存で変わる
- 担当の候補は `lib/reassignMenu` の `reassignChoices` を欄の日時で計算。保存の前に `staffPickError`
- 範囲（繰り返しの回）：この回だけ＝`savedVisit`／これ以降＝`lib/week` の `moveFollowing`／すべて＝今日以降で最初の同じ曜日の回から。範囲は同じ曜日の回。メモだけならこの回だけ。伝えた日が変わるなら確かめる
- 担当の範囲：この回だけ＝その日の並びに入れてピン／これ以降・すべて＝分けた繰り返しの担当
- 今ある訪問の〈利用者さん〉は変えない
- 開いている間に同じ訪問が別で変わったら保存せず知らせる
- 狭い画面（600px 以下）は見る・取り消す・担当替えだけ
- 日の予定の帯・カードの詳細（理由・「担当を変える ▾」）は残し、そこに「詳細・変更」を置く

## 捨てた案
今の欄を残して入口だけ足す（形がばらばらのまま）・帯を押したらすぐ欄（手直しの動きと e2e を壊す）。

## トレードオフ
- 失うもの：帯から欄まで2回押す。「これ以降」「すべて」は回の ID が変わる
