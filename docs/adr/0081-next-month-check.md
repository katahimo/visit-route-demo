# ADR-0081：月の終わりに「来月の確認」を1行で知らせる

- 日付：2026-11-01
- 状態：採用
- 関連：ADR-0012・0072・0073・0077

## 背景
カイポケでは曜日・時刻の決まった利用者（69名）の翌月分を毎月手で入れている（ヒアリング 2026-10-15）。このアプリでは繰り返しの回は計算で出るので、翌月分はすでに入っている（D372）。ただ画面がそれを伝えておらず、利用者は「来月分を作る作業」を探す。月の終わりに要るのは作ることではなく、来月の例外（担当なし・重なり・休みの人）と、休み・臨時の入れ忘れを確かめることだけ。

## 決定
- エキスパート機能が切で、今日が月の20日以降のとき、予定（月・週・日）の要対応の帯の下に「来月の確認」の1行を出す：「12月の予定 N件はできています」＋来月の要対応があれば「・担当なし a・重なり b・休みの人 c」（0 は出さない）＋［12月を見る ›］（月の予定の来月へ）＋［×］
- ［×］で閉じたらその月の間は出さない（端末に覚える。データ・書き出しには入れない）。来月に訪問が1件も無ければ出さない
- 来月の担当なしを組むのは要対応の帯の［担当なしを組む］（今日〜翌月末。D403）。この行にボタンを足さない
- 入は出さない（入の帯には「未確定 N日」などがある）

## 捨てた案
- 月初に来月分を自動で組む：開いたときに黙って担当を変えない（ADR-0072）
- 確認の専用画面：画面が増える。月の予定の来月がその画面になる

## トレードオフ
- 得るもの：「来月分は入っている」が伝わり、毎月の作業が「来月の例外を見る」だけになる
- 失うもの：月の終わりの10日ほど帯の下に1行増える
- 見直す条件：20日の境が事業所の締めと合わない声が出たとき
