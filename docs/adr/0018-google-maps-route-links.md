# ADR-0018：道順は Google マップの公開のリンク（Maps URLs）を作るだけ

- 日付：2026-10-18
- 状態：採用（日のメールの長さの段階は ADR-0059）
- 関連：ADR-0016・0017

## 背景
スタッフは訪問先の住所を地図アプリに打ち直していた。

## 決定
公開の Maps URLs（`https://www.google.com/maps/dir/?api=1&…`）のリンクを作るだけ。分数・キロ数は直線距離の概算のまま。
- アプリは通信しない。PRD §4 の「使わない」はキーの要る API のこと
- URL に入れるのは場所（座標は小数6桁、無ければ住所）と移動手段（〈スタッフ〉の `travelMode`）だけ
- 経由地は1本に3件まで（`MAPS_MOBILE_WAYPOINTS`）。超えれば複数本に分ける。URL が 2,048字を超えても分ける
- 公共交通は区間ごとのリンクだけ。場所の無い地点は全行程で飛ばして注記。自転車には徒歩への切り替えを添える
- 置く場所（主ボタンにしない）：日の予定のメール・〈スタッフ〉の画面・訪問の詳細
- 組み立ては `lib/mapsLink.ts`・`lib/mail.ts`、部品は `components/mapsLinks.tsx`

## 捨てた案
Directions API（キーを静的サイトに置けず費用がかかる）・出さない（打ち直しが残る）。

## トレードオフ
- 失うもの：訪問の多い日は全行程が2〜3本。押した人の端末から Google に場所が渡る
- 見直す条件：実機で上限を確かめ `MAPS_MOBILE_WAYPOINTS`・`MAPS_URL_LIMIT` を見直す
