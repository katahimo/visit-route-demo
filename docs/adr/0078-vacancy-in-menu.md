# ADR-0078：空き状況を左のメニューの項目に戻す

- 日付：2026-10-31
- 状態：採用
- 関連：PRD D400・D401・D406（置き換えた既存の要件：D383・D390・D377）、ADR-0073（切のメニュー4つ）・ADR-0074（入のメニュー5つ）・ADR-0012（空き状況）・ADR-0028（機能の入り切り）

## 背景
- 利用者の声（2026-10-31）：エキスパート機能が切のときメニューは4つ（予定・〈利用者さん〉・〈スタッフ〉・設定。D383）で、空き状況には予定の「その他 ▾」からしか行けず分かりにくい
- 入のメニュー（ADR-0074。D390）も同じく空き状況は「その他 ▾」から
- 制約：スマホの下のタブは 4項目＋探す＋メニュー の6つで幅が尽きている（390px）。空き状況は機能の表で切れる（`vacancy`）

## 選択肢
1. 置き場所：A＝予定のすぐ下の上の段の項目（切5つ・入6つ）／B＝予定の子の項目（月・週・日・空き状況）／C＝今のまま「その他 ▾」に置き、説明を足す
2. スマホの下のタブ：a＝今のまま（空き状況は「メニュー」の引き出しとパレット）／b＝設定と入れ替える／c＝タブを7つにする
3. 「その他 ▾」の項目：イ＝消す（入口はメニュー・パレット）／ロ＝残す

## 決定
1-A・2-a・3-イ。

1. 左のメニュー・スマホの引き出しは、切＝予定・空き状況・〈利用者さん〉・〈スタッフ〉・設定、入＝予定・空き状況・〈利用者さん〉・〈スタッフ〉・組む・設定。空き状況の画面の印は空き状況に付ける（予定から `/vacancy` を外す）
2. 下のタブは変えない（切＝予定・〈利用者さん〉・〈スタッフ〉・設定、入＝…・組む＋探す・メニュー）。空き状況は引き出しとパレット（「予定」のグループ）から
3. 予定の「その他 ▾」から空き状況を消す（入口を重ねない）。ADR-0077 で「担当なしの訪問を組む」も帯へ移したので、予定の「その他 ▾」に足す項目（`useSimpleMore`）は無くなる

## 理由とトレードオフ
- 得るもの：問い合わせの電話の最中に開く画面が、メニューから1回で開ける。予定の子にしない（B）ので畳みの決まりを増やさない
- 失うもの：メニューの項目が1つ増える（切は4→5）。スマホの下のタブからは直には開けない（引き出しの1手が要る）

## 影響
- PRD：D383→D400、D390→D401、D377→D406（`docs/prd.md`「廃止した D番号」）
- 設計：design.md §4 app（メニュー）・design/pages-nav.md・design/pages.md の確かめ
- e2e：メニューの項目の並び・印、「その他 ▾」の `more-vacancy` を使う所を直す
- 見直す条件：スマホで空き状況を使う声が多いとき（下のタブの入れ替え）
