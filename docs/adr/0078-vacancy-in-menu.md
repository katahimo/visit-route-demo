# ADR-0078：空き状況を左のメニューの項目に戻す

- 日付：2026-10-31
- 状態：採用
- 関連：ADR-0012・0028・0073・0074

## 背景
空き状況には予定の「その他 ▾」からしか行けず分かりにくかった。スマホの下のタブは幅が尽きている。

## 決定
- 左のメニュー・引き出し：切＝予定・空き状況・〈利用者さん〉・〈スタッフ〉・設定、入＝予定・空き状況・〈利用者さん〉・〈スタッフ〉・組む・設定。空き状況の画面の印は空き状況に付ける
- 下のタブは変えない（空き状況は引き出しとパレットから）
- 予定の「その他 ▾」から空き状況を消す

## 捨てた案
予定の子の項目（畳みの決まりが増える）・「その他 ▾」のまま説明を足す。

## トレードオフ
- 失うもの：メニューが1つ増える。スマホの下のタブからは直に開けない
- 見直す条件：スマホで空き状況を使う声が多いとき
