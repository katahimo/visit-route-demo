# ADR-0070：Excel・CSV の選択肢から複数の特性を選択肢ごとの列にし、経験年数を開始年で持つ

- 日付：2026-10-27
- 状態：採用（ADR-0006 の「選択肢から複数の特性は1つのセルに「、」区切り・「（なし）」＝確認済みで1つもない」を置き換え。条件のセルの書き方は ADR-0006 のまま）

## 背景
- 〈スタッフ〉の資格・得意（選択肢から複数）は、Excel・CSV の1つのセルに「看護師、保育士」と「、」で区切って書いていた。プルダウンでは1つしか選べないので手で打つことになり、表記ゆれ・打ち間違いで読み込みが止まる。Excel のフィルタで「看護師の人」を抜き出すこともできない
- 経験年数は数値の項目で、入れた数のまま変わらない。年が変わるたびに全員を書き直さないと、「経験年数3年以上」の条件が古い数で判定される
- まだ公開していないので、前の形の Excel・CSV・保存データを読めなくてよい

## 選択肢
1. 選択肢から複数の特性の列
   - 1-A：今のまま1セルに「、」区切り
   - 1-B：選択肢ごとの列（`特性：資格：看護師`）に ○／×／空
   - 1-C：選択肢ごとの列に ○／空だけ（全部空は「確認済みで1つもない」か「未確認」のどちらかに決める）
2. 経験年数
   - 2-A：数値のまま（年に1回書き直す）
   - 2-B：経験年数の項目だけ特別に扱い、年数を毎年自動で足す（保存データを書き換える）
   - 2-C：項目の種類に「開始年」を足し、始めた年を持って、条件はその日までの年数で比べる
3. 年数を数える基準の日（2-C のとき）
   - 3-A：今日
   - 3-B：予定の日（compile・空き状況の日付）

## 決定
- 1-B。選択肢から複数の特性は選択肢ごとの列 `特性：〈項目名〉：〈選択肢〉` に「○」（持つ）か「×」（持たない）。1人の行のその項目の列が全部空なら未確認、どれかに印があれば確認済み（空の列は持たない）。書き出しは、未確認なら全部空、確認済みなら持つ選択肢に ○・ほかに ×（1つもなければ全部 ×）。プルダウンは ○・×。名簿の読み込みでは、選択肢ごとの列が全部無ければ今の値のまま、一部だけなら止める。条件（必要条件・希望）のセルは今のまま（「どれか」「すべて」を表すので選択肢ごとの列にしない）
- 「（なし）」の印はやめる（選択肢の名前にも使える）。選択肢の名前に「、」と改行が使えないのは今のまま（項目のシートと条件のセルの区切り）
- 2-C。項目の種類 `startYear`（開始年。画面の名前「開始年」）を足す。値は西暦の整数（1900〜2100）。条件（is・not・gte・lte）の値は年数で、比べるのは その日の年 − 開始年（0 未満は 0）。年単位で数える（月は見ない）
- 3-B。年数は判定する日の年で数える（compile は問題の日付、空き状況は日ごと）。画面の表示（特性の「8年（2018年から）」）だけは今日の年で数える
- Excel・CSV では開始年の特性の列を `特性：〈項目名〉（開始年）` にして西暦を書く（「2018年」も読む）。条件の列（`希望：経験年数` など）は年数で、数値と同じ書き方（「3年以上」の「年」も読む）
- 初期データの経験年数は開始年の項目にし、値は 2026 年の年数から逆算した年にする

## 理由とトレードオフ
- 得るもの：資格・得意は ○ をプルダウンで選ぶだけで入り、フィルタで抜き出せる。○／× と空で「確認済み」と「未確認」を区別でき、印の文字（「（なし）」）を覚えなくてよい。経験年数は入れ直さずに毎年増え、過去・先の日の判定も日付どおりになる（同じデータなら同じ日の結果は同じ）
- 失うもの：列が増える（初期の項目で特性の列が2列から13列に）。選択肢を足すと列も増え、名簿の一部の列だけを消すと止まる。開始年は年単位なので、秋に始めた人もその年の1月から1年として数える。前の形のブック・CSV・保存データ（経験年数が数値の項目）は読めない／読んでも数値のまま
- 2-B は保存データを日付で書き換えることになり、同じデータで結果が変わる（再現性の決まりに反する）ので採らない

## 影響
- 契約：`ITEM_KINDS` に `startYear`、`START_YEAR_MIN`・`START_YEAR_MAX`。`matches(cond, item, value, date)` に日付、`yearsSince(startYear, date)`
- matching（compile の条件の理由）・vacancy（条件を満たす人を日ごとに）・seed（手作業の割当の条件の判定を matching の `matches` に寄せる）
- excel：`traitCols`（特性の列）・`traitToCells`・`parseMark`・`multiFromMarks`、見出しの重なりは書き出しで止める（`exportProblem`）。使い方のシートの文
- 画面：項目の形の選択肢、特性の入力（開始年の欄と今日までの年数）、条件の入力（年以上・年以下）、特性の表示（`traitText`）
- 見直す条件：月単位の経験が要る、または選択肢が多く列が増えすぎる（30 近い選択肢）と分かったとき
