# ADR-0070：Excel・CSV の選択肢から複数の特性を選択肢ごとの列にし、経験年数を開始年で持つ

- 日付：2026-10-27
- 状態：採用（ADR-0006 の複数の特性のセルの書き方を置き換え）

## 背景
資格・得意を1セルに「、」区切りで手打ちしていて、表記ゆれで止まりフィルタも使えなかった。経験年数は年が変わるたびに書き直す必要があった。前の形のデータは読めなくてよい。

## 決定
- 選択肢から複数の特性は選択肢ごとの列 `特性：〈項目名〉：〈選択肢〉` に「○」か「×」。その項目の列が全部空なら未確認、どれかに印があれば確認済み。プルダウンは ○・×。名簿の読み込みで列が全部無ければ今の値のまま、一部だけなら止める。条件のセルは今のまま
- 選択肢の無い項目は「確認済みで1つもない」を表せないので、最後の選択肢を消したら値は未確認。「（なし）」の印はやめる
- 項目の種類 `startYear`（開始年。西暦 1900〜2100）を足す。条件の値は年数で、比べるのは 判定する日の年 − 開始年（0 未満は 0。月は見ない）
- 判定する日は compile の問題の日付・空き状況の日ごと。画面の表示（「8年（2018年から）」）だけ今日の年
- Excel・CSV では `特性：〈項目名〉（開始年）` に西暦（「2018年」も読む）。条件の列は年数
- 契約：`ITEM_KINDS` に `startYear`、`START_YEAR_MIN`・`START_YEAR_MAX`・`isStartYear`、`matches(cond, item, value, date)`、`yearsSince(startYear, date)`

## 捨てた案
年数を毎年自動で足す（保存データを日付で書き換え、再現性に反する）・○／空だけ（未確認と区別できない）。

## トレードオフ
- 失うもの：列が増える（初期の項目で2列から13列）。年単位で数える
- 見直す条件：月単位の経験が要る、または選択肢が30近くになったとき
