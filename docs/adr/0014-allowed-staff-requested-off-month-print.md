# ADR-0014：担当を限る（可否で外す）、希望休のまとめ入力（欠勤の記録をそのまま使う）、月の予定の印刷

- 日付：2026-10-17
- 状態：採用
- 関連：PRD D68〜D70、ADR-0011（欠勤・振り直し）、ADR-0013

## 背景
訪問看護事業所のヒアリング（2026-10-15）で出た困りごと。
1. 「この方は特定の2名だけで担当する」という社内の決まりがある。相性 × を他の全員に付けるか重みで寄せるしかなく、人が増えるたびに付け直しが要り、決まりとして読めない
2. 常勤は月10日休みのシフト、非常勤は希望休を紙・LINE で集め、カレンダー・シフト表・予定へ三重に入力している。欠勤は日の画面で1人1日ずつ入れる作りで、月の初めのまとめ入力に向かない
3. 予定を紙のカレンダーにも書き写して貼っている

決めること：担当を限る持ち方と効かせ方、限った人がいなくなったときの扱い、希望休の持ち方と入れ方、印刷の作り方。

## 選択肢
- 限る：A `allowedStaffIds` ＋ compile で可否から外す／B 相性 × を自動で付ける／C 条件の型「担当を限る」を足し重み・必須を選べる
- いなくなったら：A 限らないに戻す／B だれも担当できない（印を別に持つ）
- 希望休：A 欠勤の記録を流用（終日＋メモ「希望休」）／B 欠勤に種類 `kind` を足す／C 稼働時間の上書きに空の時間帯
- 印刷：A 専用経路／B 月間に `@media print`

## 決定
担当を限るのは可否で外す（常に必須）。希望休は欠勤の記録をそのまま使う。印刷は専用の経路。

- 担当を限る：`clientSchema.allowedStaffIds`（空＝限らない）。compile は、その日の問題にいる利用中の人だけを数え、1人以上いればその人たちだけを可にする（理由 `ruleId: 'allowedStaff'`）。条件の重み・プリセットとは無関係。可否で外すので AI で組む・振り直し・週のドロップの「入れる人」・空き状況のすべてに1か所で効く
- 限った人がいなくなったとき：「限らない」に戻す。store の `repair` は、いない・休止中の ID と重なりを除く（全員いなくなれば `[]`）。〈スタッフ〉を休止にして保存するとき、その人を限った利用者さんがいれば確認に出し、同じ `update` で外す
- 希望休：`absenceSchema` は変えず、終日でメモが「希望休」のもの（`isRequestedOff`）。月間で〈スタッフ〉を選び「休みを入れる」にして日のマスを押すと足し・外す。日の画面でメモや時間帯を変えるとふつうの欠勤になる
- 希望休を入れても担当は自動では変わらない（ADR-0011 のまま）。その人の訪問がある日は「担当が休み」の要対応で気づく。希望休は前もって入れる休みなので、希望休だけでは要対応にしない（月の印・集計は希望休と欠勤を分ける）
- 印刷：専用の経路 `#/month/print`（メニューの外の画面。`lib/monthPrint` の純粋関数）。A4横の名前つきページで、連絡の一覧の印刷（A4縦）と混ぜず、CSS は印刷の画面の中だけに効かせる。担当は訪問の担当、休む〈スタッフ〉・利用者さんの休みも出す。時刻は目安
- 区切りは「、」にそろえる（理由の文・画面の印・Excel）
- データの版は1のまま（`allowedStaffIds` は `[]`）。希望休は既存の欠勤の形なので JSON・Excel の往復もそのまま

## 理由とトレードオフ
- 得るもの：担当を限る決まりが1か所に残り理由として説明できる。希望休は月のマスを続けて押すだけで紙・LINE から1か所へ写せ、稼働の差し引き・振り直し・連絡・Excel がそのまま使える。印刷はナビ・ボタンを隠す CSS を全画面に足さず、月間の作りを崩さない
- 失うもの：
  - 限るのは常に必須で、期間（〇月まで）も持たない。「なるべくこの人たち」は表せない
  - 希望休をメモの文で見分けるので、メモを書き換えると要対応・月の印の扱いが変わる。日数の確認・申請・承認はしない
  - 印刷は1マスに載る件数に限りがある。移動を入れた正確な時刻は日の画面で見る
  - 画面が1つ増える
- 捨てた案：限る B は相性の表を書き換え、決まりとして読めない。C は型・プリセット・達成の波及が大きい。印刷 B は月間の見た目と絡む
- 見直す条件：限った人が全員いなくなったときに止めたい声（2-B）。希望休と急な欠勤を分けて数えたい声（3-B。版は1のまま既定値で）

## 影響
- 主なモジュール：contracts（`allowedStaffIds`）、matching（compile）、store（repair）、`lib/requestedOff`、`lib/monthPrint`、月・〈利用者さん〉・〈スタッフ〉の画面、excel
- PRD §4：期間での一括入力はしない（希望休は月間でまとめて入れられる）
