# ADR-0014：担当を限る（可否で外す）、希望休のまとめ入力（欠勤の記録をそのまま使う）、月の予定の印刷

- 日付：2026-10-17
- 状態：採用
- 関連：ADR-0011・0013

## 背景
「この方は特定の2名だけで担当する」決まり、希望休の三重入力、紙のカレンダーへの書き写しがあった。

## 決定
- 担当を限る：`clientSchema.allowedStaffIds`（空＝限らない）。compile はその日の問題にいる利用中の人を数え、1人以上なら可をその人たちに絞る（`ruleId: 'allowedStaff'`）。常に必須で、条件の重み・プリセットとは無関係
- 限った人がいなくなれば「限らない」に戻す。`repair` がいない・休止中の ID を除く。〈スタッフ〉を休止にするとき、限った〈利用者さん〉を確認に出し同じ `update` で外す
- 希望休：`absenceSchema` は変えず、終日でメモ「希望休」のもの（`isRequestedOff`）。月間で〈スタッフ〉を選び「休みを入れる」でマスを押して足し・外す。担当は自動で変えず、訪問があれば「担当が休み」の要対応。希望休だけでは要対応にしない
- 印刷：専用の経路 `#/month/print`（`lib/monthPrint`）。A4横。CSS は印刷の画面の中だけ
- 区切りは「、」にそろえる

## 捨てた案
相性 × を自動で付ける（決まりとして読めない）・条件の型を足す（波及が大きい）・月間に `@media print`（月間の見た目と絡む）。

## トレードオフ
- 失うもの：「なるべくこの人たち」・期間付きは表せない。希望休はメモの文で見分ける。日数の申請・承認はしない
- 見直す条件：希望休と急な欠勤を分けて数えたい声（欠勤に `kind` を足す）
