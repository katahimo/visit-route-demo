# ADR-0046：週の予定で見ながら確定でき、月をまたぐ週は1度に扱う

- 日付：2026-10-21
- 状態：採用（週で組むのは担当を組むの画面。ADR-0063）
- 関連：ADR-0031・0042

## 背景
見ていた週だけを確定する手段が無く、月の予定へ飛ぶしかなかった。

## 決定
- 週の見出しの主ボタンは状態で1つ（`lib/weekPrep` の `weekNext`）。確定する日が無く問題のある日だけなら「日の予定で」の理由を出す
- 確定は月の「問題の無い日をまとめて確定」と同じ決まり（`bulkConfirmTargets`）・確認・書き方（`confirmDay`）を週の今日以降の日に当てる
- 組むのは担当を組むの画面（範囲を週に）。計算中は確定を押せず理由を出す
- 月をまたぐ週は1度に確定する

## 捨てた案
月の欄を週に絞って開く（月へ飛ぶ問題が残る）・週に別の計算を置く（止める・二重起動の決まりが二重になる）。

## トレードオフ
- 見直す条件：週のまま組みたい声が多ければ週の主ボタンに組む入口を足す
