# ADR-0069：日の予定のメールを、事業所の Google Apps Script に確定のときにまとめて預け、前日の決めた時刻に送る（mailto は残す）

- 日付：2026-10-27
- 状態：採用
- 関連：ADR-0001・0016・0017・0059

## 背景
日の予定のメールを毎日人数分押す手間があり、前日の決まった時刻に自動で送りたい。サーバーは無く、ブラウザを閉じると何も動かない。Google を使えない事業所もある。

## 決定
事業所ごとに GAS 付きのスプレッドシートのひな型をコピーしてもらい、アプリは確定のときにその Web アプリへメールを預ける。GAS が時刻トリガーで送る。mailto は残す。
- 預け先：`gas/Code.gs`。ひな型はコピー用のリンク（`GAS_TEMPLATE_URL`）。メニュー「訪問予定 › 初期設定」で合言葉・5分ごとのトリガー・シートを作る。デプロイと URL・合言葉の貼り付けは人がする
- やりとり：`src/contracts/mailSchedule.ts`（版 `v`＝1）。`ping`・`queue`（日付のキーで上書き）・`cancel`。本文は JSON の文字で POST し、独自のヘッダーを付けない。合言葉は本文に入れる
- 預けるのは日の予定のメールの欄の「N人分を予約して確定」を押したときだけ。アドレスのある担当全員分の全文を預け、その日を確定にする
- 送る時刻：訪問の前日の決めた時刻（既定 18:00、日本時間）。過ぎていれば次のトリガーで。過ぎた日は預けられない
- 同じ日を預け直すとまだ送っていない分を置き換える。「予約を取り消す」はまだ送っていない分を取り消す
- URL・合言葉・時刻・預けた記録はこの端末の localStorage の別のキー（DemoData に入れない）。管理者設定の「メールの予約送信」で入れ、「接続を試す」で確かめる
- 週のメール・連絡の一覧・空き枠の案内は mailto のまま

## 捨てた案
アプリが Google の API でシートと GAS を作る（審査の負担・トリガーは API で付かない）・ブラウザから Gmail API（時刻どおりに送れない）・サーバーから送る（デモの範囲を超える）。

## トレードオフ
- 失うもの：予定・住所が事業所の Google アカウントを通り残る（PRD §7 に予約送信を足した）。初回の準備が要る。合言葉が漏れると事業所の Gmail から送れる（「合言葉を作り直す」）。送れたかはシートで見る。予約のあとの変更は自動では預け直さない
- 見直す条件：実データで使うなら送ってよい宛先をシートで限る
