# ADR-0065：標準を決める道を組み方の標準の画面1本にし、考え方を替える所と組み方をそろえる

- 日付：2026-10-25
- 状態：採用（段の出し方と条件の重みの置き場所は ADR-0066・0067。エキスパート機能が切のときの組み方は ADR-0072）
- 関連：ADR-0010・0035・0062・0063・0064

## 背景
「考え方ごとに案を作って比べる」が担当を組むと組み方の標準の2か所にあり、計算も登録も別だった。考え方を替える所も3つあった。

## 決定（利用者が決めた）
- 標準を決める道は組み方の標準（`#/standard`）の1本：案をくらべる → 表で直す → 標準にする。登録の決まりは `registerStandard` の1つ
- 担当を組む（`#/arrange`）はいつも点数の基準で組み、考え方を選ぶ欄は置かない。標準が無い間は範囲にかかわらず組まず、「先に組み方の標準を決めてください」と［組み方の標準を決める］だけ
- 考え方を替えるのは条件の重み（点数の基準の選択）と、標準の登録（案から作ったとき）だけ
- 条件の重み：プリセットの重み・必須は変えられない。表は点数の基準の重みから始まる下書きで、［新しい考え方として保存（N件）］で名前（既定「〈元の名前〉（改）」）を付けた新しいプリセットを足し、点数の基準にする。6つあれば保存できず消すよう出す。初期の3つと最後の1つは消せない。プリセットの節は名前・一言・重みの読み取り・消す・基準に選ぶだけ
- 案をくらべるに「日で見る」：期間の日を選び、タブ（今の標準・案ごと。点・変わる件数。最高点に王冠）で切り替え、担当ごとの時間軸と地図で見る（変わる訪問に印、名前・訪問・区間を押すとその担当に絞る）。「今の標準」のタブは計算した回を今の標準のまま並べたもの
- 案は `runProposals`（来週の月曜から周期の週数・プリセットごと・ひな形）
- 持たないもの：`monthBatch` の `variants`・`choices`、`registerDayStandard`、条件の重みの画面の版1の名残

## 捨てた案
担当を組むの1日の案に1本化（曜日ごとに何度も選ぶ）・入口2つのまま（分かりにくい）・表の確定で基準のプリセットを上書き（登録時の考え方と後から食い違う）。

## トレードオフ
- 失うもの：1日の案から1手で標準にする近道。担当を組むでその場だけ別の考え方で組めない。直すたびにプリセットが増える（6つまで）
- 見直す条件：1日の事情を見て標準にしたい声が多ければ、担当を組むの提案から「組み方の標準で開く」を足す
