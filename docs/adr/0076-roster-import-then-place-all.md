# ADR-0076：名簿を読み込んだあとに「位置の無い N人を地図に置く」を出し、1回の押しでまとめて置く

- 日付：2026-10-31
- 状態：廃止（ADR-0094で置き換え）
- 関連：ADR-0016・0068・0075

## 背景
予約システムの顧客を読むと大半が位置の無いまま入り、一覧の下のまとめて置く欄まで移ってもう一度押す必要があった。外部への送信は押したときだけ。

## 決定
読み込みが入ったら、名簿の欄の中に従のボタン「位置の無い N人を地図に置く」と送る先の注記を出す。
- 出す条件：〈利用者さん〉の名簿の読み込みが入り、`geocode` が入で、`placeAllTargets` の対象が1人以上いて、まとめて置いている最中でないとき（`lib/placeAll` の `placeAllLead`、状態は `components/useRosterPlaceLead`）
- 押すと名簿の欄を閉じ、まとめて置く欄へ移ってフォーカスし、検索を始める（もう一度押させない）。この1回の押しを送る同意とする
- `usePlaceAllRun` は `components/` に置き一覧の画面が持つ。`PlaceAllPanel` は結果を見せるだけ
- 住所から見つからなかった人がいれば、結果に1行「市区町村の名前が無い住所は見つからないことがあります…」
- 〈スタッフ〉の自宅にはまとめて置くを作らない（人数が少なく、自宅の郵便番号は保存しない）

## 捨てた案
確認のダイアログに「位置も探す」（外部送信の選択が混ざる）・トーストにボタン（消えると押せない）。

## トレードオフ
- 見直す条件：〈スタッフ〉の名簿で位置の無い人が大勢入る形が増えたとき
