# ADR-0006：Excel の書き出し・読み込み（テンプレートとして編集して入れ直す）

- 日付：2026-10-13
- 状態：採用（選択肢から複数の特性のセルの書き方は ADR-0070 で置き換え）
- 関連：ADR-0020（名簿だけの読み込み）

## 背景
人・条件などを Excel の一覧で直して読み込みたい。JSON は人が編集するものではない。

## 決定
- Excel にはマスタと予定を入れる。提案など作業中の結果は持ち越さない
- 参照は名前で書く（ID 列も残し、空なら新しい行）。同じ名前の人・項目は読み込みで止める
- ライブラリは ExcelJS（見出しの色・列幅・入力規則を付けられる）。使うときだけ動的 import
- 運用の記録（伝えた内容・振り直し・組み方の標準の記録）はシートに持たず、読み込みでは今のものを残す（ADR-0053・0062）。丸ごとの控え・別の端末へ移すのは JSON
- 事業所名が違うブックは確認で知らせ、運用の記録を持ち込まない
- `src/excel/` は DemoData とブックの変換だけ。読み込んだ結果は store の `migrate`→`repair` を通して `replace`

## 捨てた案
ID で書く（手で書き足しにくい）。SheetJS（npm の版が古い）。

## トレードオフ
- 見直す条件：ファイルの大きさが問題になれば SheetJS を検討。同名の人が要るなら参照を ID 併記に
