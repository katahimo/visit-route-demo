# ADR-0006：Excel の書き出し・読み込み（テンプレートとして編集して入れ直す）

- 日付：2026-10-13
- 状態：採用（選択肢から複数の特性のセルの書き方は ADR-0070 で置き換え）
- 関連：PRD D23・ADR-0020（名簿だけの読み込み）

## 背景
利用者から「スタッフ・利用者さん・条件などを Excel で一覧にして、それをテンプレートとして追加・修正し、読み込めば内容が全部変わるようにしたい」という要望が出た。JSON の書き出し（D3）は人が直接編集するものではない。

## 選択肢
1. 計算結果の扱い
   - A：Excel にはマスタと予定だけを入れ、読み込んだら提案・記録のような作業中の結果は持ち越さない
   - B：ID が一致する人・訪問の結果は残す
2. 参照の書き方
   - A：名前で書く（ID 列も残し、空なら新しい行）
   - B：ID で書く
3. ライブラリ
   - A：ExcelJS（保守が続く。見出しの色・列幅・入力規則を付けられる）
   - B：SheetJS（軽い。npm の版は古く、新しい版は公式 CDN から入れる必要がある）

## 決定
1-A、2-A、3-A。

## 理由とトレードオフ
- 得るもの：
  - Excel で行を足す・直すだけでデータを入れ替えられる
  - 名前で書くので、手で書き足しやすい
  - 見出し・プルダウン付きのテンプレートとして渡せる
  - 結果を持ち越さないので、古い結果と新しいマスタが食い違わない
- 使い分け：Excel は人が見て直す一覧。運用の記録（伝えた内容・振り直し・組み方の標準の記録）はシートに持たず、読み込みでは今のものを残す（ADR-0053・ADR-0062）。丸ごとの控え・別の端末へ移すのは JSON。画面の両方の欄にこの使い分けを書く
- 別の事業所のブック：事業所名がいまと違えば確認で知らせ、運用の記録は持ち込まない（別の事業所の確定を残すと「未連絡の変更」が食い違うため）。事業所に ID が無いので名前で見る（名前を変えた同じ事業所でも知らせが出る）
- 失うもの：
  - 丸ごとの控えは今までどおり JSON で取る（Excel は作業中の結果を持たない）
  - 同じ名前の人・項目は読み込みで止める（名前は一意にしてもらう）
  - ExcelJS のぶん、画面のファイルが重くなる（Excel を使うときだけ読み込む動的 import にする）

## 影響
- `src/excel/` は DemoData と Excel のブックを変換するだけで、データは書き換えない。読み込んだ結果は store の `migrate`→`repair` を通して `replace` する
- 外部送信は増えない（ライブラリは同梱）
- 見直す条件：ファイルの大きさが問題になったら SheetJS への置き換えを検討する。同名の人が実際に要るなら、参照を ID 併記に変える
