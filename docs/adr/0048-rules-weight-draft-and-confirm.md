# ADR-0048：条件の重みの表を下書きにし、「変更を確定」と確認のあとで保存する

- 日付：2026-10-21
- 状態：採用
- 関連：ADR-0026・0035・0052

## 背景
基準の重みは組み方と点数のすべてに効くのに、動かすとすぐ保存していた。

## 決定
表の重み・必須は画面の下書き（`lib/weightDraft`）にし、「変更を確定（N件）」で確認してからまとめて保存する。
- 確定で `update(d => applyDraft(d, 下書き))`（型ごとに `setBasisWeight`）。保存済みと同じに戻した欄は下書きから外れる
- 違う行は注意の色の帯・淡い地・「変更あり 3→2.5」の文字
- 確定の帯は下書きがある間だけ画面の下に貼り付く（主ボタン「変更を確定（N件）」・文字「取り消す」）
- 確認：変わる条件と重み（前→後）・組み方と点数に使うこと・影響する今日以降の日（確定済みの日は作り直さない）
- 離れるとき：アプリ内のリンクの押下を捕捉して確認（`components/useLeaveGuard`・`lib/leaveGuard`）。パレットは `confirmLeave()`。再読込は beforeunload。ブラウザの戻る・進むでは確認を出せず黙って捨てる
- 基準を替える・基準のプリセットを消す・初期値に戻すと下書きを捨てる。名前・追加・削除・プリセットの節・基準の選択・乱数の種はすぐ保存

## 捨てた案
即時保存＋トーストで元に戻す（戻すまでに操作が混乱する）・画面全体を下書き（小さな操作まで確定が要る）。

## トレードオフ
- 失うもの：確定と確認の1手が増える。プリセットの節は即時のままで、基準の重みを2か所で直せる
- 見直す条件：プリセットの節も下書きにしたい声が出たとき
