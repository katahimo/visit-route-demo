# ADR-0033：狭い画面では一覧の表をカードに組み替える

- 日付：2026-10-19
- 状態：採用
- 関連：PRD D220〜D222、ADR-0024（スマホのメニュー）

## 背景
ADR-0024 はメニュー・上の帯・下のタブだけを狭い画面向けにし、各画面の中身は PC 前提のままにした（管理者役は PC、スマホは表示の確認。PRD §7）。しかし 390px では、表示の確認にも使えない画面がある。
- 条件の重み・特性の項目・〈スタッフ〉一覧・〈利用者さん〉一覧・比較の記録：操作の列（スライダー・必須・選択肢）や特性の列が画面の外。最初の画面が絞り込みのチップだけで、一覧が2画面目になる
- 週：時間軸の最小幅で今日の列が切れる
- 格子の表（相性・勤務時間・空き状況など）：1列目が止まらず、右に続きがある印も無い

制約：広い画面の見た目・URL・データは変えない。表の印（`table`・`tr`・`td`・data-testid）は e2e と読み上げが使うので変えない。新しい境目を作らない（今の 600px）。

## 選択肢
| 案 | 長所 | 短所 | 採否 |
|---|---|---|---|
| A：今のまま（表を横に巻く） | 作り直しが無い | 操作の列が画面の外で、表示の確認にも使えない | 不採用 |
| B：狭い画面で列を隠す | 簡単 | 隠した列の情報が見えず、どの列を隠すかが画面ごとに揺れる | 不採用 |
| C：一覧の表を CSS だけで1行1枚のカードに | 列を隠さない。印が変わらない。広い画面は変わらない | 1枚が縦に長い | 採用 |
| D：スマホ用の部品を別に作る | 見た目を最適にできる | 部品が二重になり、直し漏れが出る | 不採用 |
| 格子の表もカードに | 横に巻かない | 曜日×時刻・人×日の見比べという表の意味が無くなる | 不採用（表のまま1列目を止める） |
| 週の既定：時間軸のまま | 広い画面と同じ | 7列が入らず今日が切れる | 不採用 |
| 週の既定：〈スタッフ〉×曜日の表 | 1人1行で、名前の列を止めれば今日の列を名前と並べて見られる | 帯のドラッグは時間軸に移ってから | 採用 |

## 決定
狭い画面（600px 以下）では、**一覧の表**を1行1枚のカードに CSS で組み替え（表の印は変えず、WebKit が落とす表の role だけ明示する）、**格子の表**は表のまま1列目を止めて右に続きがあることを示す。週は〈スタッフ〉×曜日の表を既定にする。

- 一覧の表（D220）：`table.narrow-cards`。1行目に名前と大事な値（必須・状態など）、ほかのマスは `td::before` の見出しと値、操作は右下。列は隠さない。対象は条件の重み・プリセットの重み・特性の項目・〈スタッフ〉一覧・〈利用者さん〉一覧・比較の記録。〈利用者さん〉一覧の絞り込みは「絞り込み（N）」のボタンの下に畳む
- 格子の表（D221）：相性・勤務時間・勤務の見込み・空き状況・週の表と時間軸。1列目を止め、縦に長い表は見出しの行も止める。時間軸を除く表は、右に続きがある間は右の端をぼかす（`components/EdgeScroll`・`lib/scrollEdge`）。空き状況ははじめ 9:00 の列から見せる
- 週（D222）：`?view=`・`?by=` が無ければ〈スタッフ〉×曜日の表（URL に書かない。押した表示は書く。月の `?layout=` と同じ）。今日の列まで巻いて見せる

## 理由とトレードオフ
- 得るもの：390px で一覧が横に巻かずに使える。格子の表は1列目が見え、続きがあると分かる。週は開いてすぐ今日が見える。広い画面・URL・データは変わらない
- 失うもの：カードは縦に長く、一覧の人数が多いと巻く量が増える（絞り込みで減らす）。狭い画面の既定（週の表・絞り込みを畳む）が幅で変わるので、広い画面で時間軸を押した URL は `?view=` を書かず、狭い画面で開くと表になる。新しい一覧の表にも `narrow-*` の CSS を付ける手間
- 見直す条件：スマホで予定を直す（ドラッグ・確定する）使い方が増えたら、時間軸・日の予定のスマホ向けの作りを別に決める。カードが長すぎるという声が多ければ、カードの2行目以降を畳む

## 影響
`styles.css` の `narrow-*`・`components/EdgeScroll`・`lib/scrollEdge`・`lib/weekView`・`lib/clientFilter`、各画面（rules・items・staff・clients・compare・week・vacancy）。設計は design/pages.md「狭い画面の表」。
