# ADR-0033：狭い画面では一覧の表をカードに組み替える

- 日付：2026-10-19
- 状態：採用
- 関連：ADR-0024

## 背景
390px では操作の列が画面の外に出て、表示の確認にも使えない画面があった。表の印（`table`・`tr`・`td`・data-testid）は e2e と読み上げが使うので変えない。

## 決定
600px 以下で：
- 一覧の表（`table.narrow-cards`）を CSS だけで1行1枚のカードに。1行目に名前と大事な値、ほかは `td::before` の見出しと値。列は隠さない。WebKit が落とす表の role は明示する
- 格子の表（相性・勤務時間・空き状況・週の表など）は表のまま1列目（縦に長ければ見出しの行も）を止め、右に続きがある間は端をぼかす（`components/EdgeScroll`・`lib/scrollEdge`）
- 週は `?view=`・`?by=` が無ければ〈スタッフ〉×曜日の表を既定にし、今日の列まで巻く

## 捨てた案
列を隠す（情報が見えない）・スマホ用の部品を別に作る（二重になる）・格子の表もカード（見比べの意味が無くなる）。

## トレードオフ
- 失うもの：カードは縦に長い。新しい一覧の表にも `narrow-*` を付ける手間
- 見直す条件：スマホで予定を直す使い方が増えたとき
