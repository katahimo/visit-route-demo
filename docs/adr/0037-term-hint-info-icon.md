# ADR-0037：用語の説明の目印を ⓘ にし、同じ語の説明は1画面で1か所にする

- 日付：2026-10-19
- 状態：採用

## 背景
用語の点線の下線が1画面に何本も並び、名前のボタン（`PersonButton`。同じ点線）と見分けにくかった。

## 決定
用語の文字と小さな ⓘ を1つのボタンにし、下線はやめる（`components/Term.tsx`・`lib/glossary.ts`）。
- 読み上げの名前は見える用語の文字。説明は `aria-describedby` の先の `role="tooltip"`
- `pointer: coarse` では ⓘ のまわり 24px 角を押せる。印刷では ⓘ を出さない
- 同じ画面の同じ語は最初の1か所だけ説明つき、ほかは `plain`。開く欄は別の画面として数える

## 捨てた案
点線のまま語を増やす・ⓘ だけのボタン（読み上げの名前が見える文字と別になる）。

## トレードオフ
- 見直す条件：ⓘ が名前の i（`PersonInfo`）や `Hint` と紛れる声が出たとき
