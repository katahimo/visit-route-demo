訪問ルートAI（デモ版）
操作説明

訪問介護・移動支援の事業所向け

台帳 CSV の読み込みから、毎週の予定・当日の欠勤・空き状況・勤務の見込みまで

開くところ：https://staff-assign-demo.katahimo.com/
パソコンの Chrome か Edge で開きます。インストールとログインはありません。
説明には架空のデータを使います。

はじめに

困りごとと、このアプリでできること

困りごと（今のやり方） このアプリでは
シフトを毎月、手で組んでいる 毎週の訪問（曜日・時刻・所要）を一度入れると、担当を自動で組みます
振り分けの決め手（距離・性別の希望・相性）が頭の中にしかない 住所から緯度・経度を入れ、移動の近さで組みます。性別の希望と相性も入れておけば守ります
朝・夜の訪問に入れないスタッフがいる スタッフごとの勤務する曜日・時間の外には組みません
どこに空きがあり、誰を振れるかが分からない 「空き状況」で曜日・時間帯・所要を選ぶと、受けられる時刻と人数が出ます
当日の欠勤・キャンセルのたびに、組み直しと連絡に追われる 休む人を選ぶと、代わりの案と連絡の文が出ます。当日キャンセルも登録できます
退職者が出たときの組み直しに時間がかかる 最終勤務日を入れると、翌日からの担当と代わりの候補が一覧になります
拘束の時間と交通費を手で計算している 「勤務の見込み」に、人ごと・日ごとの拘束の時間と交通費の見込みが出ます
介護ソフトと二重に入力したくない 利用者台帳・職員台帳の CSV を、列を直さずに読み込めます

はじめに

説明の流れ

  1. 最初の設定定期＋勤務・契約
  2. 台帳 CSV の読み込み利用者台帳・職員台帳
  3. 読み込んだあとに足すこと性別・勤務時間・相性
  4. 毎週の予定と自動の組み
  5. 当日の欠勤・当日キャンセル
  6. 退職
  7. 空き状況新しい相談
  8. 勤務の見込み・交通費・契約の段階

実演のページ

  • 右の枠の中で、アプリをそのまま操作できます
  • ［大きく表示］で枠を画面いっぱいにします。Esc で戻ります
  • 前のページで入れたデータは、次のページに引き継がれます
  • ［説明用データを最初に戻す］で、最初の設定から始め直せます

データの扱い

  • データは、開いたパソコンのブラウザの中だけに残ります
  • スライドの中のアプリは説明用の保存場所を使います。ふだんのデータとは別です
  • 実在の利用者さん・職員の名前や住所は入れないでください

ページは ← → ・スペース・PageUp / PageDown で送ります。F で全画面になります。アプリの枠の中を操作している間は、キーでページは送りません（枠の外を押すと送れます）。

1. 最初の設定実演

最初の設定（定期＋勤務・契約）

  1. 「1. どちらで始めますか」で「自分のデータで始める」を選びます
  2. 「2. 使い方の近いものはどれですか」で「定期＋勤務・契約」を選びます（例：訪問介護・移動支援）
  3. ［はじめる］を押します
  4. 「登録の案内」の「① 利用者さんの名簿を読み込む」（1/3）が開きます

人の呼び方は「利用者さん」「スタッフ」になります。左のメニューは 予定・空き状況・利用者さん・スタッフ・設定 です。

「定期＋勤務・契約」では、勤務の見込み・交通費・段階と紹介元の機能が入った状態で始まります。

「最初の設定」が出ないときは、［説明用データを最初に戻す］を押します。

2. 台帳 CSV の読み込み実演

利用者台帳・職員台帳を読み込む

  1. 「① 利用者さんの名簿」で［ファイルを選ぶ］を押し、利用者台帳の CSV を選びます
  2. 確かめる画面で人数と読まない列を見て、［名簿を読み込む］を押します
  3. 続けて住所から緯度・経度を探します。「終わりました」と出たら［次へ］
  4. 「② スタッフの名簿」で職員台帳の CSV を同じように読み込み、［次へ］
  5. 「③ 予定を登録する」で［予定の画面へ］を押します
利用者台帳_サンプル.csv をダウンロード 職員台帳_サンプル.csv をダウンロード

サンプルは架空の名前で、住所は仙台市の公共施設です。緯度・経度を探している間は、ページを移らずに待ちます。

台帳 CSV の読み込み

2. 台帳 CSV の読み込み

台帳のどの列を読むか

利用者台帳の列 アプリでは
利用者名・利用者カナ名前・よみ
郵便番号・都道府県〜建物名住所（1行にまとめます）
電話番号・備考メモ
利用者状態「利用中」なら利用中、ほかは終了
生年月日・性別・請求・口座など読みません
職員台帳の列 アプリでは
職員名名前
都道府県〜建物名自宅の住所（直行直帰の出発点）
職員Eメールアドレスメールアドレス
退社年月日最終勤務日
在職状況「退社済」なら休止
資格・研修の列資格・研修
カナ・入社年月日・電話など読みません

サンプルで読み込むと

  • 利用者さん 8人。「科学館 ひかる」さんは契約終了なので終了で入り、緯度・経度を探すのは 7人です
  • スタッフ 7人。「泉区役所 いずみ」さんは最終勤務日 11/30、「旧庁舎 むかし」さんは休止で入ります

読み直すとき

  • 読み込み方は「総入れ替え」と「追加・更新」から選べます。どちらも人を消すことはありません
  • 読み込む前の状態は、設定 › データの［直前の状態に戻す］で戻せます

3. 読み込んだあとに足すこと実演

スタッフ：性別・勤務する曜日・勤務時間

  1. 一覧で人を押し、［基本情報］タブを開きます
  2. 「詳しく ▾」を押し、「特性」の［直す］で性別を選んで［保存］
  3. ［勤務時間］タブの「ふだんの勤務」で［直す］を押します
  4. 勤務開始・勤務終了・勤務する曜日を入れて［保存］

台帳から入ったスタッフは、はじめ 月〜金・9:00〜18:00・車・性別は未確認 です。性別が未確認のままだと、「必要条件：女性」の利用者さんの担当になりません。

例：子育て中で朝・夜に入れない人は 9:30〜15:00。日・月が休みの人は 火〜土 を選びます。

スタッフ

3. 読み込んだあとに足すこと実演

利用者さん：性別の希望・相性

  1. 一覧で人を押し、［基本情報］タブの「詳しく ▾」を押します
  2. 「スタッフに求めること」の［直す］を押します
  3. 「女性のヘルパーを必ず」は必要条件の性別で女性、「できれば女性」は希望の性別で女性に印を付けて［保存］
  4. 一覧の上の［相性］タブで、マスを押して印を選びます

必要条件に合わない人は担当にしません。希望は、合う人を先に考えます。資格・研修（同行援護など）が要る方も、必要条件で選びます。

相性の印：× 担当にしない／△ 選ばれにくい／○ やや選ばれやすい／◎ 選ばれやすい。何も入れなければ ふつう です。

利用者さん

4. 毎週の予定と自動の組み実演

毎週の予定を入れる

  1. 月の予定で［定期の予定を追加］を押します
  2. 利用者さん・曜日（いくつでも）・くり返し・開始日・時刻・所要（分）を入れます
  3. ［追加］を押すと、「N件の担当を組みました」と出ます
  4. ［月］［週］［日］で見方を替えます

曜日は、はじめ今日の曜日が選ばれています。要らなければ押して外します。

くり返しは 毎週・隔週・3週ごと・4週ごと・毎月（第N）。今日から翌月の終わりまでの回に担当が付きます。

例：体育館 つよし　月〜金　8:30　30分

月の予定

4. 毎週の予定と自動の組み

組むときに守ること・良くすること

必ず守ること

  • スタッフの勤務する曜日・勤務時間・休み・最終勤務日
  • 利用者さんの必要条件（性別・資格・研修）
  • 相性の「× 担当にしない」

できるだけ良くすること

  • 移動が近いこと（自宅や前の訪問先から）。緯度・経度が無い所への移動は 30分とみます
  • 希望・相性
  • 受け持ちが人によってかたよらないこと

サンプルで組むと

  • 体育館 つよしさんの朝 8:30・夜 18:00 には、9:30〜15:00 勤務の国際センター みどりさんは入りません
  • 博物館 かわ子さん（必要条件：女性）には、女性のスタッフだけが入ります
  • 天文台 ほしおさん（同行援護）には、研修を持つ図書館 つつじさんが入ります
  • 動物公園 ももさん（相性 ×：図書館 つつじ）には、つつじさんは入りません
  • 土曜のメディアテーク はるさんには、土曜に勤務する宮城野区役所 みやぎのさんが入ります

決まったあとに担当や時刻が変わった訪問には「変更あり」の印が付きます。予定の画面の矢印のボタンで、ひとつ前に戻す・やり直すができます。

5. 当日の欠勤・当日キャンセル実演

当日の欠勤・当日キャンセル

  1. ［欠勤・キャンセルを登録］を押し、「スタッフが休む」を選びます
  2. 休む人と、休む時間（終日・午前だけ・午後だけ・時間帯）を選びます
  3. 「入らなくなる訪問」とおすすめの案が出ます。［この案で決める］を押します
  4. 「変更を伝えて確定する」で［文をコピー］を押し、LINE などに貼ります。送ったら［連絡した］、最後に［終わる］
  5. 当日キャンセルは「利用者さんがキャンセル」で訪問を選び、「当日キャンセル」→［当日キャンセルとして取り消す］

おすすめの案は、ほかの人の担当・順番・時刻を変えません。決めたあとも［振り直す前に戻す］で戻せます。

6. 退職実演

退職するスタッフの担当を振り直す

  1. スタッフの画面の「最終勤務日（退職・担当替え）」で日付を入れます。職員台帳の退社年月日からも入ります
  2. スタッフ一覧の上の「最終勤務日のあるスタッフ」で［担当の振り直しを開く］を押します
  3. 「利用者さんごとの代わり」で代わりのスタッフを選びます（入れる回数と、4週の受け持ちの回数が出ます）
  4. ［まとめて適用］→［担当を置き換える］。最終勤務日の翌日からの担当が替わります

振り直すものが無いときは「振り直しは済んでいます」と出ます。試すときは、担当のあるスタッフに数日先の最終勤務日を入れます。

7. 空き状況（新しい相談）実演

新しい相談に答える

  1. 曜日（例：火・木）、時間帯（例：午前）、所要（例：60分）を選びます
  2. 「受けられます：火・木 8:30〜11:30 に 約2〜4人」のように出ます
  3. ［要約をコピー］で答えの文をコピーし、相談員さんへの返事に使えます
  4. 「2. 場所」に住所を入れると、移動も入れて絞り込みます
  5. 受けるときは［仮の利用者さんとして押さえる］→ 表示名を入れて［押さえる］

今日から 4週分の予定のすき間に入るかを見ます。ほかの人の予定は動かしません。

押さえた人は「仮」の印の利用者さんになり、段階は「相談受付」です。

空き状況

8. 勤務の見込み・交通費・契約の段階実演

勤務の見込み（拘束の時間）と交通費

  1. 開き方：［スタッフ］→［勤務］タブ→［勤務の見込み］（月の予定の［その他］からも開けます）
  2. 「月の合計」に、人ごとの日数・訪問・出勤〜退勤（拘束）・一番長い日・移動・空き時間（待ち）・距離・交通費が出ます
  3. 「日ごと」で名前を押すと、その人の日ごとの時間が出ます
  4. ［表をコピー］で、Excel に貼り付けられます

拘束は、その日の最初の訪問の始まりから最後の訪問の終わりまでです。交通費の単価ははじめ 10円/km、拘束の上限ははじめ 10時間です。

予定から出した見込みで、実際に働いた時間ではありません。

勤務の見込み

8. 勤務の見込み・交通費・契約の段階実演

相談から契約までの段階と紹介元

  1. 利用者さんの画面の［基本情報］タブで「詳しく ▾」を押します
  2. 「段階と紹介元」の［直す］で段階を選びます：相談受付・顔合わせ・契約・利用中・終了
  3. 紹介元・連絡先・メールアドレス・メモを入れて［保存］
  4. 仮押さえの人は［本登録にする］で利用中に、［仮押さえを取り消す］で取り消します

利用中より前の段階では「枠を仮押さえする」に印を付けると、契約の前でも予定に入れて担当を組めます。

台帳から読み込んだ人の段階は、「利用中」か「終了」です。

おわりに

このデモでできないこと

  • 請求国保連・移動支援の市町村ごとの明細、利用者負担の集金、キャンセル料の請求
  • 勤怠・打刻入ります／終わりました の打刻、実際に働いた時間の記録。勤務の見込みは予定からの見込みです
  • 実績記録票実績記録票・利用者さんのサイン
  • LINE とのつながり連絡の文はコピーして、人が送ります。自動では送りません
  • ログイン・共有ログイン、何台ものパソコンでの同時の入力、インターネット上への保存
  • 交通費の精算交通費は見込みです。精算は事業所の決まりで行います

データはブラウザの中だけにあります。残すときは、設定 › データの「控え（バックアップ）」で［ファイルに書き出す］を押します。
